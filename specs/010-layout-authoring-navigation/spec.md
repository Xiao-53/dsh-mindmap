# Feature Specification: 导图四向邻接排版、生成质量与详情关系操控优化

**Feature Branch**: `main`（沿用当前工作分支）
**Created**: 2026-11-22
**Status**: Draft
**Input**: User description: "吸收 MapFlow 项目优点：1. 不引入不适配的学习进度点亮机制；2. 解决 AI 生成导图的质量问题（防伪连线、防单根强迫症、去虚词质量判据、明确边界与阅读起点）；3. 结合四向动态端口优化现有导图的二维网格邻接自动排版与连线穿卡问题；4. 优化分组容器紧凑包裹并精简冗余多列模式；5. 优化节点详情的前后关系跳转、画布联动与连线焦点高亮操控（保持模块化可独立回退）"

## Clarifications

### Session 2026-11-22

- Q: 当打开工作区中已经保存过 `layout.json` 的既有导图时，新的自动排版与紧凑分组外框应当在什么时机生效? → A: 采用仅新图与主动重排生效（Option A）：已有 `layout.json` 的视图打开时完全保留原节点坐标与已存分组外框；仅在新建导图、视图缺少已存布局、新增未定位节点的空位补齐，或用户主动点击顶栏“重置排列 / 切换排列模式”时，应用新的自动排版与紧凑分组框计算。
- Q: 当两点之间的连线路径穿过中间其他节点卡片时，连线应当采用哪种避让呈现方式? → A: 采用贝塞尔弧度偏移避让（Option A）：保留 HTML v17 基准的三次贝塞尔平滑曲线与现有端口投影过渡动画；仅当检测到连线穿过中间非端点节点卡片的矩形区域时，将曲线控制点向阻挡卡片外侧通道偏移绕弧，未受阻挡的连线保持原样。
- Q: 在节点详情面板（`NoteInspector`）中展示的前置与后续关系胶囊，应当取材于哪个范围，且当点击的目标节点自身带有子图（`childViewId`）时应当如何跳转? → A: 采用当前视图范围 + 统一切换详情并同层居中（Option A），且必须做好模块化可拆分设计（支持验收后单独打回/回退）：仅展示当前视图（`view.relationIds`）内直接相连的前置依赖、后续节点与补充关联胶囊；点击任意胶囊时，始终在当前视图内将画布平滑居中并选中目标节点、同时将详情面板切换到该节点的详情笔记，不触发跨视图子图下钻；该能力在实现与任务拆分上与核心排版、提示词改动完全解耦。
- Q: 当用户在画布上点击节点或关闭详情面板时，“节点选中（触发关联连线高亮）”与“打开/收起详情面板”应当遵循哪种交互组合? → A: 采用保持原有单击直觉 + 收起详情保留画布选中高亮（Option A），且同样保持独立可拆分/可回退：单击无子图节点同时选中高亮关联连线并打开详情（单击有子图节点仍直接下钻进入子图）；点击详情关闭按钮（或按一次 `Escape`）仅收起详情面板而保留画布上的节点选中与关联边高亮；在详情已收起时，再次点击该已选中节点重新展开详情，点击画布空白处（或再按一次 `Escape`）才彻底清除节点选中态与连线高亮。
- Q: 结合我们现有的四向动态端口机制，自动排版与排列模式精简应当采用哪种方案? → A: 采用四向端口感知的二维网格邻接排布 + 紧凑分组框 + 删除 `columns` 多列模式（Option A）：移除需 7 组以上才触发的 `columns`（多列）模式，仅保留 `vertical`（单列纵向）与 `grid`（双列田字）；组内维持最大 3 列的紧凑二维网格，按关系将相连节点优先分配在上下或左右相邻格（连续长链采用 S 型蛇形折行避免回车长斜线、多连线枢纽优先居中以充分利用上/下/左/右四向动态端口、避免同行/同列夹心穿卡、保持左上到右下的流向微偏向），并去掉分组框 `1058px` 固定最小宽度，按实际节点列数紧凑包裹。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 契合四向动态端口的二维网格邻接排版与紧凑分组 (Priority: P1)

用户在侧栏中让 AI 新建一张包含多个分组和前后依赖关系的思维导图，或对已有导图执行排列切换与重置时，画布能够充分利用节点卡片的上、下、左、右四向动态端口特性，在最大 3 列的紧凑二维网格中将有连线关系的节点优先安置在左右或上下相邻格位（连续链条自动采用 S 型蛇形折行，多连线枢纽优先居中向四周散射，避免同行或同列中间夹着无关卡片导致水平/垂直穿卡），同时根据组内实际节点列数紧凑包裹分组外框，并精简掉不再适用的 `columns`（≥7 组多列）排列模式。

**Why this priority**: 导图打开后的第一眼可读性直接决定用户能否理解知识脉络；目前按 JSON 数组下标盲填 3 列网格导致的“行尾到次行首超长斜跨线”、“同行/同列隔山打牛穿卡”以及硬编码 `1058px` 超宽空分组框，是影响现有导图观感最突出的排版痛点。

**Independent Test**: 打开或新建包含串联长链、一分多枢纽、汇合、局部环路及 1～2 个节点小分组的导图，在不手动拖拽的情况下检查初始自动布局与重置排列结果：相连节点优先位于左右或上下相邻格，连续 4～6 节点长链呈 S 型折行而非跨屏大斜线，多度枢纽节点位于网格内部格使端口分散到多个方向，1～2 个节点的分组边框紧贴内部节点收缩，且已有 `layout.json` 的老导图在未主动触发重置/切换排列前保持原坐标与外框完全不变。

**Acceptance Scenarios**:

1. **Given** 一张新创建或执行“重置/切换排列”的导图视图中包含串联依赖链（如 `A -> B -> C -> D`）与多分支枢纽节点，**When** 系统自动计算组内（或无分组视图内）的二维网格槽位，**Then** 串联节点沿左右与上下相邻格连续排布（换行处直接向下衔接呈 S 型折行，不产生从上一行最右端斜跨至下一行最左端的长斜线），多连线枢纽优先落入网格中间槽位以将连线分摊至上、下、左、右四向端口，且避免将有直接连线的两端排在同行第 1、3 列或同列第 1、3 行而中间夹着无关节点。
2. **Given** 视图中的关系包含合法的知识循环或无连线的孤立节点，**When** 系统执行二维网格槽位优选计算，**Then** 系统以确定性规则在有限步内完成槽位分配，不会陷入死循环，成环节点聚拢在相邻格位，孤立节点平整排放在剩余槽位。
3. **Given** 某分组内仅包含 1 至 2 个节点，或视图包含多个分组，**When** 系统计算分组背景框尺寸与顶栏可用排列模式，**Then** 分组外框根据组内实际占用的节点包络与固定内边距紧凑包裹（不再强制撑出 `1058px` 最小宽度），且顶栏排列模式仅在 `vertical`（单列纵向）与 `grid`（双列田字，分组数 ≥ 2 时可用）之间切换，不再出现 `columns`（多列）模式。
4. **Given** 工作区中某张既有导图的视图已保存过 `layout.json`，**When** 用户直接打开该导图或仅修改节点文字内容，**Then** 所有已存节点坐标与分组外框保持原样不变；仅在新建导图、视图缺少布局、为新增未定位节点补齐空位，或用户主动点击“重置排列 / 切换排列模式”时，才应用新的二维邻接排版与紧凑分组框。
5. **Given** 两点之间的连线路径上仍存在其他非端点节点卡片阻挡，**When** 画布渲染关系连线，**Then** 连线在保留 HTML v17 三次贝塞尔曲线与端口投影过渡动画的前提下，自动将曲线控制点向阻挡卡片外侧通道偏移绕弧，避开卡片文字主体区域。

### User Story 2 - 高信号、无伪连线的 AI 导图生成质量控制 (Priority: P1)

用户通过 `/mindmap` 让 AI 根据材料或主题生成、扩展思维导图时，生成的节点摘要与正文直接写清职责边界、触发条件或可观察的检验标准，不再充斥“了解 XX / 理解原理 / 负责相关处理”等空洞套话；节点之间的连线严格反映真实依赖或有价值的补充对比，不再为了“凑成单一根节点”或“把图连满”而编造虚假的先后连线，且给出清晰的覆盖范围与推荐阅读起点。

**Why this priority**: AI 生成内容的结构真实性与信息密度是思维导图的核心价值；消除伪连线与空话套话能直接提升所有新建与修改导图的可用性，且无需破坏现有存储格式。

**Independent Test**: 使用架构设计、业务流程和学科知识三类主题分别调用 `/mindmap` 生成导图，检查产出的结构与笔记：无为了凑单根而硬连的虚假 `dependency`，每个入度为 0 的起始节点均有独立存在依据，节点摘要与正文无空洞口号，且根视图与完成反馈明确说明覆盖边界与阅读入口。

**Acceptance Scenarios**:

1. **Given** 用户提供包含多个并列模块或外部前置概念的材料要求建图，**When** AI 组织视图关系并提交创建，**Then** AI 会逐个核对无前置节点的合理性（确属独立入口或前置在范围外），保留多个合法的起始节点，绝不为了凑成“唯一根节点”而强行在并列节点间编造 `dependency` 连线。
2. **Given** 用户要求生成架构图、流程图或知识学习图，**When** AI 编写节点 `summary` 与 Markdown 正文，**Then** 内容遵循去虚词的质量判据（架构写明职责与上下游约束、流程写明输入条件与分支产出、学习写明核心机制边界与可检验的掌握标准），不出现“了解/掌握/相关处理”等不可检验的空泛表述。
3. **Given** 用户围绕较大主题发起建图请求，**When** AI 完成导图生成并向用户反馈，**Then** 明确交待本图覆盖的范围边界（含刻意未纳入的外部范围）以及推荐的默认阅读起点节点，且不会因为 AI 生成了解释就把任何待核实或待掌握内容伪造成既成事实。

### User Story 3 - 可独立拆分的节点详情前后关系跳转与画布焦点联动操控 (Priority: P2)

用户在侧栏中选中某个节点或打开节点详情面板阅读笔记时，画布自动突出显示与该节点直接相连的前置入边和后续出边、淡化无关连线以降低视觉噪音；用户可以直接在详情面板中看到当前视图内与该节点直接相连的“前置依赖”、“后续节点”与“补充关联”快捷胶囊，点击任意胶囊即可在当前视图内一键切换到目标节点的详情并将画布视角平滑居中到该节点；用户还可以单独收起详情面板而在画布上保留当前节点的高亮选中态。该详情胶囊与选中解耦层采用高度模块化设计，支持在人工验收后按需独立调整或回退。

**Why this priority**: 在 360px～480px 的窄侧栏中，详情面板打开后会遮挡部分画布；提供详情内同层关系直跳与画布焦点连线降噪能显著减少“关详情 → 找线 → 拖画布 → 再点开详情”的往返操作成本，同时模块化隔离确保核心排版与提示词成果不受交互微调影响。

**Independent Test**: 打开一张包含多条交错关系的导图，单击任意无子图节点打开详情：验证画布上直接关联边高亮、无关边淡化；点击详情面板中的前置或后续节点胶囊（含带有 `childViewId` 的相邻节点）可在当前视图内同步切换详情并让画布平滑居中到目标节点（不触发跨视图下钻）；点击详情关闭按钮后画布仍保留该节点的选中与连线高亮，再次点击该节点重新展开详情，点击画布空白处才清除选中。

**Acceptance Scenarios**:

1. **Given** 用户打开了某节点的详情面板，且该节点在当前视图（`view.relationIds`）中存在直接相连的前置依赖、后续节点或补充关联节点，**When** 详情面板渲染完成，**Then** 面板中清晰展示按关系角色区分的可点击节点胶囊；点击任一胶囊（无论目标节点是否带有 `childViewId`）均在当前视图内将画布相机平滑定位并选中该目标节点，同时将详情面板切换至该目标节点的详情笔记。
2. **Given** 当前视图中存在多条关系连线，**When** 用户在画布上选中某节点或打开其详情面板，**Then** 与该选中节点直接相连的入边和出边保持清晰高亮（并可直观区分前置入边与后续出边），视图中其余不直接相连的边自动降低视觉权重，避免线条交织干扰阅读。
3. **Given** 用户正在阅读某节点详情并希望对照画布查看该节点的全图连线上下文，**When** 用户点击详情面板关闭按钮（或按一次 `Escape`），**Then** 详情面板收起但画布继续保留该节点的选中状态与关联连线高亮；在详情已收起时，再次单击该已选中无子图节点重新展开详情，点击画布空白区域（或再按一次 `Escape`）才彻底清除节点选中态并恢复全图连线默认显示。

### Edge Cases

- **存在环路、高密度连线或全孤立节点的二维网格排布**: 当组内节点存在循环依赖（如 `A -> B -> A`）、网状多对多连接或完全无连线时，二维网格槽位分配算法必须在确定性的有限步内收敛（无连线时保持原有从左到右顺序，有连线时按固定权重对邻接距离、夹心穿卡惩罚与流向偏向评分），不得出现死循环或随机跳变。
- **既有 `layout.json` 中曾保存 `mode: "columns"` 的历史兼容**: 当打开旧版保存过 `mode: "columns"` 的 `layout.json` 时，读取与校验层应平滑兼容（不报错拒绝打开，保留已有节点坐标；当用户切换或重置排列时自动归入 `grid` 或 `vertical`）。
- **详情胶囊目标节点带有 `childViewId` 或无独立笔记正文**: 当用户在详情面板中点击一个带有子图（`childViewId`）或尚无 Markdown 正文的相邻节点胶囊时，系统仍在当前视图居中选中该节点并切换详情面板显示该节点标题/摘要/空笔记状态（及它的相邻关系胶囊），不误触发跨视图子图下钻。
- **窄侧栏（360px）下的详情与画布联动居中**: 当详情面板处于展开状态时，点击关系胶囊触发的画布居中计算应考虑可视画布区域，使目标节点在未被遮挡的可视区域或画布视口内平滑居中。
- **离线 HTML 导出的一致性**: 导出后的离线单文件 HTML 在二维邻接排版、紧凑分组框、贝塞尔绕弧避让、选中节点的连线焦点高亮以及详情面板内的前后关系胶囊跳转上，必须与宿主侧栏保持一致的阅读与交互体验。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 自动布局与重置排列功能（`fillLayout` 与 `relayoutView`）MUST 在组内（及无分组区域）采用契合四向动态端口的**二维网格邻接排布算法**：在最大 3 列的紧凑网格中，基于视图内关系将相连节点优先分配在左右或上下相邻格位（连续长链采用 S 型蛇形折行以消除跨行回车大斜线，多连线枢纽优先置于内部格位以向四向端口分散连线，对同行第 1/3 列或同列第 1/3 行的夹心穿卡施加避让惩罚，并保持上游偏左上、下游偏右下的自然流向偏向）；遇到环路或孤立节点时 MUST 以确定性顺序稳定收敛。
- **FR-002**: 分组（`Group`）外框尺寸 MUST 根据组内实际节点包络与固定内边距紧凑计算，移除硬编码的 `1058px` 最小宽度限制；顶栏与布局的排列模式 MUST 移除冗余的 `columns`（≥7 组多列）模式，仅保留 `vertical`（单列纵向）与 `grid`（双列田字，分组区域数 ≥ 2 时可用），并对旧 `layout.json` 中可能遗留的 `"columns"` 字段值保持向后兼容读取。
- **FR-003**: 自动排版的升级 MUST 严格遵守既有布局保护原则：对于已有 `layout.json` 的视图，打开时完全保留已保存的节点坐标与分组外框，不得静默重排既有视图；仅在新建导图、视图尚无已存布局、为新增未定位节点补齐初始空位，或用户主动点击“重置排列 / 切换排列模式”时，才应用新的二维网格邻接排版与紧凑分组框计算。
- **FR-004**: 关系连线几何计算 MUST 保持 HTML v17 基准的三次贝塞尔曲线与现有端口投影过渡动画；当检测到连线穿过中间非端点节点卡片的矩形区域时，MUST 将贝塞尔控制点向阻挡卡片外侧间隙偏移绕弧以避让卡片文字区域，未受阻挡的连线保持原有曲线轨迹。
- **FR-005**: 内嵌的 `/mindmap` 运行时生成与修改提示词 MUST 补充通用导图质量约束：要求模型在建图和扩图时逐一核查无前置节点的合理性（严禁为凑唯一根节点或填满画布而编造虚假 `dependency`）、按主题类型（架构/流程/学习）遵循去虚词的可检验写作标准，并在交付时说明导图覆盖范围边界与推荐阅读起点。
- **FR-006**: 节点详情面板（`NoteInspector`）MUST 基于当前视图可见的关系数据（`view.relationIds`）展示当前节点的直接前置依赖、直接后续节点与补充关联节点快捷跳转胶囊；用户点击任一胶囊时，系统 MUST 在当前视图内将画布相机平滑定位并选中该目标节点，同时将详情面板切换至该目标节点的详情笔记（即便目标节点带有关联子图 `childViewId`，也不触发跨视图下钻）。该关系胶囊模块 MUST 与核心笔记渲染、编辑会话及自动布局逻辑完全解耦，确保在人工验收后如需打回可独立移除或回退而不影响其他功能。
- **FR-007**: 画布场景（`MapScene`）在存在当前选中节点时 MUST 启用关系焦点高亮模式：突出显示与选中节点直接相连的入边与出边（区分前置依赖与后续/补充视觉层次），并降低当前视图内其余非直接关联连线的视觉透明度。
- **FR-008**: 侧栏详情面板的“收起详情”操作与画布的“取消节点选中”操作 MUST 解耦且保持原有卡片单击直觉：单击无子图节点时同时选中并打开详情（单击有子图节点仍进入子图）；关闭详情面板（或按一次 `Escape`）仅收起面板而保留画布上的当前节点选中态与关联连线高亮；在详情已收起状态下，再次点击该已选中无子图节点重新展开详情，点击画布空白处（或再按一次 `Escape`）才彻底清除选中态；该交互层同样 MUST 保持独立可拆分以便单独回退。
- **FR-009**: 本次二维邻接排版、紧凑分组框、贝塞尔绕弧避让、连线焦点高亮及详情内前后节点胶囊跳转改动 MUST 在离线导出的独立 HTML 阅读器中同步生效，且不得引入任何新的外部重型图形库或改动现有 `map.json` 核心必填存储契约。

### Key Entities

- **四向邻接网格槽位（4-Port Grid Adjacency Slot）**: 分组或视图内部最大 3 列的二维网格坐标槽位，结合四向动态端口特性，通过邻接距离、夹心穿卡惩罚、枢纽居中度与流向偏向确定每个节点的最佳落位。
- **关系焦点状态（Relation Focus State）**: 当前选中节点在画布中触发的关联边分类状态（直接前置入边、直接后续出边、直接补充关联边、非关联背景边）及与详情面板展开/收起相互独立的画布选中态。
- **同层关系导航胶囊（In-View Neighbor Pill）**: 节点详情面板中可独立拆分的关联跳转组件，展示当前视图（`view.relationIds`）内直接相连的前置、后续与补充节点，点击后触发同层画布居中与详情切换。
- **生成质量判据（Authoring Quality Criteria）**: `/mindmap` 技能提示词中用于约束 AI 建图质量的规则集合，涵盖起始节点独立性自检、跨主题去虚词写法正反例、范围边界声明与默认阅读入口。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在包含 6～20 个节点（含串联长链、分叉枢纽与跨步关系）的标准测试导图中，执行自动布局或重置排列后，相比原按数组下标盲填的 3 列网格，相连节点的平均连线长度与跨行大斜线数量减少 **50% 以上**，同行/同列直接夹心穿卡（结合贝塞尔绕弧避让后）降至 **0**。
- **SC-002**: 对于仅包含 1～2 个节点的分组，自动生成的分组外框宽度相比原硬编码 `1058px` 最小宽度缩减 **50% 以上**，紧贴组内节点实际列宽加上标准内边距；既有保存过 `layout.json` 的导图在直接打开时坐标保持率 **100%**。
- **SC-003**: 在节点详情面板中，用户从当前节点跳转到当前视图内任意直接前置或后续节点并完成画布定位所需的操作步数从原来的“关闭/移开详情 → 查找连线 → 点击目标节点”（3 步）缩短为 **1 次点击**，且响应过渡在 0.5 秒内完成。
- **SC-004**: 选中任意包含上下游关系的节点时，画布直接关联边与非关联背景边的视觉对比度清晰可辨，收起详情面板后画布选中高亮 100% 保持，点击画布空白处后 100% 恢复全图默认态；且详情关系胶囊与选中解耦模块可在不动排版和提示词代码的前提下独立拆分回退。
- **SC-005**: 通过更新后的 `/mindmap` 提示词在架构、流程、学习三类场景下的验收用例中，不出现为凑单一根节点而编造的虚假依赖边，节点摘要与正文不出现“了解/掌握/相关处理”等空泛占位词，且离线 HTML 导出 100% 同步具备新排版与详情跳转能力。

## Assumptions

- **保持通用思维导图定位与纯画布收敛**: 本次明确不引入课程通关式的“节点点亮进度条、前置解锁就绪度计算、学习计划排期”，不照搬画布内可折叠小组卡片，也不额外新增“线性大纲阅读视图”，专注把画布内的四向邻接排版、紧凑分组框、提示词质量与详情关系操控做好。
- **零 `map.json` Schema 破坏与 `layout.json` 向后兼容**: 所有自动排版、贝塞尔绕弧避让、详情关系胶囊和连线焦点高亮均基于现有 `map.json` 与原生 DOM/SVG 实现；`layout.json` 移除新建 `columns` 模式但对历史文件中的 `"columns"` 值保持兼容读取。
- **作用边界遵循项目宪章**: 内容与布局继续严格分离，AI 模型仍只输出知识结构与 Markdown 正文，不计算或输出任何坐标。
