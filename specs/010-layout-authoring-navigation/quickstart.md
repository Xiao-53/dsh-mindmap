# Quickstart & Validation Guide: 导图四向邻接排版、生成质量与详情关系操控优化

**Feature**: `010-layout-authoring-navigation` | **Date**: 2026-11-22

## 1. 自动化编译与回归测试（本地工程核验）

在仓库根目录执行以下命令，验证类型、排版算法、贝塞尔绕弧避让、提示词契约、详情关系胶囊与选中解耦逻辑及打包产物：

```powershell
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
npm.cmd run pack:plugin -- --dry-run
```

### 自动化测试重点检查项
1. **四向邻接二维网格排版（`tests/shared/layout.test.ts`）**：
   - 串联长链（如 `A -> B -> C -> D -> E -> F`）在 3 列网格中呈 S 型蛇形连续相邻折行（`C(0,2) -> D(1,2)` 垂直相邻），不再出现从 `(0,2)` 跨到 `(1,0)` 的长斜线；
   - 多分支枢纽节点（连接 $\ge 3$ 个节点）自动落入内部槽位（如 `col === 1`），使连线分散到多侧端口；
   - 消除同行 `(r,0) <-> (r,2)` 或同列 `(0,c) <-> (2,c)` 中间夹着无关第三节点的夹心穿卡；
   - 1～2 个节点的分组外框宽度紧凑包裹（1 节点组宽 `284px`、2 节点组宽 `611px`），不再硬编码 `1058px`；
   - 既有保存过 `layout.json` 的视图通过 `fillLayout` 加载时，已存节点坐标与分组外框 100% 保持原样；历史含 `mode: "columns"` 的 `layout.json` 校验通过且重排时平滑归一；`availableModes` 不再返回 `'columns'`。
2. **贝塞尔穿卡绕弧避让（`tests/shared/edge-geometry.test.ts`）**：
   - 当两点间存在中间阻挡卡片时，`connectionGeometry` 输出的贝塞尔控制点向阻挡卡片外侧法向偏移，曲线中点不再落入阻挡卡片核心矩形内；无阻挡时曲线与原公式完全一致。
3. **详情关系胶囊、连线焦点高亮与选中解耦（`tests/integration/dom.test.ts`）**：
   - 打开节点详情时，`NeighborPills` 准确展示当前视图 `view.relationIds` 内的前置依赖、后续节点与补充关联胶囊；
   - 点击任一胶囊（含带有 `childViewId` 的相邻节点）在当前视图内切换详情并更新相机居中，不触发跨视图子图下钻；
   - 选中节点时，直接相连的入边/出边带 `data-focus="in" | "out" | "supplement"` 高亮，其余边带 `data-focus="dimmed"` 降噪；
   - 点击详情面板关闭按钮（或按一次 `Escape`）后详情收起，但画布节点选中与关联边高亮保留；再点画布空白处（或再按一次 `Escape`）彻底清除选中；
   - 离线 HTML 导出（`export-html.ts` / `offline.tsx`）同步具备相同排版、高亮与关系胶囊跳转能力。

## 2. DSH Desktop 真机人工验收步骤

> 按项目约定，日常开发改动完成后不自行启动浏览器视觉验收，由用户在 DSH Desktop 真机与离线 HTML 中按以下步骤人工确认（若需单独打回“详情关系胶囊 / 收起详情保留选中高亮”，可独立拆分回退）：

1. **验收既有导图兼容性與主动重置排版**：
   - 在 DSH 侧栏打开一张升级前已保存过 `layout.json` 的老导图，确认初始画面坐标与分组框保持不变；
   - 点击顶栏“重置排列”或“切换排列”按钮（确认仅在“纵向”与“田字型”间切换，无“多列”），观察小分组框是否紧贴节点收缩、相连节点是否就近排在上下/左右相邻格、跨卡连线是否平滑向卡片外侧绕弧。
2. **验收 `/mindmap` 新建导图质量与初始排版**：
   - 在输入框使用 `/mindmap` 围绕某个架构或流程主题新建导图，检查：
     - 初始自动生成的画面是否按四向邻接紧凑排布、无莫名其妙的跨屏大斜线或 `1058px` 大空框；
     - AI 是否保留了合理的并列入口节点（未强行编造单根假 `dependency`），节点摘要与正文是否具体可检验（无“了解/掌握/相关处理”等空话），并在回复中说明了覆盖边界与推荐阅读起点。
3. **验收节点详情关系胶囊与连线焦点高亮（可拆分模块）**：
   - 单击某个有多条连线的节点打开详情：观察画布上与该节点直接相连的前置入边、后续出边是否高亮突出，其余无关连线是否淡化降噪；
   - 在详情面板中点击“前置依赖”或“后续节点”胶囊（特别是尝试点击一个本身带有子图入口图标的相邻节点胶囊）：确认画布在当前视图内平滑居中到该节点且详情面板直接切换为该节点笔记，不会突然跳进子图；
   - 点击详情面板右上角 `×`（或按一次 `Escape`）收起详情：确认详情面板关闭后，画布上该节点及直接关联连线依然保持高亮；随后点击画布空白处（或再按一次 `Escape`），确认高亮清除、全图连线恢复常态；
   - 导出离线 HTML 并在浏览器打开，确认上述排版、连线高亮和详情胶囊跳转同样正常工作。
