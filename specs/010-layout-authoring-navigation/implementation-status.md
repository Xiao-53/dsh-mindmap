## 人工验收重点

1. 打开旧图，确认节点和组框不变；主动重排后检查 1/2 节点组宽、六节点链换行与枢纽位置；顶栏仅纵向/田字型。
2. 拖动节点造成中间卡片阻挡（尤其长跨度连线经过多张卡片、且带有关系名称标签时），检查三段绕弧平滑度、箭头、端口动画以及连线中央小字是否跟随曲线移动；密集图及高卡片重点观察。避让使用二十个采样点、有限偏移候选集，不保证任意重叠/密集布局完全无穿卡；性能目标尚未测量。
3. 详情胶囊仅展示当前视图直接关系；点击带子图的邻居仍在原视图切详情，检查缩放是否为“适配缩放 + 10%”，以及宽/窄侧栏下的居中视野是否合适。
4. 关闭详情或按一次 Escape 后保留高亮；再次单击叶节点重新展开；空白轻点或第二次 Escape 清除；平移拖拽不清除。编辑未保存时应先走保存保护。
5. 用架构、流程、知识主题调用 /mindmap，检查真实生成质量与交付边界说明。
6. 导出 HTML，离线复核关系胶囊、焦点高亮、主题和详情关闭行为。
