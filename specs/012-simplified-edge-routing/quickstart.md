## 1. 自动化编译与单元测试核验（本地工程验证）

> 按项目约定（`AGENTS.md`），日常开发默认仅运行静态类型检查、构建与打包预检并在交付时标注未验证项；`npm.cmd run test` 仅在用户明确授权执行自动化测试时运行。

在仓库根目录按授权范围执行以下命令，验证类型检查、构建、插件打包产物及（经用户明确授权时的）单元测试与 DOM 集成回归：

```powershell
# 日常默认执行的静态检查、构建与打包核验
npm.cmd run typecheck
npm.cmd run build
npm.cmd run pack:plugin -- --dry-run

# 仅在用户明确授权运行自动化测试时执行
npm.cmd run test
```

### 自动化验证对照要点（引用 [contracts/edge-routing.md](contracts/edge-routing.md) 与 [data-model.md](data-model.md)）
1. **该直则直（`SC-001`）**：
   - `tests/shared/edge-routing.test.ts` 验证 ≥ 12 组同排高度不一串联、多端口对单端口、16px 容差小错位直连全部生成纯直线 `M.. L..` 且箭头与直线方向严格共线。
2. **受控曲线与允许穿底（`SC-002`）**：
   - `tests/shared/edge-routing.test.ts` 与 `tests/shared/prototype-parity.test.ts` 验证 ≥ 15 组跨行/跨列/远距/反向/穿卡斜连与自环均保持单段受控曲线（0 条多段波浪），非直线端口切向与法线误差 `< 0.01°`。
3. **隔卡拱桥与仅单击选中提层（`SC-003`）**：
   - 验证同排/同列正面直挡转为同侧平滑单弧拱桥越过中间卡；
   - `tests/integration/dom.test.ts` 验证常规状态下连线位于 `.edges-base`，仅当节点被单击选中时生成 `.edges-focus` 将直接关联连线与 `.edge-pill.is-focused` 提至卡片之上（悬停不触发提层）。
4. **关系胶囊避卡与短边兜底（`SC-004`）**：
   - 验证常规带标签边胶囊自动沿 7 个探测点避开卡片（$\ge 95\%$ 无压卡），极短间距边居中回退不飞离连线，HTML 胶囊携带截断类与完整 `title`。
5. **大图流畅性、零崩溃与双端一致（`SC-005`, `SC-006`）**：
   - 验证 40 节点 / 60+ 边连续路由耗时、隔卡临界拖过切换次数 $\le 1$、零尺寸/重叠边界零 `NaN`、零修改节点坐标及离线导出 HTML 完整渲染。

## 2. DSH Desktop 真机与离线 HTML 人工验收步骤

> 日常开发构建完成后，视觉与交互手感由用户在 DSH Desktop 真机（浅色/深色主题）及导出的独立离线 HTML 阅读页中按以下 6 项人工确认：

1. **同排直连与高矮/多端口对齐（`US1`）**：
   - 打开包含同排高矮不一串联卡片（例如 2 行连 3～4 行卡片）、以及一侧挂有 2 条边对接另一侧 1 条边的导图；
   - 确认同一排串联水平线处于同一平直高度、多对一邻边拉成水平直线，彻底消除小 S 弯；轻微错位的多对多面对面直连顺畅拉直且箭头与直线方向自然一致无折角。
2. **跨行/跨列曲线弧度与穿底观感（`US1`）**：
   - 观察跨行、跨列和跨多列长距离连线：确认弧度温和克制、无远距大鼓包、无深 U/过山车波浪，途中经过无关卡片时平稳从卡片下层穿过。
3. **同排/同列隔卡拱桥（`US2`）**：
   - 查看或拖出“同排/同列三张卡片首尾直连且中间卡正挡通道”的场景：确认自动从顶/底（或左/右）形成舒展对称单弧拱桥跨过中间卡，普通斜边则不变。
4. **单击选中提层高亮（`US2` / Q1）**：
   - 鼠标在画布卡片、连线和胶囊上自由晃动：确认画面保持冷静，不发生任何连线跳层闪烁；
   - 单击选中任意节点：确认直接相连的传入/传出/补充连线立刻浮现到卡片上方高亮看清穿底脉络，其余线淡化留底；点击空白处取消选中后立刻恢复底层。
5. **关系胶囊节点避卡与短边截断（`US3`）**：
   - 在浅色与深色主题下检查带文字的关系胶囊：确认悬浮于卡片之上，自动沿曲线避开邻近卡片；在间距极短的上下两卡连线上，胶囊居中收束、超长字省略且鼠标悬停可看到完整文字；选中节点时胶囊高亮/淡化联动正确。
6. **40 节点拖拽流畅度、旧布局保护与离线导出（`US3` / `FR-011` / `FR-012`）**：
   - 在较复杂导图内按住节点快速连续拖拽 30 秒并反复跨过隔卡拱桥临界区：确认全程跟手顺滑、零卡顿、零崩溃、零来回闪边；
   - 打开历史已保存 `layout.json` 的导图并导出独立离线 HTML 阅读页，对比确认节点坐标 100% 保持原样且双端呈现完全一致。
