# Feature Specification: 简化节点连线路由、焦点提层与自适应关系胶囊标签

**Feature Branch**: `main`（沿用当前工作分支）
**Created**: 2026-11-23
**Status**: Draft
**Input**: User description: "放弃全局多卡避让，简化连线判定逻辑：允许连线部分从卡片下方穿过，做到该直的地方直、该弯的地方弯，仅保留轻量同排/同列隔卡直连避让；新增选中节点关联边提层高亮，并将固定在连线中点的关系文字升级为可根据节点与连线位置自动避卡移动的小胶囊节点。"

## Clarifications

### Session 2026-11-23

- Q: 当连线允许常态从无关卡片下方穿过时，除“单击选中节点”外，鼠标悬停在卡片或连线/胶囊上时是否也要临时将连线提层到卡片上方高亮？ → A: 仅单击选中节点时将直接关联的连线与胶囊提层至卡片上方高亮（Option A），悬停卡片或连线/胶囊不触发提层；取消选中后恢复底层。
- Q: 当同一排相邻卡片因正文行数不同而高度不一（例如 2 行卡片连向 3～4 行卡片，且串联多张卡片）时，左右侧单端口的默认高度基准应采用哪种方式？ → A: 左右侧单端口统一采用距卡片顶部固定基准高度（约标准卡片中线）（Option A）；同排串联即使卡片高矮不一也保持同一水平直线，遇一侧多端口时对侧单端口自动投影对齐。
- Q: 当面对面相连的两张卡片两侧都挂有多个端口（无法通过单端口投影对齐）且存在小幅错位、触发“小错位拉直”时，直线与目标箭头的衔接应采用哪种呈现？ → A: 小错位拉成干净斜直线，箭头方向顺沿斜直线自然微调对准输入圆外沿（Option A），兼顾零 S 弯与零箭头折角。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 该直则直、该弯克制、允许穿底的简洁连线呈现 (Priority: P1)

用户在思维导图画布上阅读各类关系（包括同排或同列相邻卡片、高度不一的对齐卡片、斜向错位卡片及跨分组远距离卡片）时，应当直连的位置干净笔直，需要转弯的位置自然顺滑、弧度克制。同排或同列相邻卡片不会因为正文行数不同导致高度相差十余单位，或一侧挂有多个端口而另一侧仅有一个端口，就莫名拧出弯曲的小 S 形起伏。面对跨行、跨列及远距离斜连线，连线从起点输出圆点垂直卡片边缘引出、垂直对准终点箭头顺滑汇入，采用单段受控弧度的温和曲线连接；当路径途中经过其他无关卡片时，不再强行绕出夸张的深 U 或多段波浪，而是允许连线自然平稳地从无关卡片下方穿过。卡片指向自身的自环同样以独立圆润的小回环清晰呈现。

**Why this priority**: 先解决当前画布中“该直的地方弯”、“过度避让产生畸变大弯”与“复杂重计算导致卡顿崩溃”三大核心痛点，才能恢复整个知识导图简洁清晰的视觉秩序与基础流畅度。

**Independent Test**: 构造覆盖“同排高度不等相邻卡片”、“一侧双端口对接对侧单端口”、“面对面微错位相邻卡片”、“跨行跨列斜向与长距离连线”、“途中被无关卡片局部遮挡的斜连线”以及“自环连线”的标准视图，逐项核查：对齐与微错位相邻边 100% 呈干净直线，跨行跨列曲线单段顺滑、端口与箭头无折角且无大鼓包，跨卡斜线直接穿底而不产生多段波浪，自环清晰独立不压字。

**Acceptance Scenarios**:

1. **Given** 两张同排相邻卡片因正文行数不同而高度不一（含连续串联多张高矮卡片），或一侧边缘挂接多个连接端口而对端边缘仅有一个连接端口，**When** 画布计算并渲染两者之间的直连关系，**Then** 左右侧单端口默认统一锚定在距卡片顶部固定基准高度（约标准卡片中线，使整排高矮卡串联共享同一水平主干线），若遇一侧多端口或垂直/水平偏移，对端单端口沿连线轴向自动投影对齐源端口位置（同时保持在卡片边缘安全内边距内），使连线保持干脆笔直的直线，不拧出小 S 形曲线。
2. **Given** 面对面相连的两张卡片两侧端口均已固定且存在小幅错位（落入直线拉直容差范围内），**When** 画布渲染该连线，**Then** 连线直接以干净斜直线连接两端，且目标箭头顺沿该直线的方向自然微调并停靠输入圆外沿，既不强行弯折出两个反曲小 S 弯，也不产生箭头根部折角。
3. **Given** 两张卡片处于跨行、跨列、远距离或反向回环位置，且连线途中经过其他无关卡片，**When** 画布渲染该曲线连线，**Then** 连线在起点输出圆点与终点箭头处保持垂直卡片边缘顺滑衔接，中段采用弧度受控的温和单段曲线过渡并允许局部从无关卡片下方穿过，不产生多段连续蛇形绕行、深 U 扭曲或远距夸张大鼓包。
4. **Given** 一张节点卡片存在指向自身的自环关系，**When** 画布渲染自环连线，**Then** 自环在卡片外侧形成清晰圆润的独立回环，输出空心圆与输入实心圆分离可辨，箭头指向准确且不遮挡卡片文字内容。

### User Story 2 - 轻量同排/同列隔卡直连拱桥与选中提层高亮 (Priority: P1)

当两张位于同一排或同一列的节点卡片相隔中间卡片直连（例如同排三张卡片首尾相连），且中间卡片从正面完全堵住两者直连通道时，连线不再直接穿过中间卡片正心导致方向模糊，而是轻量切换至同侧边缘（如顶边对顶边、底边对底边，或左边对左边、右边对右边），以一条对称舒展的平滑拱桥跨过中间卡片；而普通斜向连接与非正面堵死的场景保持既有四向动态选边和穿底策略，绝不触发多余换边。平时未选中节点时，所有连线位于卡片下层以保证画布清爽；当用户单击选中任意一张节点卡片时，与该节点直接关联的全部连线（传入、传出与补充关系）立即提层至卡片上方高亮呈现，让局部穿底的脉络一目了然，其余无关连线同步淡化退居底层；取消选中后立即恢复常态层级。

**Why this priority**: 允许一般连线穿底渲染后，“同排/同列隔卡直连拱桥”能防止最常见的三卡同排直连彻底藏在中间卡正下方看不出起止；“选中提层高亮”则让用户在需要追踪某张卡片的关联脉络时，能够零干扰地看清每一条穿底连线的完整去向。

**Independent Test**: 在包含“同排三卡首尾直连”、“同列三卡首尾直连”、“普通斜向穿底连线”及“点击选中节点/取消选中”的视图中逐一验证：仅正面被整卡完全直挡的同排/同列边转为同侧平滑拱桥越过中间卡；选中任意节点时其全部关联边完整浮升到所有卡片之上高亮显示，取消选中后即时退回卡片下层。

**Acceptance Scenarios**:

1. **Given** 两张同排或同列的卡片以面对面方式相连，且两者之间存在一张中间卡片从正面直接阻挡直连路径，**When** 画布计算端口与连线几何，**Then** 连线自动改走两卡同一侧边缘（如顶对顶、底对底，或左对左、右对右）并平滑滑动端口形成单段对称拱弧跨过中间卡片；而一般斜向穿底边或仅擦碰卡片边缘的连线维持原有端口方向不变。
2. **Given** 用户未选中任何节点卡片（即使鼠标在卡片、连线或胶囊上方悬停移动），**When** 浏览包含跨卡连线的导图画布，**Then** 所有连线保持在卡片层下方不跳层，途经无关卡片区域时自然被卡片背景遮挡，画布维持低视觉噪点的整洁观感。
3. **Given** 用户在画布上单击选中某张节点卡片，**When** 画布进入节点焦点状态，**Then** 仅在该节点被选中时，与其直接相连的所有传入、传出主要连线及补充关联虚线（连同关联胶囊）全部浮升至节点卡片上方并以高亮样式完整呈现，同时非关联连线显著淡化并留在底层；当用户取消选中该节点时，所有连线立即恢复原有层级与常规透明度。

### User Story 3 - 沿线自动避卡滑动的关系胶囊标签与丝滑交互稳定性 (Priority: P2)

带有名称文字的关系连线不再把纯文字死板固定在路径正中，而是升级为悬浮在卡片上方（端口圆点下方）的小巧圆角胶囊节点，在浅色与深色暖纸主题下均保持清晰背景与柔和边框，并跟随所属连线的焦点高亮或淡化状态同步变换视觉权重。系统会根据节点卡片当前位置与连线实际弯曲形态，沿曲线从中间向两侧可读弧段自动移动胶囊，优先停靠在不遮挡任何卡片的空隙位置；当整条连线极短、没有完全避开卡片的位置时，胶囊稳妥居中留在连线上，并对超长文字进行截断省略、鼠标悬停时显示完整关系名称。用户连续拖拽卡片穿过其他连线或卡片中线时，画布全程跟手流畅、无明显卡顿、不崩溃，临界换边处具备稳定缓冲防闪烁，且原有已保存布局与离线导出阅读页完全一致。

**Why this priority**: 将中点固定纯文字改为可沿曲线自动避卡移动的小胶囊节点，能彻底消除卡片切字与短线糊字问题；同时极简确定性计算与丝滑拖拽体验直接保证了大视图下的稳定性与交互品质。

**Independent Test**: 在包含多种长度关系标签的视图及 40 节点、60 条以上连线的复杂视图中测试：核查浅色/深色主题与选中高亮下胶囊样式同步联动、普通长度绕跨边胶囊自动避开卡片压盖、极短边胶囊居中截断并可悬停查看全文；持续鼠标拖拽卡片 30 秒以上验证零崩溃、跟手流畅、无临界高频闪烁，并验证历史布局坐标未变及离线导出页面一致性。

**Acceptance Scenarios**:

1. **Given** 视图中存在带有名称文字的关系连线，**When** 画布渲染连线与标签，**Then** 关系文字以圆角胶囊节点展示在卡片层之上、端口圆点之下，适配浅色与深色主题暖纸配色；当用户选中关联节点触发高亮或淡化时，对应胶囊的边框、文字及整体透明度同步响应。
2. **Given** 某条带名称连线的中点恰好被其他节点卡片遮挡，或用户移动卡片改变了连线形状，**When** 视图重算连线与胶囊位置，**Then** 胶囊沿着曲线优先从中间向两侧自动寻找不压盖任何卡片的位置实时滑动避让；若连线极短导致全部候选位置都紧邻或接触卡片，则胶囊稳妥居中停留在线上，超长文本以省略号收束并在悬停时提示完整文字，绝不飞离所属连线。
3. **Given** 用户在包含 40 个节点与 60 条以上连线的复杂视图中按住节点连续拖动并穿过其他卡片与连线临界区，**When** 节点坐标持续高频变化，**Then** 交互全程响应丝滑流畅、不卡顿不崩溃，端口圆点、连线路径与胶囊位置严密同步随动，且同排/同列隔卡拱桥在临界位置具备稳定防闪烁缓冲。
4. **Given** 用户打开历史已保存布局的导图，或将其导出为可离线阅读的独立 HTML 页面，**When** 在宿主桌面侧栏（浅色/深色主题）和独立离线阅读页中对比查看同一视图，**Then** 既有节点与分组位置 100% 保持原样不变，且两端的直线、拱桥、穿底曲线、提层高亮与关系胶囊显示完全一致。

### Edge Cases

- **零间距或相互重叠的卡片**: 当两张相连卡片被手动拖至边缘几乎相贴或部分重叠时，连线仍保持有限闭合几何形态且不出现反向尖刺、无限大曲率或页面崩溃，胶囊稳妥定位且不报错。
- **同排高度差异悬殊的卡片**: 当同一水平排内同时存在简短单行卡与多行高摘要卡时，单端口投影对齐优先保证在双方共同覆盖的安全高度范围内拉直，若两卡垂直完全错开无重叠才平滑过渡为曲线。
- **单侧高连接度节点与双向多关系**: 当单张卡片某一边挂接 4 条及以上连线，或两张卡片间同时存在往返双向及多条并行关系时，同侧端口保持不交叉排列与合理间距，双向或并行连线及各自胶囊互相可分辨且不完全重合。
- **极短连线配超长标签**: 当两卡间隔极窄且关系名称较长时，胶囊限制合理最大宽度并以省略号截断、悬停展示完整名称，避免横向撑爆挤压相邻卡片标题。
- **跨分组区域与样式一致性**: 连线跨越不同分组框时自然穿过分组半透明背景，不将分组容器视为阻挡实体；自环、主要依赖实线、补充关联虚线及焦点高亮与输入/输出端点视觉规范完整兼容。
- **连续高速拖拽与动画并发**: 快速连续拖拽卡片触发隔卡拱桥切换、端口滑动动画并发时，无内存泄漏、无未捕获异常或画面撕裂卡死。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 取消全局多卡片硬避让与多段自适应绕行寻路，允许一般斜向及跨区域连线在必要时平稳从无关卡片下方穿过，绝不为了避免遮挡而在卡片外部生成多段蛇形波浪或夸张深 U 绕弯。
- **FR-002**: 系统 MUST 实现“该直的地方直”的端口与直线判定：左右侧单端口默认统一锚定在距卡片顶部固定基准高度（约标准卡片中线），使同排高矮不一的串联卡片始终共用同一水平主干线；当面对面连线的目标侧边缘仅有一个接入端口时，该单端口 MUST 沿连线轴向自动投影对齐源端口坐标（同时限制在卡片安全内边距范围内，并保证不低于最小可读高度）；当面对面连线的两端端口均已固定且横向或纵向错位处于小幅直线容差内时，连线 MUST 直接拉直衔接，并让箭头顺沿该斜直线的方向自然微调停靠输入圆外沿，消除小错位 S 形弯曲与箭头根部折角。
- **FR-003**: 系统 MUST 为所有需要转弯的曲线连线生成平滑、单段、弧度受控的曲线：起点沿垂直于起点卡片边缘的方向引出，终点沿箭头方向垂直目标卡片边缘汇入，端口出口与箭头根部无可见折角（按 `FR-002` 触发小错位拉直的直连则沿直线方向对接箭头）；长距离跨列或反向回环连线的弯曲幅度 MUST 受到合理上限约束，避免产生失比例的大鼓包。
- **FR-004**: 常规无正面直挡场景 MUST 保留既有四向动态端口选边与同侧防交叉排序；仅当同排或同列面对面相连的两张卡片正前方被中间卡片正面堵死直连通道、且该连接处于导图最外侧边缘（拱桥所在外侧没有任何其他卡片）时，系统 MUST 轻量切换至外侧同侧端口（顶对顶、底对底，或左对左、右对右）并生成单段对称拱弧跨过中间卡片；位于导图内部行/列（拱桥两侧均有其他卡片）时 MUST 保持默认对边穿底直连，不向外侧绕行以免增加多余交叉。
- **FR-005**: 未选中节点时所有常规连线 MUST 位于节点卡片下方；**仅当用户单击选中某张节点卡片时**，与该节点直接相连的所有传入、传出及补充关系连线（及对应胶囊）MUST 自动提层至节点卡片上方高亮显示以完整展现穿底脉络，无关连线同步淡化并留在底层；鼠标悬停节点卡片、连线或胶囊 MUST NOT 触发临时提层，取消选中后立即恢复原层级。
- **FR-006**: 所有带有关系名称文字的连线 MUST 以圆角胶囊节点形式替代原直接描边纯文本，悬浮渲染在卡片层上方、端口圆点下方，并自适应浅色与深色暖纸主题配色；胶囊样式 MUST 与所属连线的选中高亮及淡化状态保持联动。
- **FR-007**: 关系胶囊节点 MUST 根据当前视图内节点位置与实时连线轨迹沿曲线从中间向两侧可读区域自动探测停靠点，优先避开节点卡片遮挡；当整条连线过短、全部候选点均无法完全避开卡片时，胶囊 MUST 稳妥居中停留在连线上，并对过长文本限制合理宽度、省略截断且支持悬停显示完整名称。
- **FR-008**: 当单张卡片同侧存在多个端口或两张卡片之间存在双向互连与并行多关系时，系统 MUST 保持同侧端口不交叉排序，并使双向/并行连线及其关系胶囊保持可分辨分离、避免完全叠合。
- **FR-009**: 在用户持续拖拽卡片及端口沿卡片边缘滑动过渡期间，连线、拱桥、端口圆点与关系胶囊位置 MUST 实时同步更新且保持流畅不崩溃；同排/同列隔卡拱桥与临界方向切换 MUST 具备轻度缓冲滞回，防止拖拽过临界线时高频闪变。
- **FR-010**: 自环连线、主要依赖实线、补充关联虚线及既有端点视觉规范 MUST 完整保留：输入端点保持雾霾蓝（`#8699aa`）实心圆，输出端点保持灰豆沙（`#b38c97`）空心圆及 `2px` 描边，箭头尖端停靠输入圆外沿。
- **FR-011**: 本次连线路由、焦点提层与胶囊定位 MUST 完全作为视图实时呈现状态运行，不得改写任何已保存的节点或分组坐标，也不得改动导图结构（`map.json`）或布局（`layout.json`）的持久化存储格式。
- **FR-012**: 宿主桌面侧栏（浅色/深色主题）与导出的独立离线 HTML 阅读页 MUST 复用同一套连线、提层与胶囊呈现规则，保证双端表现一致。

### Key Entities

- **节点连线（Node Connection）**: 表达视图内两节点间（或节点自身）有向关系的视觉通道，在常态下呈现在卡片下层，含起点输出端口、终点输入端口与箭头、直线或受控单段曲线路径以及关系类型样式。
- **自适应端口锚点（Adaptive Port Anchor）**: 位于卡片四边安全内边距内的连线端点；左右侧单端口默认以距卡片顶部固定高度为基准保持整排串联水平共线，单端口接入面对面多端口或偏移边时自动沿轴向投影对齐对端端口，多端口同侧时按防交叉顺序均匀排布，隔卡直连时可沿边框平滑滑至同侧形成拱桥。
- **隔卡拱桥（Inline-Blocked Arch）**: 专用于同排或同列被中间卡片正面堵死的轻量单段对称拱弧，使首尾直连无需穿入中间卡片中心即可清晰跨过。
- **关系胶囊标签（Edge Label Pill）**: 悬浮在卡片之上、端口之下的可移动圆角标签节点，自动沿所属曲线寻找无卡片遮挡的可读位置并随主题及焦点高亮状态联动。
- **焦点连线浮层（Elevated Focus Layer）**: 仅在节点被选中时激活的上层连线呈现层级，将与选中节点直接关联的全部连线与对应胶囊提至卡片之上清晰呈现。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在包含不少于 12 组“同排高度不等相邻卡片”、“多端口对单端口相邻连接”及“小幅错位面对面连接”的测试视图中，**100%** 的对齐与容差内相邻连线呈现为干净笔直的直线，彻底消除小 S 形弯曲。
- **SC-002**: 在包含不少于 15 组跨行、跨列、远距、反向回环、跨无关卡片斜连与自环的标准曲线场景中，**100%** 的连线保持单段顺滑、端口与箭头衔接无可见折角且无远距夸张大鼓包，**0 条**连线因避让无关卡片而生成多段蛇形波浪或深 U 绕行。
- **SC-003**: 在外侧边缘的同排/同列隔卡直连场景中，**100%** 的正面堵死直连转为干净对称的外侧拱桥跨过中间卡片，内部列/行隔卡连线则保持穿底直连不产生额外绕行交叉；选中任意节点时，**100%** 的直接关联连线（含原本穿底的跨卡连线）完整浮升至卡片上方高亮可辨。
- **SC-004**: 在常规跨距带标签连线上，至少 **95%** 的关系胶囊标签自动停靠于曲线上不压盖任何卡片的可读位置；在极短间距连线上，**100%** 的胶囊稳定居中显示、超长文本优雅截断且悬停可读全文，不飞离连线。
- **SC-005**: 在包含 40 个节点与 60 条以上连线的复杂视图中持续拖拽节点 30 秒，操作全程顺滑跟手，渲染无卡死、无页面崩溃，且慢速拖过隔卡拱桥临界位置时切换次数不超过 **1 次**。
- **SC-006**: 打开任意既有保存布局的导图时，节点与分组坐标保持率 **100%**；在宿主桌面侧栏（浅色与深色主题）以及导出的独立离线 HTML 阅读页中，同一视图的连线形态、提层高亮与胶囊位置一致率 **100%**。

## Assumptions

- **替代前序全局避让方案**: 本规范正式取代并简化 `011-edge-curve-avoidance` 中基于全局多卡安全包络的多阶段启发式绕行设计，仅保留“局部端口对齐与直线拉直 + 限幅单段平滑曲线 + 轻量同排/同列隔卡拱桥”。
- **保留柔和曲线视觉基准**: 继续遵循 HTML v17 柔和曲线风格与端口圆点颜色描边规范，不将全局连线切换为直角正交折线风格。
- **穿底与选中提层协同**: 默认连线保持在卡片下层（卡片具有足够不透明背景），依赖节点选中时的上层高亮浮层来完整呈现穿底连线脉络。
- **自动避卡胶囊不写回存储**: 关系胶囊节点随节点拖拽和曲线重算实时自动滑位，不提供手动拖拽胶囊落盘或向 `map.json` / `layout.json` 新增位置字段，以此零成本兼容全部历史导图与离线导出。
