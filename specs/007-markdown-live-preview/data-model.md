# 实时预览编辑数据模型

本设计沿用[现有存储格式](../../docs/mindmap-storage-format.md)和[正文定位契约](../005-unify-note-presentation/contracts/dsh-insertion-reference.md)。下列编辑状态作用域为会话内存。

## 节点正文工作文档

| 字段 | 含义与校验 |
| --- | --- |
| 身份 | 绑定当前会话、工作区、地图、节点及出现视图。相同节点跨视图复用同一笔记。需要重新挂载时以当前 `EditSession` 为准。 |
| 原始 Markdown | 当前正文原文，保留 CRLF、LF、单独 CR、结尾空行及未改变的围栏定义。已保存版本仍由 `EditSession.baseline` 管理。 |
| 编辑文档 | CodeMirror `Text`，通过将原文逻辑换行表示为 LF 得到。任何已接受的编辑事务完成后维持这项对应关系。 |
| 偏移映射 | 编辑文档与原文间的 UTF-16 边界对照。DSH 定位额外排除 CRLF 中间和 Unicode 代理对中间，只有经共享解析验证的位置可成为锚点。 |
| 选择与视口 | 按编辑文档位置保存光标、选区方向、主要范围和可见位置。选区和滚动是会话状态，只更新显示。 |
| 编辑身份版本 | 区分已被上游替换或已销毁的视图。图片读取、位置计算、拖动、引用回跳等异步操作提交前须对照身份和对应的正文及选区／落点。 |

新行遵循原文的首个换行风格，空笔记默认 LF。多范围事务使用变更前的全部坐标一次执行。只读与编辑模式切换不会写入原样正文。输入法组字结果等确认后才可保存。

## 源码范围与预览

| 范围 | 来源和状态 |
| --- | --- |
| 标题、文字格式、列表标记 | 来自当前 Markdown 语法树。光标进入或选区相交时显示标记。未激活时使用同一字号、颜色、缩进、行距规则呈现。 |
| 公式 | 带行内／独立类别、已验证起止点、定界符和表达式。有效行内公式在当前源码和排版之间切换。独立公式的活动范围可在源码下附一处预览。非法、未闭合或无法解析的源文可直接操作。 |
| 图片 | 来自受支持的 Markdown 资源引用并使用现有资源验证。加入图片把验证过的图片及引用放入同一编辑操作。移除图片只改目标引用。 |
| 图表 | 现有 `dsh-plot` 顶层围栏。范围验证使用原始 Markdown，健全图块使用已有 ID，坏块可见诊断和原文快照。显式移动／删除只适用于已有契约承认的完整且唯一的图表。 |
| 位置／文字引用 | 位置保留 v1 `block/start` 或 v2 `gap`、节点身份、原文摘要与邻居上下文。选文继续使用当前读者投影的文字、前文和后文，排除图表控件与公式重复排版。 |

## 变更、历史和保存

- **普通正文事务**　计算候选原文并核对受保护图块。接受后更新工作文档、选区和历史，并将当前详情状态交给 `EditSession.input`。只读状态拒绝文档变更。
- **正文历史条目**　由同一次文档变更的原文、选区前后值和操作类别组成。依现有规则合批及保留最近 30 步。正文撤销／重做来自当前编辑身份的历史条目，并将完整结果带入自动保存。图表恢复须保留原围栏和身份。
- **导图历史条目**　继续由 `EditSession` 封存详情保存批次、布局和节点移动，最多 30 步。正文历史与导图历史由实际键盘焦点决定命令归属。导图历史改变当前正文时重新同步正文历史，避免重放过期条目。
- **会话状态**　开始组字后暂停提交定时器，组字结束重新排队。普通详情输入停顿约 800 毫秒提交，图片和整图动作按既有规则尽快排队。保存回执确认已写版本，留存稍晚的本地输入。保存失败保留草稿。外部版本冲突保留原稿和本地草稿，按既有动作处理。
- **状态失效**　外部版本实际载入、显式丢弃、撤销导致上游正文替换、编辑目标离开时同步或清理正文历史。已保存回执内容相同、图表挂载、输入焦点变化或纯滚动均不重建文档历史。

原有提交请求继续包含工作区、预期地图版本、操作 ID 和现行编辑数据。图表删除及恢复由服务器现有记录校验。详细操作规则见[交互和集成契约](contracts/live-preview.md)。
