# 节点正文实时预览交互与集成契约

本契约推进 [005 节点详情契约](../../005-unify-note-presentation/contracts/note-detail.md) 的实时正文编辑。宿主引用载荷和文件请求沿用[正文定位契约](../../005-unify-note-presentation/contracts/dsh-insertion-reference.md)与[存储契约](../../../docs/mindmap-storage-format.md)。

## 读写入口与显示

| 场景 | 可观察行为 |
| --- | --- |
| 打开、切换和完成 | 默认只读。可写详情在「复制内容」旁提供「编辑」；同处显示「完成」。使用同一详情面板并保持可见段落。没有输入时原文和版本保持原值。 |
| 标题与行内格式 | 正文一、二、三级区分字号、颜色、字重和留白，正文一级低于节点主标题。阅读和编辑的非激活内容共用排版。进入标题行可见实际井号；进入加粗、斜体范围可修改实际符号，离开后恢复格式。选中格式范围亦可编辑其标记。 |
| 行内公式 | 点击预览或用方向键进入实际范围时，显示同一行上的 Markdown 源码。移动出范围时显示一处有效排版。用鼠标拖选、键盘选择或复制时遵循真实文档边界。 |
| 独立公式 | 非激活时显示一处数学排版。源码激活后正常可编辑，其后至多有一处有效预览。前后普通段落可达，删除定界符、无效输入或中断后仍可继续编辑其他内容。 |
| 未识别或暂时无效内容 | 保留源码。无效公式、代码中的样例、转义标记、尚未完成的行内格式都可被选择和修改。纯显示转换不拦截「完成」或下一次输入。 |
| 输入法 | 组字期间维持当前选区和组合范围，延后该范围的显示切换和正文提交。结束时最终值只进入一次正常保存流程。取消组字时保留组字前已有的草稿和保存安排。 |

样式复用 `atlas.css` 的正文排版规则。替换真实字符的公式和图片允许点击或键盘进入。图表的受保护范围只在正文导航中整体跳过。触发只读的会话状态继续显示既有提示、正文和复制途径。

## 键盘与文档变更

| 动作 | 约定 |
| --- | --- |
| Enter，有内容的列表条目末尾 | 在原缩进续写同类条目，后续编号按现有 Markdown 规则延续。位置以逻辑行和语法树为准。 |
| Enter，空列表条目 | 顶层退出列表，嵌套时回到上一层。紧密列表的第二个空条目同样退出当前层。 |
| Backspace，列表内容起点 | 空项按对应层级退出。相邻同级条目均有内容时可合并，保留前一条目的标记和两段文字，光标留在合并点。其他情况使用列表上下文或普通退格。 |
| Backspace、Delete，公式或格式源码 | 按当前选择或相邻字符修改实际源码，包括 `$`、`$$` 和星号。正常选区删除可跨公式、标题和列表。 |
| 复制、剪切和粘贴 | 编辑态文本剪贴板基于所选正文源范围，跳过受保护图表定义。坏块的原文可从明确的诊断入口复制，复制正文按钮保持已有约定。选文加入 DSH 使用现有可读文本投影与上下文。阻止普通剪切、删除、粘贴或拖选替换改写受保护图表围栏，并提示对应整图操作。 |
| Ctrl+Z / Ctrl+Y | 焦点在正文时使用正文历史。焦点回到画布时使用导图历史，分别处理正文和画布焦点。正文回放更新选区并经同一保存入口。组合输入进行中保持平台输入法按键。 |

正文候选原文应保留变更范围外的内容。普通事务提交前核对原始图表定义和顺序，包括因块外的换行、缩进或围栏输入产生的解析边界变化。命令拦截保留当前工作文档和历史，编辑其他部分仍可继续。保存服务继续承担最终写入校验。

## 图片与图表

1. 图片显示复用当前资源解析和格式限制。使用现有入口加入图片，验证后让引用与图像一起进入同一次保存。异步读取后重新核对节点、工作区、写入状态，以及可验证的待插入位置。目标无法确认时请用户重新选择。移除图片只删除对应引用，撤销可恢复。
2. 图表复用现有图面、图例、统计数据、函数校验与诊断。整图保持固定源码，不把图表操作界面放入正文剪贴、编辑或取点范围。坏块仍可查看诊断和原文。
3. 拖动由已有图表控件发起，提供合法落点提示。落点限顶层块之间、正文开头或末尾，须匹配当前 Markdown 版本。取消、无变化、越界、落点失效时原文保持原样。显式「删除图表」只作用于该 ID 对应的整块。
4. 整图操作与历史回放使用现有图表变更语义。移动前后图表 ID 与围栏字节相同。删除和撤销由已有 `manualPlotDelta`、`removedPlots`、Host 校验及恢复记录核对。
5. 图表 JSON、函数表达式与统计数据继续通过 DSH 既有工具修改。正文只负责显示、定位、整图移动和删除。

## 右键、引用与回跳

1. 在正文右键或通过键盘打开菜单时，捕获当前文档、编辑身份和实际位置。鼠标坐标向编辑文档位置映射后，再转成原始 UTF-16 偏移。点击未落在可验证的文本边界、块间空白或空笔记时，提示重新选点。视觉换行、图表、公式预览、图片和虚拟布局占位不是块间空白。
2. 复用 `captureNoteAnchor` 与 `captureNoteGap` 和唯一匹配规则，在已保存版本复核锚点。存在未保存修改时，仅唯一对应已保存正文的位置可加入引用。计算完成后复核编辑身份、正文和保存基线，过期结果提示重新选择。
3. 「添加图表/公式」保留会话和已有草稿。手动发送后，行内公式使用可插入的文字点，独立公式和图表放在支持的顶层段落之后，块间空白和空正文则使用既有边界规则。不安全的列表、代码与图表内部位置沿用现有提示。
4. 文本引用沿用读者投影的文字及前后文。从编辑器选区映射可验证范围并保留公式原文，排除图表 UI。引用回跳先走现有编辑结束和保存保护，再使用读态投影定位。被改写或重复的来源保留快照和失效提示。
5. 图表引用继续按原会话、节点及图表 ID 加入提问框。位置、图表和选文引用均由用户手动发送。

## 保存、宿主与离线边界

- 在线正文把真实文档变更交给已有 `EditSession`。自动保存等待组合输入结束。普通停顿批次、图片和图表操作、保存回执、失败重试及外部版本冲突沿用已有流程。点击「完成」和插件内切换沿用结束输入与保存保护；只有有效的正文更改参与历史。详见[数据模型](../data-model.md)。
- DSH `v0.2.2-rc.3` 使用现有 `sidebar.right.pane.tab`、会话、输入框及引用服务。新增依赖随在线客户端闭包模块打包。
- 独立 HTML 使用已保存正文和既有阅读投影。仍可显示、选中文本和复制，公式字体及图表资源按既有办法随包内嵌。其读取入口不引入 CodeMirror、在线编辑控件或 DSH 草稿动作。画布能力按既有离线契约验收。
