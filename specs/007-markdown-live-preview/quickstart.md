# 节点正文实时预览快速验收

本指南供实现完成后使用。在实际 DSH 和记有宿主版本的侧栏中验证，每组记录实际结果，保留坏块、写入失败和外部修改场景的原文副本。

## 1 准备

1. 使用 Node.js ≥ 24.9、本仓库依赖和 DSH `v0.2.2-rc.3`，准备独立可写验收导图。另备一个只读节点或工作区，以及用户日常使用的宿主版本用于补充复验。
2. 在实现完成后按[插件安装说明](../../docs/plugin-development.md#在已有-dsh-中加载)加载新候选。在项目根目录运行下列命令准备产物。依赖尚未安装时先运行 `npm ci`。记录客户端和离线阅读产物的依赖核对结果。

   ```powershell
   npm run typecheck
   npm run pack:plugin
   ```

3. 建立混合样例，包含三个级别的标题、粗体、斜体、组合语法、两类列表、引用、代码、转义、单行和多行独立公式、图片、函数图和统计图。图表按[图块语法](../004-function-plot/contracts/plot-markdown.md)生成。在一个单独的旧笔记副本里保留 CRLF、LF 和末尾空行，围栏也包含原始换行。备份各节点 Markdown。
4. 在原会话提问框保留文字、已有引用和附件。分别准备空正文节点、重复段落与坏图块副本，以及混合中英和表情的普通段落。

## 2 排版、选区与输入（SC-001、SC-002）

1. 用约 320 px 和 260 px 的详情宽度滚至中段，往返「编辑」和「完成」。核对 8 类格式的非激活样式和可见段落，比较前后文件原文。
2. 连续 10 次用点击或键盘进入、离开格式。核对标题井号、加粗、斜体和组合范围，检查选区方向、长标题换行和正文位置。然后覆盖一段含多种格式、公式和普通文字的选区进行复制、剪切和撤销。
3. 逐项验收列表续写、顶层第二个空项 Enter 退出、嵌套空项 Enter 或 Backspace 退一层、同级相邻条目 Backspace 合并、单行粘贴、多行粘贴、跨段选区删除、中文组字。观察实际光标、缩进和未涉及条目，另用侧栏窄宽的视觉折行复查。
4. 使用中文输入法在加粗旁、行内公式前后和列表内输入，并停顿在组合中。组合字未确认时磁盘保持原样，确认后只出现一次当前文字。再取消一次组字，确认之前等待保存的正文仍可保存。
5. 编辑 `- *原料*产地、**销售市场**与资本输出场所`，再将光标移至下一段。侧栏宽度充足时，项目符号、斜体、粗体和普通文字保持同一行。缩窄侧栏后，文字随可用宽度自然折行。

## 3 行内和独立公式（SC-003）

1. 在普通段落与有序列表中各使用一次 `前文 $eee$ 后文`。从前、后两侧进入公式，再移出，检查编辑源码与排版没有重影。
   宽度充足时，离开公式后 `300万平方公里（$dd$常见估计）` 中的公式与前后文字保持同一行。
   再用 `- sdaf$x$` 和 `- sdaf$xxxxxxx$` 核对公式在编辑态失焦与只读态均完整显示，字母基线与前文对齐，行内没有滚动条。缩窄侧栏并加长公式，核对超宽内容仍可横向查看。
2. 连续放入两处独立公式，分别使用单行与多行形式。进入每条公式检查源码和其下方至多一处预览，离开后只留一处排版。
3. 对两种公式分别删除一个 `$` 和一侧定界符，接着编辑相邻文字、按 Enter、点击「完成」。检查剩余源码可改可保存，撤销和重做恢复实际源码、位置和定界符。复验无法渲染的 LaTeX、转义美元和代码块中的公式示例。

## 4 图片、图表与精确原文（SC-004）

1. 加入、删除图片，核对只改目标引用。撤销／重做后重开，检查对应资源、图片和余下正文。
   在「编辑」状态直接拖动图片，分别放到正文开头、段落之间和末尾。核对落点提示、图片顺序，以及保存后重开和撤销重做。随后把图片拖到 DSH 提问框上松手，确认正文位置和提问框草稿都保持原样。
   分别从图片左侧按 Delete、右侧按 Backspace，核对整张图片引用删除，撤销后恢复。图片后面的标题和列表应继续排版。旧笔记里由插图按钮生成但缺少 `!` 的资源链接仍应显示图片，拖到新位置后核对图片语法已恢复。
2. 将一张图拖至正文开头、段间、末尾，再执行越界拖动及取消。删除另一张图，保存后分别执行正文撤销和重做。核对图表 ID、围栏原文和图序。已有统计图和函数图在两态均可完整显示。
3. 分别以跨图剪切、选区替换、粘贴围栏及图块邻接行编辑尝试改变图块解析。普通操作不得改变受保护图表。验证坏块的诊断和只读原文仍可查看。
4. 在混合换行笔记内先只读和切换模式，再修改局部文字、移动图表、撤销和重做。用记录的原文核对未改片段、末尾空行和围栏字节，包括恢复的图块。
5. 依次形成 31 个独立有效导图历史批次。在画布焦点核对最近 30 步、重做和最旧记录淘汰。正文焦点核对正文自身撤销，并确保一次按键只触发一条历史路径。

## 5 DSH 引用与插入（SC-005）

1. 在中文或表情旁、有加粗的普通段落、段间空白、起始空正文分别选点，可以用鼠标或键盘打开菜单。核对保留原会话和草稿，每次加入后均等待用户手动发送。
2. 使用可写验收导图手动发送行内公式、独立公式、图表的单项请求，核对字符点、段后和块间空白落点。复验编辑态选文、图表引用和已加入引用的回跳。
3. 加入后改写目标段或制造多个相同上下文，再发送。核对可读快照及重新选点提示。另在未保存的新段、视觉折行处、公式预览和图表内部取点，核对只提供能映射到已保存正文的位置。

## 6 自动保存和冲突（SC-004、SC-005）

1. 继续输入直到超过一次自动保存停顿，确认保存回执到达时当前选区、后续输入和正文撤销仍可用。保存后重开验收目标节点。复验快速切节点、插件内关闭，以及宿主在组字已经结束但未落盘时直接关闭后同会话重开。
2. 用验收副本制造一次保存失败，检查用户可看到未保存状态和仍在的草稿。恢复可写后重试，核对只保存最终内容。再用独立副本在本地草稿未提交时从外部改同一笔记，验证已有版本提示，磁盘外部版没有被覆盖，所选处理动作符合提示。
3. 需要模拟 Host 中途写失败、丢失响应等情况时，按项目的专项授权执行现有保存检查。未执行项单独记录。

## 7 长笔记、只读和离线

1. 在独立样例中加入至少 100 段文字并分布图表、图片与公式，从开头快速滚动到结尾并在边界编辑。观察没有编辑器重置、光标跳走或图面重复初始化，局部编辑保存后可继续浏览。
2. 用只读会话验证仍可浏览、复制正文、显示公式和图表。导出已保存的导图为独立 HTML，移至不同目录后断网打开，核对字体、图表、公式、标题和图片。复验既有画布操作，节点详情只呈现阅读和复制能力。
3. 记录 DSH 版本、插件候选版本、侧栏尺寸、输入法和验收日期。规划及构建结果均单独记录，实际交互验收以本指南对应操作结果为准。
