## 1. 自动化编译与单元测试核验（本地工程验证）

> 按项目约定（`AGENTS.md`），日常开发默认仅运行静态类型检查、构建与打包预检并在交付时标注未验证项；`npm.cmd run test` 仅在用户明确授权执行自动化测试时运行。

在仓库根目录按授权范围执行以下命令，验证类型检查、构建、插件打包产物及（经用户授权时的）几何路由、原型对齐与 DOM 集成回归：

```powershell
# 日常默认执行的静态检查、构建与打包核验
npm.cmd run typecheck
npm.cmd run build
npm.cmd run pack:plugin -- --dry-run

# 仅在用户明确授权运行自动化测试时执行
npm.cmd run test
```

### 自动化验证对照要点（引用 [contracts/edge-routing.md](contracts/edge-routing.md) 与 [data-model.md](data-model.md)）
1. **端切向顺滑与无阻挡基础弧度（`SC-001`）**：
   - 在 `tests/shared/edge-routing.test.ts` 中覆盖 ≥ 15 种方位组合，校验所有输出路径首段控制点严格位于起点端口外法线射线、末段控制点严格位于箭头方向反向延长线（端切向误差 $< 0.01^\circ$），邻边与远距连线无过度鼓包，自环清晰独立且零 `NaN`。
2. **完整外框避让、自身防穿透与 1～3 段自适应（`SC-002`）**：
   - 覆盖 ≥ 12 个典型场景（同排/同列正面直挡拱桥换边、轻微擦边最小微调不绕大圈、高/宽卡片避让、多障碍交错 1～3 段自动升段与冗余抽稀、极端卡片重叠最小遮挡降级），校验存在可通行走廊时非端点卡片完整边框碰撞次数为 `0`、起终点自身卡片碰撞次数为 `0`，且曲线分段数始终 $\in [1, 3]$。
3. **共路分层、标签防压卡与拖拽滞回（`SC-003`、`SC-004`）**：
   - 验证 2～4 条共路绕行边与双向互连边清晰错开、窄走廊自适应收紧且不挤到对侧绕大圈；
   - 验证带标签绕行边 $\ge 90\%$ 场景下标签包围盒与卡片无重叠；
   - 验证节点以 `2px` 步长连续拖过障碍中线临界区时绕行方向切换 $\le 1$ 次；20 节点 / 30+ 边复杂视图批量路由耗时满足 60fps 拖拽流畅性预算。
4. **原型兼容性与既有布局只读（`SC-005`）**：
   - `tests/shared/prototype-parity.test.ts` 确认 v17 无阻挡边保持原端口侧边与分布、直挡隔卡边完成无穿卡避让；
   - 复用 `tests/integration/dom.test.ts` 既有宿主 DOM 与离线 HTML 导出用例（及 `T319` 附带轻量烟雾断言），确认 `MapScene` 与离线导出同步渲染完整连线、标签、端口动画且不改写既有布局坐标。

## 2. DSH Desktop 真机与离线 HTML 人工验收步骤

> 按项目约定（`AGENTS.md`），日常开发完成构建验证后，UI 与视觉体验交由用户在 DSH Desktop 真机及独立离线阅读页中按以下步骤人工确认：

1. **基础弧度、端口出入射与转角观感（`US1`）**：
   - 打开既有包含水平、垂直、斜向、邻边转角和长距离跨组连线的导图；
   - 放大观察每一条连线的灰豆沙空心圆出口和雾霾蓝实心圆入口箭头：确认所有出口均垂直边框引出、箭头根部均垂直对准且**无任何可见折角或擦边**；转角与远距连线弧度克制自然、无夸张大鼓包。
2. **正面直挡拱桥、轻微擦边最小让与多障碍平滑绕行（`US2`）**：
   - 在任意视图中找或拖出“同排 A—B—C 中 `A → C` 被中间卡片 `B` 正面挡死”的场景：确认端口平滑滑至卡片顶边或底边形成舒展拱桥跨过 `B`，而未堵死的一般斜向边保持原侧边；
   - 拖动一张卡片使其仅**轻微擦过**另一条斜线边角：确认该斜线只顺滑微调让出约 `6～8px` 留白，不绕大圈也不折多个大弯；
   - 构造经过两张错位卡片或高/宽卡片的跨组长连线：确认曲线以顺滑的 1～3 段弧线沿着空走廊绕过全部阻挡，无尖角、无多余波浪抖动，且不穿回起点或终点卡片自身。
3. **多线绕行分离与关系标签可读性（`US3`）**：
   - 在有 2～3 条连线同时绕过同一张卡片同侧、以及两节点双向互连且带文字名称的场景中：确认多条曲线保持清晰分层间距、不粘连叠成一根线，窄间隙里也能紧密并行而不强行翻到另一侧；
   - 检查绕行连线上的关系名称小字：确认文字跟随实际绕行弧线并躲开卡片遮挡、清晰可读。
4. **拖拽稳定性、端口滑轨动画与焦点高亮兼容性（`US3`）**：
   - 按住一张中间卡片缓慢来回横穿某条长连线的中线临界位置：确认绕行侧不会高频来回闪烁，跨过一定缓冲后才一次性平滑切换到另一侧，且端口圆点、曲线与箭头全程严密贴合、操作跟手无掉帧；
   - 单击节点启用焦点高亮并切换浅色/深色主题，确认实线、虚线与自环曲线均显示正常。
5. **既有布局保护与离线导出一致性（`FR-011` / `SC-005`）**：
   - 重新打开历史已保存过 `layout.json` 的导图，确认所有节点与分组位置 100% 保持原样未漂移；
   - 点击导出独立离线 HTML 并在浏览器中打开，对比验证相同视图的连线弧度、绕行路径、共路分离与关系标签与侧栏完全一致。
