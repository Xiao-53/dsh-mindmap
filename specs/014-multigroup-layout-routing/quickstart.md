## 1. 本地编译、静态检查与单元测试（工程验证）

> 按 `AGENTS.md` 开发约定，日常开发默认运行 `npm.cmd run typecheck`、`npm.cmd run build` 及预览打包；`npm.cmd run test` 仅在用户明确授权运行自动化测试时执行。

在仓库根目录执行：

```powershell
# 静态类型检查与构建产物验证
npm.cmd run typecheck
npm.cmd run build

# 自动化单元测试与 DOM 集成测试（仅在用户明确授权时执行）
npm.cmd run test
```

### 自动化验收对照点（`SC-001` – `SC-007`）
1. **全视图实高多分组与环路外侧通道（`SC-001`, `SC-002`, `SC-006`）**：
   - 核查 `tests/shared/layout-navigation.test.ts` 中所有既有回归断言（离散 3 列对齐、首行填满、统一分组宽、内列零直穿与零重线、独立分叉/菱形、20 节点环路 10 次确定性零重叠、`previous` 布局零漂移）100% 通过；
   - 核查极端变高卡片（86–260px）、2×2 强耦合田字、组内闭环与跨组反馈回边（外边界列牵引）穿刺与交叉显著压降，以及 20 节点满载单次重排耗时达标。
2. **双向/平行斜线分离、拱桥护栏分层与胶囊四维避让（`SC-003`, `SC-004`, `SC-006`）**：
   - 核查 `tests/shared/edge-routing.test.ts` 与 `tests/shared/prototype-parity.test.ts` 全量通过；
   - 验证 `dy ∈ [24, 162]` 与 `dx = +200` 双向斜线 0 交叉且净空 `>= 16px`、慢速过界翻转 `<= 1` 次、平行斜线四向分离 `>= 14px`、同端嵌套拱桥 0 交叉且外层更高、首行顶拱 `min_y > group.y + 34`、左拱 `min_x >= 10`（含双列邻组标题安全）、8 边多组标注胶囊四维碰撞归 `0`，及 40 节点 / 65 边单次路由远低于 `16ms`。
3. **框内补位、局部整理与高亮光晕 DOM 校验（`SC-005`, `SC-007`）**：
   - 核查 `tests/integration/dom.test.ts` 验证 `.edge-focus-halo` 仅随选中提层挂载、水平短边胶囊附带收窄 `maxWidth`、顶部“整理未锁定节点”按钮保留 `manual` 节点零位移且可一步撤销、离线渲染不含局部整理按钮。

## 2. DSH Desktop 真机与离线 HTML 人工验收步骤

> 实现完成并按 `AGENTS.md` 打包最新 `0.4.5-preview.n` 后，在 DSH `v0.2.2-rc.3` 桌面原生侧栏（浅色/深色主题、窄栏至宽屏）与导出的独立离线 HTML 页面中逐项核查：

1. **多分组高矮卡片与田字型排列（`US1`）**：
   - 准备包含 3～4 个分层分组、部分卡片带长摘要的导图，切换纵向与田字型排列：确认长摘要高卡片下方无纵向穿卡错位，田字型左右相邻分组相连卡片主动向内侧边靠拢且水平对齐，既有一战/斯大林式规整三列秩序完整保持。
2. **组内闭环与跨组长回边（`US2`）**：
   - 打开含双向互连与下游指向上游跨组反馈的导图并重置排列：确认循环相关卡片紧凑邻近且未倒拉首行，跨多组反馈连线被牵引至最外侧左右边界列沿外围拱桥绕行，不横穿中间卡片正文。
3. **斜线分离、拱桥护栏与高亮光晕（`US3`）**：
   - 观察斜向双向连线与多条同向平行斜线：确认中段清晰分离无双交叉或粘连，拖动跨过水平/垂直临界线平滑不闪跳；
   - 检查首行 3 卡隔卡顶拱与阶梯分组外拱桥：确认顶拱不切穿分组标题文字、左拱不越出画布左侧、多条同侧拱桥按“短在内低层、长在外高层”整齐分层无出口交叉；
   - 分别在浅色和深色主题下单击选中存在穿底连线的卡片：确认高亮连线底层带柔和画布同色光晕与下方卡片正文清晰区隔；悬停卡片/连线不触发提层。
4. **关系胶囊四维避让与极短边呈现（`US4`）**：
   - 观察交叉斜线与相邻 91px 水平短边 / 32px 竖向短边的带文字连线：确认胶囊不压他线、不压箭头/端口圆点；短水平边胶囊居中收窄且超长省略可悬停查看全文；短竖边胶囊停靠于行间间隙走廊右侧（或左侧）侧鞍位置。
5. **脱框补位、局部整理与双端/旧图兼容（`US5`）**：
   - 将某卡片拖出分组外框后同组新增关联节点：确认新节点落回原分组框内最靠近该邻居的空位，旧卡片和分组框纹丝不动；
   - 手动调整若干卡片位置后点击顶部工具栏重置旁的“整理未锁定节点”：确认手动卡片与分组框零位移，其余节点重排整齐且零重叠，按 `Ctrl+Z` 可完整撤销；
   - 打开工作区已有 `layout.json` 旧图确认坐标零静默漂移；拖动节点确认跟手零延迟、0.5 秒子图过渡无重影；导出独立离线 HTML，对比浅深主题渲染一致性并确认无编辑按钮。
