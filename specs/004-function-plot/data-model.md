# 数据模型：节点笔记图块

## 笔记图块

节点 Markdown 的顶层 `dsh-plot` 围栏承载一个严格 JSON 对象。围栏之外继续使用当前 Markdown 和 LaTeX 规则。地图结构、笔记路径、布局和资源目录均沿用现有存储契约，旧图无需迁移。

| 字段 | 规则 |
| --- | --- |
| `version` | 整数 `1`。未知版本或类型按局部错误展示。 |
| `id` | 现有字母、数字、下划线、短横线 ID 规则，同一笔记内唯一。新图块用新 ID，修改保留原 ID。完整身份为工作区内的 `mapId/nodeId/plotId`。 |
| `kind` | `function`、`bar`、`line` 三选一。 |
| `title` | 可选非空单行短标题。无标题时用系列名称或函数式区分。 |
| `xRange`、`yRange` | 仅函数图可选，各为两个严格递增有限数。省略的范围独立默认 `[-5,5]`。 |
| `series`（函数图） | 有序 1–3 项，每项含 `expression` 和可选 `label`。表达式至多 256 字符，使用 [语法与求值契约](contracts/plot-markdown.md)。省略标签时用函数式作为图例。 |
| `categories`（统计图） | 1–100 个有序非空单行类目，柱状图必填。折线图可省略，按数据位置使用从 1 开始的序号。重复文字按位置区分。 |
| `series`（统计图） | 有序 1–3 项，每项含 `label`、`values` 和可选 `unit`。每个值为有限数或表示缺值的 `null`。各系列长度相同，且与显式类目等长。原单位逐系列保存和展示。 |

标题、系列名、类目和单位均作为单行纯文本，每项最多 120 字符。相同单位可标在共享数值轴上，多个单位保留在各自图例和数据文本中，数值按原量纲列出。默认范围和衍生序号由解析结果补齐，读取时不写回源文档。图块不含独立文件、资源 URL、代码、用户坐标或渲染参数。

解析先记录原围栏文本、源码位置及其诊断，再产生规范化图块数据。有效图块的内容等同判断使用规范化后的有序数据（对象字段顺序不影响等同）。身份比较始终包含图块 ID。同一笔记的重复 ID 无法唯一定位，相应图块都回退显示，其他块照常阅读。

## 图块引用

`ReferenceSnapshot` 延续现有 source 及解码兼容，新增 `kind: 'plot'`，图块引用具备：

- **定位**。来源 `mapId/nodeId/originViewId` 和 `plotId`，内部保留原有会话、工作区与资源地址约束。
- **内容**。从已保存图块生成可读快照，包含类型、标题、范围及表达式，或有序类目、系列、数值、缺值与单位。快照含足以重建规范化内容的字段，宿主序列化把 `mapId/nodeId/plotId` 和内容明确传给模型。
- **回跳**。打开来源地图、视图与节点。命中唯一身份并核对内容后聚焦对应图块。来源范围失效、图已删除、重复或内容改变时保留快照并说明。无关正文变化按图块内容判断，不把整篇笔记版本当作图块变化。

图块引用和既有文本引用均由 DSH 草稿机制保存。内容写入与引用序列化互不触发。导出只包含已保存笔记和阅读数据。

## 图块变更与状态

| 入口 | 数据规则 |
| --- | --- |
| 读取或导出 | 解析当前 Markdown；坏块和未知版只做局部原文回退。 |
| 手动正文编辑 | 将所有已保存图块（含异常围栏）当作不可编辑片段。保存时用当前有效版本比较原始图块序列，禁止新增、改写、删除、重复或调整既有图块顺序。保留普通文字、公式及图片原有编辑方式。 |
| AI 新建地图或添加图 | 允许有效且 ID 唯一的图块。复用 `atlas_create` 或 `atlas_read` 后的 `atlas_apply`，服务端在写入和建立创建占位前校验图块。 |
| AI 按引用改图 | 当前笔记中唯一 ID 和引用内容相符时可准备候选。保留图块 ID，原样保留无关段落，提交本次读取得到的 `expectedFingerprint`。 |
| AI 删除图块 | 对比原笔记与候选，将删除的图块加入既有 `removals`。走 `atlas_preview` 和 `atlas_apply` 的当前版本绑定与宿主授权。仅图块的笔记删除最后一块仍按已有笔记删除契约处理。 |
| 错误及并发 | 新增或修改的无效块拒绝保存。已经存在的坏块可原样保留，允许同笔记的合法无关改动。写入冲突和事务失败沿用现有诊断、回退和重试语义。 |
