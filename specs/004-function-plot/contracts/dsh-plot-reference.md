# DSH 图块引用、写入与离线阅读契约

## 在线右键与键盘

右键或聚焦图块后按 Shift+F10 / 菜单键，打开当前图块的菜单，使用「添加到 DSH 提问框」。仅为可唯一定位的已保存图块提供该动作。图块菜单优先命中该图块，避免旁边选文或画布菜单同时打开；退出菜单回到原焦点。

用原会话 `captureInsertion` 捕获范围和 `draftRev`，将范围折叠到选区末端后用 `conversation.input.for(...).insertReference` 写入，保留已有文字、引用和附件。会话、工作区或原插入位置已失效时沿现有引用错误/重试路径，任何重试只能回原会话同一有效工作区。加入草稿无需运行模型或改写文件。

宿主展示引用标签。手动发送时 source codec 将地图、节点、图块 ID 和可读内容快照序列化给模型，引用内部其他地址和会话字段不进入模型文本。点击草稿中的引用时，source 回到合法来源并定位图块。已发送的普通消息保留可读来源和快照。已删除、已变化或身份不唯一时保留可读快照并说明。旧有节点和选文引用继续通过原路径解码、序列化和回跳。

## AI 修改

1. 用户明确发出修改任务后，用 `atlas_read` 按 `mapId` 和 `nodeIds` 读取当前笔记。引用只提供任务目标和内容快照。按 ID 核对内容；正文变而图块未变时用最新笔记继续，目标已变化、缺失或无法核对即停止说明。
2. 用现有 `set_note` 拼回完整正文，只改目标图块与用户指定的邻近说明。无目标图块时按明确节点新加唯一 ID。缺少统计数据时说明缺项或从获授权的来源取得实际数据。
3. 使用本次 `atlas_read` 的 `fingerprint` 作为 `expectedFingerprint`。候选验证在写入前完成。删除图块须通过含相应删除项的 `atlas_preview`，以相同版本、相同 `changes` 和 `previewToken` 调用 `atlas_apply`，由宿主授权。只读策略、版本冲突、回退与幂等重试沿用现有契约。
4. `/mindmap` 负责引导目标核对和合法格式。服务端负责数据校验、权限、事务和实际提交的版本检查。用户仅改了无关正文时无需重新引用图块。

## 离线

独立 HTML 内嵌已保存 Markdown、布局、必要资源、KaTeX 与 JSXGraph 的脚本和样式。同一图块解析、图例和错误回退在断网 `file://` 环境下复用。保留打开节点、子图导航、查找、阅读缩放和平移、选文和复制。画布节点可自由拖动，也可切换当前视图的排列方式，调整只在当前 HTML 页面内有效。节点内容只读，编辑历史及 DSH 引用属于侧栏。源快照与当前本地草稿冲突时，导出只取已保存版本，不携带会话数据。
