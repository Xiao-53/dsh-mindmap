# 图块 Markdown 与求值契约

状态为计划。此契约适用于节点笔记、DSH atlas 工具及独立 HTML 的共用解析。

## 存储格式

在 Markdown 顶层用独立围栏承载一个 JSON 对象，开启行与结束行各独占一行，正文前后空行分隔。JSON 可多行，内部不加空行。围栏标记固定为 `dsh-plot`，不把普通代码块、行内代码、引用或嵌套示例解释成图块。字段和上限见 [数据模型](../data-model.md)。

```dsh-plot
{
  "version": 1,
  "id": "quadratic",
  "kind": "function",
  "title": "二次函数",
  "xRange": [-3, 3],
  "yRange": [-1, 9],
  "series": [{"expression": "x^2", "label": "平方"}]
}
```

```dsh-plot
{
  "version": 1,
  "id": "observations",
  "kind": "line",
  "title": "观察结果",
  "categories": ["第 1 天", "第 2 天", "第 3 天", "第 4 天"],
  "series": [{"label": "甲", "unit": "次", "values": [0, 4, null, 5]}]
}
```

围栏语法错误、超限、无效数据及未知版本的图块显示简短诊断和可复制原文。对缺结束围栏用确定的局部边界恢复，遇段落分隔空行、下一围栏或 EOF 即停止该坏块的扫描，后续正文继续交给 Markdown 解析；单图块 JSON 输入最多 128 KiB。渲染器不执行图块数据或请求外部资源。读取/比较保留原源码，只有显式写入才保存候选。

## 函数式

- 变量为 `x`、常量为 `pi` 与 `e`。支持有限十进制数字（含科学计数法）、括号、显式 `*`、二元 `+ - * / ^`、一元 `+ -`。幂右结合，比前置一元运算优先；允许 `2^-2`。例如 `-x^2` 等于 `-(x^2)`，`2^3^2` 等于 `2^(3^2)`。
- 单参函数名称为 `sin cos tan sqrt abs exp ln`，三角函数用弧度。调用须带括号。函数承载实数结果，除零、正切极点、平方根负参数、非正数的对数、无实数结果的幂或非有限结果均为不可绘制。
- 输入只通过白名单语法解析并消费完整表达式，嵌套最多 32 层。拒绝隐式乘法、赋值、属性读取、方法调用、任意标识符及程序语句。渲染端采用受控数值求值；既有 KaTeX 从同一表达式排版函数图例，排版失败时仍提供原式文本。
- 曲线先做有界分段采样和视窗裁切。用 AST 的区间判定识别可能跨越除零、正切极点和定义域边界的线段，继续细分仍无法确认连续时断开。避免把视窗外的采样丢失误当作可跨接点。无可绘制点时保留坐标轴和说明。

## 统计数据

- 柱状图共享同类目中心，各系列按既定顺序分组。数值轴含零基线，负值按数据画在基线下。缺值留空，零是实际值。
- 折线按类目或序号顺序绘制，`null` 两侧断开，保留单独有值的标记点。标签拥挤时可抽稀坐标轴标签，完整文本数据始终可读和可复制。
- 所有类型使用文本图例，按不同标记或线型辅助区分系列。样式、刻度和显示位置由插件决定。
