# 快速验收：节点笔记图块

本指南用于图块功能实现后在目标宿主和离线环境手动验收。

## 准备

1. 使用 Node.js ≥24.9、DSH `v0.2.2-rc.3`，启用该版本的原生 skill 入口。固定一台实际验收电脑，记录 CPU、内存、操作系统以及 DSH 和离线浏览器版本，后续用同一环境复测。详情宽度先用 320 px，窄栏另用 260 px。
2. 在仓库根目录运行 `npm ci` 和 `npm run pack:plugin`，按 [插件安装说明](../../docs/plugin-development.md) 将实际生成的 tgz 加到验收 profile。记录升级前后 `lib/client.js`、同图离线 HTML 与 tgz 的字节数。
3. 用 [图块契约](contracts/plot-markdown.md) 准备一张独立地图，其中一份笔记含文字、既有公式、图片及图块，另保留一个普通节点和一处已有选文引用。损坏或未知版本图块应通过复制一个验收文件后在外部手动放入，单独作为历史数据读取样例。
4. 用更新后的 `/mindmap` 经手动发送准备有效图块。准备两张标题及数据相同、ID 不同的函数图，以验证身份区分；另准备图块前后有普通段落的手动编辑样例。

## SC-001 渲染与旧笔记

先复验 [公式快速验收的 16 条样例](../003-latex-formula-preview/quickstart.md)。再打开以下函数图，一张可包含多条曲线。

| 函数 | 可观察结果 |
| --- | --- |
| `x^2` | 原点为顶点，左右对称。 |
| `1/x` | 在 x=0 分为两段，原点两侧无跨接线。 |
| `tan(x)` | 在 ±π/2 断开，0 处过原点。 |
| `sqrt(x)` | 从 (0,0) 起绘，负 x 区域留空。 |
| `ln(x)` | 经过 (1,0)，x≤0 无曲线。 |
| `sin(x)` | 经过 (0,0)，峰值与谷值位于 ±1。 |
| `exp(x)` | 经过 (0,1)，正值递增。 |
| `abs(x)` | 原点有折角，经过 (−1,1) 和 (1,1)。 |

柱状图用类目甲、乙、丙，系列分别为 `[0,4,null]` 和 `[-1,2,3]`，单位「次」。检查同类目分组及零、负、缺值差异。折线图用 `[1,null,0,3]`，单位「次」，检查缺失点断开及孤立值可见。检查图例、单位、图块文本复制与普通代码块、公式并存。

## SC-002 引用、写入与手动边界

1. 在提问框准备文字、一个旧引用及附件，并选中部分草稿。右键第二个同名图块加入提问框，另用图块焦点加 Shift+F10 复验。检查草稿未清空或截断、引用来源正确、无自动发送或保存。点击草稿引用回到目标图。手动发送后检查消息文本中有地图、节点和图块 ID 及内容快照。
2. 依次验收按节点增加第一张图、修改指定同名图、删除指定图。新增使用新 ID，修改保留目标 ID。删除先预览实际图块并经宿主确认。保存后对照另一同名图、无关文字和原布局。
3. 引用后只修改图旁正文并保存，再手动发送图块修改请求。AI 应重新读取并按最新版本保存，同时保留该正文。重复操作，本次在发送前先由 AI 修改目标图块；旧引用请求应停止并说明，保留可读快照。已删除和来源失效同样按契约报告。
4. 普通正文编辑时尝试拖动、键盘删除、跨块剪切或粘贴替换，以及把新图块源码粘贴到正文。既有图块保留，新图块不会由手动路径保存。改动图块相邻文字仍能保存，退出重开后结果一致。
5. 补验缺少统计数据的请求、用户拒绝删除审批及请求提交时版本变化。缺少数据不凭空补造；拒绝与冲突保留已存内容。候选包含新坏块时应得到具体诊断，并保留旧笔记。

## SC-003 窄栏与性能

在 320 px 详情宽度下分别打开两个固定样例各 5 次。函数样例用 `x^2`、`1/x`、`tan(x)` 和默认范围。统计样例用三个各含 100 个值的虚构数列作验收数据，顺序分别为 1–100、100–1、交替 25 和 75。通过手动计时或本地屏幕录制，从详情出现计到坐标、图形和图例可读，记录 10 次耗时及设备信息。每次目标 ≤1 秒。用 260 px 复验图例换行、图面裁切和横向宽度，检查切换笔记和拖宽详情时图面稳定。

## SC-004 断网分享

导出含函数、统计、KaTeX、图片和异常块的单个 HTML，复制到新目录，断网后通过浏览器直接打开。核对保存内容、图形及局部原文回退，检查页面资源加载不依赖 DSH 或网络。验证阅读导航、搜索和复制；遍历详情、标题栏、节点右键、拖动和 Ctrl+Z / Ctrl+Y，确认这些位置没有编辑、保存、布局修改或 DSH 入口。
