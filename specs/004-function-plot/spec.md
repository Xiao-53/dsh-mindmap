# Feature Specification: 节点笔记函数图像与统计图表

**Feature Branch**: main（当前工作分支）

**Created**: 2026-11-18

**Status**: Draft

**Input**: 用图像辅助理解节点知识。函数图和统计图由 AI 按用户请求管理，用户可将指定图块引用到 DSH 提问框。独立 HTML 分享仅供阅读。技术背景见 [可行性调研](research.md)。

## Clarifications

### Session 2026-11-18

- Q: 引用后笔记其他文字发生变化，如何处理图块修改？ → A: 在 /mindmap 说明中提醒 AI 修改前重读笔记，核对图块身份和内容。图块未变就按最新版本继续；图块变了或找不到就停止并说明。提交沿用现有版本校验，无需另设因普通文字变动而重新引用的流程。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 阅读节点中的图像 (Priority: P1)

读者在节点笔记里看到由 AI 根据知识内容生成的函数图或统计图。图块与正文相邻，坐标轴、曲线或数据、图例和文字说明可以一起阅读。

**Why this priority**: 图块用于解释知识，读者打开笔记就能看懂函数变化或数据差异。

**Independent Test**: 打开含二次函数、倒数函数、柱状图和折线图的笔记，核对曲线、数值、标签与正文。在普通笔记编辑模式中尝试直接修改图块，确认图块保持只读。

**Acceptance Scenarios**:

1. **Given** 已保存的节点包含函数图，**When** 打开笔记，**Then** 函数、坐标范围、刻度和曲线对应可读。倒数或正切曲线在间断处断开。
2. **Given** 节点包含柱状图和折线图，**When** 阅读它们，**Then** 类目或点的顺序、数值、单位与已有数据一致。
3. **Given** 用户开启普通笔记编辑，**When** 点击、拖动或尝试剪切、删除、粘贴替换图块，**Then** 图块定义不会被手动更改。图块前后的文本仍可编辑。

### User Story 2 - 把指定图块交给 DSH (Priority: P1)

读者右键图像，选「添加到 DSH 提问框」。输入框加入该图的引用，保留已有草稿。读者补充问题后手动发送，可以请 AI 解释该图、添加相关图、修改目标图或删除它。没有已有图块时，也可通过节点引用或明确描述目标节点，请 AI 添加第一张图。

**Why this priority**: 用户可以直接指出要讨论或修改的图，避免截图和重复描述，也避免误改笔记里的同名图块。

**Independent Test**: 预先在提问框输入一段文字。在一个含两张相同标题的图的笔记中引用第二张图。发送前确认没有写入；随后请 AI 修改它、以它为参照添加一张图、再删除选定的图，核对结果。

**Acceptance Scenarios**:

1. **Given** 提问框有草稿，**When** 用户右键图块并选择添加到提问框，**Then** 已有草稿和附件保留，加入可识别来源的图块引用，未自动发送、调用 AI 或改写笔记。
2. **Given** 两张图同名或数据相同，**When** 用户引用其中一张并明确要求 AI 修改或删除，**Then** 仅该图变化。要求增加相关图时只增加图块，不误改引用图及其他正文。
3. **Given** 图块引用在发送前已失效或正文版本已变化，**When** AI 准备增删改，**Then** AI 依照 /mindmap 说明重读目标笔记。图块身份和内容未变时按最新版本继续；目标图块已变化、已删除或无法核对时停止并说明，保留可读引用。
4. **Given** 用户提出绘图请求但没有所需统计数据，**When** AI 准备添加图，**Then** 说明缺少的数据或按授权取得实际数据，不能凭空补数并当成事实。

### User Story 3 - 在离线分享文件中只读看图 (Priority: P1)

接收者断网打开独立 HTML，看到已保存的函数图、统计图和笔记。可以浏览、选文、复制内容及使用阅读导航。整个离线阅读器仅供阅读。

**Why this priority**: 分享用于传递知识，接收者无需 DSH 或工作区写权限即可浏览。

**Independent Test**: 导出含两类图的导图，把单个 HTML 移到另一目录后断网打开。检查图像、内容复制，以及整个离线页面上是否仍有编辑或宿主动作。

**Acceptance Scenarios**:

1. **Given** 导图含已保存的函数图和统计图，**When** 移动导出的单个 HTML 并断网打开，**Then** 曲线、坐标和统计数据与已保存版本一致。
2. **Given** 一个图块损坏或版本不认识，**When** 在线或离线阅读，**Then** 可查看或复制该处原始内容，邻近图块与正文继续呈现。
3. **Given** 分享文件已打开，**When** 浏览节点笔记、画布、菜单与键盘操作，**Then** 保留阅读与复制。编辑、增删内容、布局修改、保存、编辑撤销及发送到 DSH 的功能均不可用。

### Edge Cases

- 倒数在 x=0 两侧断开，正切不跨渐近线，平方根与对数只显示有实数结果的部分。视窗内无可绘制点时保留坐标轴与可读说明。
- 区间反序、非有限数、表达式不受支持、统计标签和值数量不匹配时给出局部提示。无效 AI 候选不能覆盖原有数据。
- 统计缺值须明确标注。折线缺值处断开，不按零值补齐。
- 打开笔记、显示图像或加入 DSH 草稿均不会写入。普通公式与普通代码块仍照常阅读。
- 右键命中的图块是唯一引用对象。键盘能从聚焦图块调出同一操作。离线没有该操作。
- 窄栏图例可换行，坐标轴、曲线与统计图留在图块内。可读文本应含函数式或数据及单位，不能仅以颜色传达含义。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**：函数图、统计图均作为节点正文里的只读图块呈现。在线的普通笔记编辑也不得通过按钮、拖拽、键盘删除、剪切、粘贴替换或跨图块选区来添加、修改或删除图块。
- **FR-002**：函数图首版允许同轴显示 1 至 3 条单变量实函数，每条最多 256 字符。支持显式乘号、四则、括号、幂、pi/e 以及 sin、cos、tan、sqrt、abs、exp、ln。默认 x、y 范围均为 [−5,5]。AI 可设置严格递增的有限上下界，曲线在视窗内裁切，示例间断不跨接。
- **FR-003**：统计图首版支持柱状图与折线图，各图含 1 至 3 个有序数据系列，每系列至多 100 个值。显示实际分类或序号、系列名称、数值及数据原有的单位；缺值与零分别表示。AI 不得把推测数值作为真实数据写入。
- **FR-004**：在线右键图块或使用键盘等效操作可选「添加到 DSH 提问框」。插入一份可辨认图块的引用并保留草稿、附件和原会话。引用含来源地图、节点、图块身份和可读内容快照，点击可按来源回跳。引用动作不会自动发送或改写。
- **FR-005**：只有在用户手动发送明确请求后，AI 才能按现有版本保护及权限路径增加、修改或删除图块。没有图块时通过指定节点添加。/mindmap 说明须提示 AI 修改前重读，核对引用图块的身份和内容。只有无关文字变化时可使用最新版本继续；目标图块已变化、已删除或无法核对时停止。既有提交版本校验继续处理读取后发生的变化；失败保留原内容并提示。更新只涉及指定图块及用户明确要求的相邻说明。
- **FR-006**：有效图块保存足以恢复的函数式和范围，或有序统计数据及标签。修改时保留图块身份。阅读复制可取得文本表达式或数据，不要求屏幕截图或手动改写源码。已有笔记无需迁移。
- **FR-007**：独立 HTML 在断网及新目录中可显示函数图和统计图。整个离线阅读器不提供编辑、增删改、拖动保存、撤销重做、工作区写入或 DSH 交互，仅保留阅读、查找、浏览与复制。
- **FR-008**：不受支持或损坏的图块以可复制的原文和简短提示回退，不能让其他内容失效。图块数据不得执行一般程序、访问网页或文件。在线和离线均适用。
- **FR-009**：通过文本标签、线型或清晰标记区分曲线及数据系列。窄栏可阅读，支持用文字获取函数式、范围或统计值。

### Key Entities *(include if feature involves data)*

- **笔记图块**：节点正文中的一处图形内容，具有可区分的身份、类型和可读标题或标签。函数图含有序表达式与显示范围，统计图含有序类别和数据系列。
- **图块引用**：加入提问草稿的来源与内容快照，能够区分相同标题的多次出现。
- **AI 图块变更**：用户手动发送后提出的新增、修改或删除，只在目标、来源版本与候选数据有效时提交。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**：16 条既有公式样例保持原结果。八类函数样例的关键点或有效域符合预期，倒数与正切间断处 0 次跨接。各一张柱状图和折线图的标签、数值和单位均与验收数据一致。
- **SC-002**：依次验收引用、AI 添加、修改同名图中的指定一张、删除指定图、旁边文字更新后成功定位、拒绝失效引用六项，6/6 符合预期。仅引用时宿主发送和笔记写入次数均为 0；手动笔记编辑中测试拖拽、删除、剪切、粘贴替换均不改变图块。
- **SC-003**：在目标 DSH 桌面、320 px 详情宽度下，对含三条曲线和含三个系列的样例图各开 5 次，每次从详情出现到图块可读 ≤1 秒。260 px 窄栏下图例不撑宽侧栏。
- **SC-004**：单个分享 HTML 断网移到新目录后，函数图、统计图和异常图块均满足各自预期。检查笔记、画布、菜单和快捷键，发现 0 个离线编辑或 DSH 操作入口。

## Assumptions

- 首版统计图以柱状图和折线图为主。其他统计图、滑块、拖动点、参数方程、隐式方程及自动把任意 LaTeX 转为函数暂不纳入。
- 在线的普通文字、图片与 KaTeX 公式继续按各自现有规则编辑。图块的 AI 管理边界单独适用。
- 首版不新增专用聊天入口。已有 DSH 提问与节点引用能力承接请求。验收设备与样例在规划阶段固定，上述指标尚未实测。
