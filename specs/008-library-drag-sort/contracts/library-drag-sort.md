# Interface & Interaction Contract: 管理页拖放与手动排序

**Feature**: `008-library-drag-sort` | **Date**: 2026-11-18 | **Spec**: [spec.md](spec.md)

## 1. 宿主 RPC 与存储契约

本功能不新增宿主 RPC 接口，继续复用既有 `saveLibrary`、`list`、`purge` 接口：

- **客户端保存调用**：`MapLibrary` 通过 `save(nextLibrary)` 调用宿主 `saveLibrary(data, currentLibrary, signal)`，基于 `library.json` 版本条件写入（`createIfAbsent` / `replaceIfVersion`）。
- **版本冲突与失败保护**：若 `library.json` 在拖动期间被外部变更或写入失败，服务端返回 `version_conflict` 或对应错误，前端保留既有列表展示并显示错误提示，不误报成功。
- **永久删除清理**：服务端 `purge` 成功删除导图后，在清理 `mapFolders` 的同时同步移除 `rootMapOrder` 与 `folderMapOrders` 中对应导图 ID。

## 2. 拖放语义契约（Drag-and-Drop Matrix）

以下矩阵定义不同拖动源与悬停目标组合的行为；若当前处于**搜索筛选状态**（`query.trim().length > 0`）、**回收站视图**（`trash === true`）或**加载/提交忙碌中**（`disabled === true`），所有拖动与落放均禁用。

| 被拖动对象（`dragEntries`） | 悬停/释放目标 | 指针纵向分区 | 视觉指示 | 释放后结果 |
| --- | --- | --- | --- | --- |
| 纯导图（1 张或多张） | 任意有效导图行（根目录或已展开文件夹内） | 上半区 | 目标导图上方显示横向插入指示线 | 归属改为目标导图所在层级，按原相对顺序插在目标导图之前（若无变化则跳过保存） |
| 纯导图（1 张或多张） | 任意有效导图行（根目录或已展开文件夹内） | 下半区 | 目标导图下方显示横向插入指示线 | 归属改为目标导图所在层级，按原相对顺序插在目标导图之后（若无变化则跳过保存） |
| 纯导图（1 张或多张） | 文件夹标题行 | 整行 | 文件夹行高亮为移入目标 | 归属改为该文件夹，追加到该文件夹导图末尾并自动展开该文件夹 |
| 纯导图（1 张或多张） | 已展开文件夹的空占位区或子列表底部空白 | 区域内 | 文件夹内部/最后一张导图下方指示 | 归属改为该文件夹，追加到该文件夹导图末尾（不冒泡至根目录） |
| 纯导图（1 张或多张） | 「全部导图」标题区或根目录列表空白区 | 区域内 | 根目录区域高亮 | 移出到根目录，追加到根目录导图末尾 |
| 纯文件夹（1 个或多个） | 另一个不在拖动集合内的文件夹标题行 | 上半区 | 目标文件夹上方显示横向插入指示线 | 调整文件夹顺序插在目标文件夹之前；**绝不嵌套** |
| 纯文件夹（1 个或多个） | 另一个不在拖动集合内的文件夹标题行 | 下半区 | 目标文件夹下方显示横向插入指示线 | 调整文件夹顺序插在目标文件夹之后；**绝不嵌套** |
| 纯文件夹（1 个或多个） | 导图行 / 文件夹内子列表 | 任意 | 无插入线（`dropEffect = 'none'`） | 阻止冒泡与嵌套，松手不生效 |
| 多选混合（同时含文件夹与导图） | 任意有效导图行 | 上半区 / 下半区 | 目标导图上/下方显示横向插入指示线 | 仅移动所选导图到目标位置，所选文件夹保持原顺序不混排 |
| 多选混合（同时含文件夹与导图） | 文件夹标题行（排序区） | 上半区 / 下半区 | 目标文件夹上/下方显示横向插入指示线 | 仅重排所选文件夹到目标文件夹前/后，所选导图保持各自归属与顺序 |
| 任意对象 | 无效区域 / 列表外 / 按 `Esc` | — | 清除全部指示线与高亮 | 取消拖动，不触发保存，所有归属与顺序保持原样 |

## 3. 多选与重排边界约束

1. **目标在选中集合内**：当目标导图（或目标文件夹）本身就是当前 `dragEntries` 的一员时，不显示插入线，松手不触发变更。
2. **多选相对顺序保留**：批量拖动多张导图时，先按当前画面展示顺序提取这些导图，再整体插入目标锚点之前或之后，保证它们之间的原有相对顺序不反转、不打乱。
3. **无变化静默跳过**：移动前与移动后计算得到的 `folders` 顺序、`mapFolders` 映射与目标层级序列完全相同时，不调用 `saveLibrary`，也不弹出成功提示或误报。
4. **拖放不误触发点击**：拖拽结束时确保不触发导图按钮的打开点击事件或文件夹折叠切换事件。
