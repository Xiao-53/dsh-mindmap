# Validation Quickstart: 思维导图管理页拖放定位与手动排序

**Feature**: `008-library-drag-sort` | **Date**: 2026-11-18 | **Spec**: [spec.md](spec.md)

本指南用于核验管理页拖放移动与手动排序的完整闭环，包含自动化单元/集成检查与 DSH 侧栏人工验收步骤。

## 1. 自动化构建与检查（开发阶段执行）

在仓库根目录执行：

```powershell
npm run typecheck
npm run test
npm run build
```

重点关注：
- `tests/shared/` 中针对目录排序、跨文件夹移动、多选重排、无变化跳过、单层文件夹规范化及删除/还原兼容的单元测试全部通过。
- `tests/integration/local-files.test.ts` 中 `library.json` 读写、版本冲突检测、历史 `parentId` 数据兼容及 `purge` 清理排序残留全部通过。
- `tests/integration/dom.test.ts` 中管理页渲染、搜索禁用拖拽、拖放插入指定导图下方/上方、拖入已展开文件夹不冒泡回根目录、文件夹手动排序不嵌套全部通过。

## 2. DSH 侧栏人工验收步骤（交付后由用户/验收执行）

### 前置准备
在工作区准备至少 2 个文件夹（如 `F1`、`F2`，其中 `F1` 内含 3 张导图 `M1`、`M2`、`M3`，`F2` 为空或折叠）以及根目录至少 3 张导图（`A`、`B`、`C`）。

### 用例 1：同级手动排序与首位落位（对应 SC-001）
1. 在根目录拖动 `C` 到 `A` 下方（接近 `A` 下半部分），确认 `A` 与 `B` 之间出现横向插入指示线。
2. 松手放下，确认列表变为 `A`、`C`、`B`。
3. 拖动 `B` 到 `A` 上半部分，确认 `A` 上方出现横向插入指示线；松手后 `B` 排在第一位。

### 用例 2：直接拖入已展开文件夹指定导图下方（对应 SC-001）
1. 展开 `F1`，将根目录导图 `B` 拖到 `M1` 与 `M2` 之间（`M1` 下半部分），确认 `M1` 下方出现横向插入指示线（且根目录外框不高亮）。
2. 松手放下，确认 `B` 进入 `F1` 并精准位于 `M1` 与 `M2` 之间，未意外弹回根目录。

### 用例 3：从文件夹拖出到根目录指定导图下方（对应 SC-001）
1. 将 `F1` 内的 `M2` 直接拖到根目录导图 `A` 下方并松手。
2. 确认 `M2` 移出 `F1` 并精准排在 `A` 下方。

### 用例 4：文件夹手动排序与禁止嵌套（对应 SC-001）
1. 拖动文件夹 `F2` 到文件夹 `F1` 上半部分，确认 `F1` 上方出现横向插入指示线。
2. 松手放下，确认 `F2` 排到 `F1` 前面，且没有嵌套进 `F1`；所有文件夹仍整体位于根目录导图上方。

### 用例 5：持久化保留与增删还原兼容（对应 SC-002、SC-003）
1. 打开任意导图后再点击返回「全部导图」，以及刷新页面 / 重开工作区，确认文件夹和导图排序完全保持。
2. 新建 1 个文件夹并新增 1 张导图，确认新项目出现在对应末尾，原有手动顺序不变。
3. 将 1 张在文件夹内的导图删至回收站后再还原，确认回到原文件夹末尾且其余导图顺序不变；再删除 1 个非空文件夹，确认其导图移至根目录末尾且原有根目录导图顺序不变。
4. 在搜索框输入关键词筛选时尝试拖动，确认搜索筛选期间不允许拖动重排，清空搜索后原顺序完好。
