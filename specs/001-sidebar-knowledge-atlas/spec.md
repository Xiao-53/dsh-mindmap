# Feature Specification: DSH 侧栏知识图谱学习插件

**Feature Branch**: `main`（本次未创建分支）

**Created**: 2026-11-14

**Status**: Draft — 需求规范已整理，尚未进入技术规划与实现

**Input**: 参照 `knowledge_atlas_demo_v17.html` 设计侧栏，拆解并规划完整插件；知识图谱导出使用 HTML，不使用 JSON，便于分享。

**补充范围**: 聊天交互与可钻取知识地图结合；DSH 通过插件原生工具创建、扩展和维护知识结构；结构化地图数据、Markdown 详情及用户布局分离保存；工作区自动建立专用存储目录，每张地图独立文件夹。用户提供的五阶段开发顺序已明确撤回，不作为实施顺序依据；保留下文既有分期，新补充能力暂不另行排期。

## Clarifications

### Session 2026-11-14

- Q: 同一个知识节点出现在多个视图中时，它的子图应如何关联？ → A: 用户要求直接遵循 `docs/knowledge_atlas_demo_v17.html`，动画、排版、节点及已有交互均按该文件，不另行设计选项。源码中节点共用同一子图入口，面包屑与上一级按目标视图的父级路径导航。
- Q: 结构与布局文件采用 JSON，还是 YAML？ → A: A，采用 JSON 保存结构与布局、Markdown 保存笔记；用户同时要求设计思维导图生成与修改提示词。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在侧栏阅读分层知识图谱 (Priority: P1)

学习者在 DSH 会话旁打开图谱，从课程总览进入模块与知识点，阅读概念、公式、例题，同时理解当前位置与知识关系。

**Why this priority**: 稳定阅读是引用和后续维护的基础。

**Independent Test**: 打开包含三层视图、共享节点、两类关系和长笔记的图谱，独立验证导航及阅读。

**Acceptance Scenarios**:

1. **Given** 有效图谱文件，**When** 从原生侧栏入口选择并打开，**Then** 显示图谱名称、当前视图、分组节点、关系图例及路径，不要求 Better Sidebar。
2. **Given** 节点关联子图，**When** 点击节点，**Then** 按 v17 进入该节点关联的同一子图，并按目标视图的父级路径更新面包屑与上一级；当前已在该子图或节点没有子图时打开详情，有子图的节点也可通过“本节笔记”阅读自身内容。
3. **Given** 父视图已经平移缩放，**When** 下钻再返回，**Then** 恢复父视图的阅读位置；层数根据实际内容显示，不固定为三层。
4. **Given** 侧栏宽度为 360、480 或 720 像素，**When** 浏览和打开详情，**Then** 返回、关闭、搜索及缩放均可操作，长笔记可独立滚动，不靠缩小全部文字适应侧栏。
5. **Given** 合法空图谱或读取失败，**When** 打开，**Then** 分别显示空状态或具体错误与重试入口，不生成虚构内容。
6. **Given** 用户或 DSH 提供有效 JSON 结构和 Markdown 内容，但尚无布局文件，**When** 插件打开地图，**Then** 使用插件内置完整模板填充内容并计算初始布局，无需 DSH 提供 HTML、坐标或原型文件。

### User Story 2 - 选中文本加入草稿并回到来源 (Priority: P1)

学习者选中笔记文字，作为可读引用加入所属会话输入框，自行编辑与发送；点击草稿引用回到来源。

**Why this priority**: 这是已确认的首期学习闭环。

**Independent Test**: 在已有文字、引用和附件的草稿中加入选文再点击引用，检查草稿完整、来源正确且没有自动发送。

**Acceptance Scenarios**:

1. **Given** 详情有非空选区，**When** 执行“加入输入框”，**Then** 插入所选文本及图谱、节点来源，已有草稿、引用及附件完整保留，不发起模型请求。
2. **Given** 来源未变化，**When** 点击草稿引用，**Then** 打开对应图谱与视图，突出节点，在详情定位选文；同一节点出现在多处时优先返回引用产生的视图。
3. **Given** 原视图出现位置已删除但节点仍在，**When** 回跳，**Then** 定位同一节点的可用位置并说明变化，不根据同名标题猜测目标。
4. **Given** 选文被改写或无法唯一定位，**When** 回跳，**Then** 打开节点并提示内容变化，不假装精确定位；节点或文件失效时显示原因，始终保留引用原文。
5. **Given** 插入期间切换会话、草稿变化或输入框不可写，**When** 无法安全插入，**Then** 不覆盖草稿、不插入其他会话，保留待引用文本供用户在原会话重试。
6. **Given** 草稿已有引用，**When** 用户手动发送，**Then** 模型获得可读选文和来源说明，而非只有标题或路径；不擅自补入整份图谱。
7. **Given** 完整版本中用户右键选中节点，**When** 执行“加入输入框”，**Then** 加入节点标题、摘要和可读笔记及来源引用，不自动包含子图或相邻节点；返回定位该节点，内容超出宿主限制时明确失败，不静默截断。
8. **Given** 完整版本中用户选定节点或文字，**When** 执行“针对内容提问”，**Then** 生成带所选内容引用的可编辑问题草稿，保留已有草稿，由用户手动发送，不以此操作自动提交输入框。

### User Story 3 - 搜索、定位与复制知识 (Priority: P2)

学习者搜索当前图谱各层的知识点，定位并复制笔记，无需逐层翻找。

**Why this priority**: 图谱扩大后的必要阅读能力，纳入首期。

**Independent Test**: 搜索跨层节点、同名标题、正文词语与无结果关键词，验证定位和复制。

**Acceptance Scenarios**:

1. **Given** 命中其他层级，**When** 选择搜索结果，**Then** 打开所在视图及详情；结果展示路径以区分同名节点，不无提示截断结果。
2. **Given** 无匹配，**When** 搜索，**Then** 显示无结果，可清空后返回阅读。
3. **Given** 笔记含公式、示例与提醒，**When** 复制笔记，**Then** 得到按阅读顺序组织的可读文本；失败提示原因，原文仍可选择。
4. **Given** 使用键盘，**When** 聚焦节点、打开操作菜单、搜索、关闭浮层，**Then** 可完成等价阅读和引用操作；关闭后焦点回到触发位置。

### User Story 4 - 持续维护内容与布局 (Priority: P2)

用户通过 DSH 让 AI 修改独立内容文件，图谱保持一致呈现；后续在插件内轻量编辑内容与布局。

**Why this priority**: 支持长期维护；外部文件刷新归首期，界面编辑归第二期。

**Independent Test**: 外部修改节点，再模拟无效结构、保存失败和编辑冲突，检查刷新与修改保留。

**Acceptance Scenarios**:

1. **Given** 首期已打开有效图谱，**When** 外部仅修改某节点，**Then** 显示新内容，其他节点身份、内容和呈现规则不变；保持当前阅读位置，当前节点删除时说明并返回可用视图。
2. **Given** 外部修改产生重复身份、悬空关系或视图父级循环，**When** 加载，**Then** 指出具体对象，保留最近有效画面并标明旧版本，不静默修复或覆盖源文件。
3. **Given** 第二期新建或编辑节点、笔记、关系、分组与视图，**When** 保存重开，**Then** 内容一致；拖动节点时连线跟随且不误触下钻，保存的位置重开仍在。
4. **Given** 未保存编辑，**When** 外部更新同一图谱，**Then** 提示冲突，允许保留本地副本或放弃本地后加载外部版本，不自动覆盖任一版本。
5. **Given** 删除节点或子图，**When** 执行，**Then** 先说明受影响关系与出现位置，确认后无悬空关系；本次编辑可撤销。
6. **Given** 保存失败或关闭有未保存编辑的图谱，**When** 用户继续操作，**Then** 失败保留内容供重试；关闭或切换前提供保存、放弃与取消。
7. **Given** 新建视图或加入未布局节点，**When** 自动布局，**Then** 自动为节点安排不重叠的位置并连接正确端点；已有手动位置保持不变，除非用户明确选择重新布局该视图。
8. **Given** 已有手动位置，**When** 仅修改标题或 Markdown 笔记，**Then** 知识内容更新不重写布局；仅拖动节点也不改变节点正文、身份与关系。

### User Story 5 - 导出独立 HTML 分享 (Priority: P2)

学习者将图谱导出为单个 HTML，接收者无需 DSH 即可离线阅读、搜索与逐层探索。

**Why this priority**: 用户明确要求的分享能力，作为第三期完整交付内容，不用 JSON 导出替代。

**Independent Test**: 导出含子图、共享节点、公式与独立笔记的图谱，在没有 DSH 的浏览器断网打开。

**Acceptance Scenarios**:

1. **Given** 有效图谱，**When** 默认导出，**Then** 得到单个 HTML，包含全图、所有子图、关系和笔记；断网仍能下钻、返回、平移、缩放、搜索与看详情。
2. **Given** 选择“仅当前视图”，**When** 导出，**Then** 包含本视图节点、关系及完整笔记，明确标示范围；未包含子图的入口不可点击并说明未导出，不留假链接。
3. **Given** 内容关联独立文件，**When** 导出，**Then** 将范围内内容纳入成品；缺失或无权限部分在导出前列出，允许取消或明确选择省略，成品标示缺失内容。
4. **Given** 导出前查看范围，**When** 确认，**Then** 不包含草稿、聊天记录、凭据、本机绝对路径；外部来源链接可保留，但核心阅读不依赖网络。
5. **Given** 接收者打开成品，**When** 操作，**Then** 不出现“加入输入框”“提问 DSH”等宿主动作，不访问原作者本地文件。
6. **Given** 存在未保存编辑，**When** 导出，**Then** 明示导出当前有效编辑快照；导出不自动写回源文件，未保存状态保持。

### User Story 6 - 让 DSH 逐步构建地图并按图保存 (Priority: P2)

学习者在对话中要求 DSH 创建地图、补充知识或调整关系，DSH 通过插件提供的原生工具读取并修改知识；产物自动归入当前工作区中每图独立的文件夹，后续对话可以继续维护。

**Why this priority**: 从一次性静态图扩展为持续可维护的学习地图；本故事定义完整产品范围，不指定新增开发顺序。

**Independent Test**: 在一个工作区创建两张同名地图，再读取、扩展、修改、连接和删除其中一张图的节点，重开并验证另一张图及已有手动布局没有变化。

**Acceptance Scenarios**:

1. **Given** 工作区尚无插件数据目录，**When** 首次创建地图，**Then** 自动建立专用根目录及该图独立文件夹；随后创建另一张同名图时使用不同身份和目录，不覆盖前图。
2. **Given** 已有地图，**When** DSH 使用原生工具查询、创建、修改、连接或删除节点及关系，**Then** 结果明确返回目标地图、受影响对象与成功或失败状态；成功后侧栏更新，失败不声称完成。
3. **Given** 对话要求扩展某节点，**When** 创建内部子图，**Then** 继承正确导航路径，不限制为固定层数；已有节点身份和未受影响的手动位置保持。
4. **Given** AI 修改期间内容版本已变化，或请求含不存在的节点、无权限路径，**When** 执行工具，**Then** 返回明确冲突或错误，保留最新有效内容；一个工具操作不留下半完成的结构与笔记。
5. **Given** 图谱标题改变或再次打开工作区，**When** 继续编辑，**Then** 使用原图身份及目录，不因同名或改名另建图；只列出有效地图目录，未知已有文件不被接管或覆盖。
6. **Given** 目录不可写、磁盘空间不足或创建中断，**When** 创建或保存，**Then** 明确失败且不将残缺产物列为正常地图，已有地图保持完整，可重试。
7. **Given** 用户导出 HTML，**When** 未另选目标，**Then** 默认保存至该图目录内的导出区；重复导出不静默覆盖既有分享文件。

### Edge Cases

- 长标题可换行或截断后查看全文；长笔记独立滚动；公式选文保留原字符、上下标与换行。
- 连续导航、拖动后松手及会话切换期间的异步操作，不造成重复下钻、错位或串会话。
- 同名节点、共享节点、重复选文依靠稳定身份区分；无法唯一定位选文时回退至节点并说明。
- 知识关联可形成循环；视图父级循环属于结构错误，不能导致无限导航。
- 文件移动、删除、权限撤销时保留可读引用并明确失效，不按名称猜测来源。
- 侧栏关闭或插件停用不自动发送草稿或写回未确认编辑；再次打开从已保存内容恢复。
- 图谱包含看似脚本的内容时按学习内容展示，不允许其执行代码或读取本地文件。
- 地图同名、工作区切换、目录名非法或路径越界时，以工作区和稳定身份确定目标；不得写入其他工作区或覆盖不属于插件的文件。
- “无限层级”指不设置固定业务深度上限，不承诺无限资源；深层路径可滚动与返回，资源不足时提示并保留数据，不静默截断层级。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001（首期）**: 面向 DSH `v0.2.2-rc.3` 原生侧栏提供图谱打开与切换入口；每次引用绑定来源会话，不依赖 Better Sidebar。（US1、US2）
- **FR-002（首期）**: 支持图谱、分层视图、节点详情；视图层级与知识关系分别表达，同一节点可在多个视图复用并共用同一子图入口，面包屑与上一级遵循视图父级路径，行为与 v17 一致；知识关系不限制为单父树。（US1、US2）
- **FR-003（首期）**: 展示分组、节点标题/摘要/类别、带方向的概念依赖及补充/对比关系；线型与图例共同区分关系，每条线连接对应卡片边界。（US1）
- **FR-004（首期）**: 提供面包屑、上一级、本节笔记、平移、缩放、适配视图，层数从内容得出，往返恢复阅读位置。（US1）
- **FR-005（首期）**: 详情支持简介、核心理解、公式/规则、示例、提醒；缺失栏目不显示空占位；正文可选择，公式至少保留可读数学字符、上下标与换行。（US1、US3）
- **FR-006（首期）**: 遵循下述视觉与侧栏适配要求，支持键盘和减少动态效果偏好，不依赖仅鼠标右键的入口。（US1、US3）
- **FR-007（首期）**: 搜索当前图谱全部层级的标题、摘要和笔记文本，显示结果路径并定位命中，无结果时可返回阅读。（US3）
- **FR-008（首期）**: 详情非空选文提供“加入输入框”，右键菜单之外提供可发现的等价入口；空选区不提交历史残留选文。（US2）
- **FR-009（首期）**: 插入引用保留草稿、已有引用和附件，失败可重试；不自动发送、不直接提问、不向其他会话兜底插入。（US2）
- **FR-010（首期）**: 引用保存文本快照、图谱/节点身份、来源视图及选文定位线索；改名和重排不改变身份。（US2）
- **FR-011（首期）**: 点击草稿引用定位来源；内容变化或失效时按 US2 分级说明，保留原文；手动发送提供可读文本和来源。（US2）
- **FR-012（首期）**: 提供整篇笔记复制及失败反馈，复制不触发加入草稿。（US3）
- **FR-013（首期）**: 插件维护完整界面模板，读取独立 JSON 结构和 Markdown 内容，填充模板并生成侧栏界面；用户或 AI 局部修改后刷新，未修改节点身份和整体风格保持。DSH 不负责生成界面或布局坐标，无布局的新图由插件计算初始位置。（US1、US4）
- **FR-014（首期）**: 加载检查必要字段、唯一身份、引用目标和视图父级无环；指出具体问题，不误拒合法知识关系循环。（US4）
- **FR-015（首期）**: 外部有效更新反映至视图；无效更新保留最近有效画面并标记旧版本；初次无效显示错误，不伪造内容。（US4）
- **FR-016（第二期）**: 支持新建图谱、增删改节点和笔记、组织视图与分组、维护两类关系，保存重开一致。（US4）
- **FR-017（第二期）**: 支持节点位置调整、连线跟随、位置保存及本次编辑撤销；拖动不触发点击。（US4）
- **FR-018（第二期）**: 显示已保存/未保存/失败/冲突状态；关闭与切换时保护编辑；冲突时不静默覆盖，失败可重试。（US4）
- **FR-019（第三期）**: 分享导出使用单个可独立打开的 HTML，不提供 JSON 分享导出；默认全图，可选当前视图，明确范围。（US5）
- **FR-020（第三期）**: 导出保留一致视觉及范围内的导航、详情、搜索、缩放和平移，核心阅读断网可用，无需 DSH 或账户。（US5）
- **FR-021（第三期）**: 导出前展示范围、内容数量和缺失项；仅纳入知识及必要阅读功能，排除会话状态、凭据、本机绝对路径及宿主动作。（US5）
- **FR-022（全部阶段）**: 内容不能作为任意代码运行；文件访问遵守宿主授权范围，权限不足明确提示且不绕过。（US4、US5、边界案例）

以下新增需求属于完整产品范围，具体纳入哪个实施批次留待后续规划，不改变既有三期顺序：

- **FR-023**: 提供供 DSH Agent 调用的原生工具能力，覆盖地图创建/读取、节点与关系增删改查、子图扩展及 Markdown 笔记维护；准确报告操作结果，不依赖重写整份 HTML。（US6）
- **FR-024**: AI 修改必须使用稳定目标身份并检查版本与结构；冲突或无效操作不得破坏最近有效内容，单次工具操作失败不留下部分知识修改。（US6）
- **FR-025**: 在当前工作区自动创建插件专用数据目录，每张地图使用独立文件夹；目录在首次创建地图时建立，同名地图隔离，改标题保持原目录与身份。（US6）
- **FR-026**: 地图结构采用 `map.json`，详细知识采用 Markdown，由 DSH 准备或修改内容；`layout.json` 由插件独立生成和维护，不是 DSH 的内容输出。地图文件夹包含本图结构、详情、布局、必要本地资源及 HTML 导出，跨工作区不串写。具体信息与字段见[存储契约](../../docs/mindmap-storage-format.md)。（US4、US6）
- **FR-027**: 自动布局为新图和新增节点提供可用位置，基准图谱卡片不重叠；已有手动位置优先，只有显式重新布局才整体调整该视图，且可撤销。（US4）
- **FR-028**: 支持递归下钻而不硬编码层级上限，提供完整路径和返回入口；至少验证连续 20 层的导航、保存及重开，拒绝视图父级循环。（US6）
- **FR-029**: 完整版本支持节点和选文加入草稿，也支持为两者准备问题草稿；保持首期不自动发送的约定，节点引用范围按 US2 场景7定义。（US2）
- **FR-030**: `docs/knowledge_atlas_demo_v17.html` 为动画、排版、节点及已有交互的直接验收依据，按原文件呈现，不另行设计；输入端点采用雾霾蓝（#8699aa）实心圆，输出端点采用灰豆沙（#b38c97）空心圆与 2px 描边。进入与退出子图均沿用原型的 180ms 旧图退出、完全透明时切换、320ms 新图淡入，合计 0.5 秒；新图不做位移或缩放入场，不出现重影或回弹，减少动态效果偏好可跳过动画。（US1、SC-011）

### 原型拆解与视觉要求

已读取并核对 [knowledge_atlas_demo_v17.html](../../docs/knowledge_atlas_demo_v17.html) 的样式与交互源码，本轮未做浏览器渲染验收。动画、排版、节点、连线端点、详情面板、菜单及导航按该文件直接实现与验收，不仅保留大致风格，也不另行设计方案。文件内部页面标题仍标 v12，以文件 v17 的实际内容为准。既有明确产品要求（HTML 分享、真实 DSH 草稿交互、动态层数及分期）继续适用；示例学科不构成内置课程要求。

| 区域 | 保留的设计 | 产品化处理 |
| --- | --- | --- |

### 产品范围与分期

本规范是完整产品蓝图，期次是建议交付顺序，不是本轮实现命令。后续技术规划先覆盖首期，再分别安排后续阶段。

本次补充规划中的“五阶段开发顺序”经用户明确撤回，不替换此处既有三期建议。FR-023～030 是新增完整产品要求，尚未分配实施批次；技术规划时按依赖纳入，不由本轮自动排期。

| 阶段 | 用户获得的结果 | 范围 | 退出条件 |
| --- | --- | --- | --- |
| 首期：阅读与引用闭环 | 读图、搜索、选文入草稿、回跳及外部文件刷新 | FR-001～015、022 | US1、US2场景1～6、US3、US4场景1～2、SC-001～005、008通过 |
| 第二期：内容与布局维护 | 新建、轻量编辑、拖动、保存、撤销与冲突恢复 | FR-016～018、022 | 首期稳定；US4场景1～6及SC-006通过 |
| 第三期：HTML分享 | 全图或当前视图的独立离线HTML | FR-019～022 | 内容与身份规则稳定；US5及SC-007通过 |

首期图谱由用户或 AI 准备独立 JSON 和 Markdown 内容文件，插件用完整模板呈现并处理初始布局；不要求首期内置知识内容生成器或可视化编辑器。HTML 分享属于明确产品范围；内部独立数据文件不等于面向用户提供 JSON 导出。

当前不纳入：未经用户发送的问题自动提交、持续监听所有聊天并自动建图、知识库检索服务、多人协作、云同步、账号系统、进度测验与课程规划系统、任意网页执行、任意 HTML 导入、图片/PDF 导出、完整文档编辑器。用户在对话中明确要求 DSH 通过工具建图属于完整范围。首期保证草稿引用回跳及发送后的可读来源；已发送历史消息的可点击回跳待官方契约核实后另行规范。

### 工作区存储与职责边界

- DSH Agent 负责讲解、生成 JSON/Markdown 内容与提出结构修改；插件原生工具负责查询及受控修改，插件持有完整界面模板，负责填充内容、布局、连线、动画、导航和交互；本地文件负责持久保存。HTML v17 是插件开发参考，不进入 DSH 内容生成提示词。
- 默认根目录暂定为工作区内的 `dsh-knowledge-maps/`，每图使用稳定身份对应的子目录。首次创建地图时自动建立，单纯浏览插件或切换会话不产生空地图文件夹。本轮只记录产品行为，不提前创建占位产物目录。
- 每图采用 `map.json` 保存格式版本、稳定地图身份、标题、入口视图、节点、视图、分组与关系；`layout.json` 由插件按视图和节点身份保存位置、宽度、手动布局标记及分组区域。新图或新增节点缺少布局是合法输入，由插件补齐；已有手动位置保留。正文与布局不得混存，改标题不改变身份。
- 节点通过 `notePath` 关联 Markdown 详情，默认使用 `notes/<节点ID>.md`，没有正文不生成空文件；必要资源存放于 `assets/`，HTML 分享文件存放于 `exports/`，目录按需创建。用户调整位置不得改写知识正文，内容变化不得重置已保存的手动位置。
- 引用快照随 DSH 草稿引用保存，包含原文、地图/节点/视图身份、选文前后文与内容指纹；会话绑定和临时阅读状态不写入地图目录。格式版本不代替内容版本检查，外部修改依据实际内容变化检测。
- [存储契约](../../docs/mindmap-storage-format.md)明确必填字段、节点与子图关联、关系展示、Markdown 分节及数据校验；[生成与修改提示词](../../docs/mindmap-authoring-prompts.md)据此约束内容生成与局部修改。工具签名、实际写入及事务能力仍需后续技术规划验证，提示词不代表相关能力已经实现。
- 文件夹名不直接使用未经处理的用户标题；同名不覆盖、改名不改变身份，路径始终位于所属工作区的数据根目录。遇到已有不明目录或文件时报告冲突，不自动接管。
- 默认 HTML 导出保存在所属地图目录内，允许用户另选分享位置；不提供 JSON 分享导出。目录内容仅限地图产物，不保存聊天会话、凭据或机器状态。
- 优先复用 DSH 原生能力并评估成熟图谱库，是否采用以及采用哪一个需有官方契约与需求验证；不在此处指定框架或库。

### Key Entities *(include if feature involves data)*

- **知识图谱**：独立学习主题，具有稳定身份、名称、入口视图、版本和节点集合。
- **视图/子图**：某层阅读场景，包含父视图、焦点知识点、分组、节点出现位置和关系；按 v17 的父级路径生成面包屑与上一级，导航层级无环。
- **知识节点**：稳定身份、标题、摘要、类别、笔记及可选子图入口；可跨视图复用并共用同一子图入口，改名移动不产生新身份。
- **节点出现位置**：节点在特定视图的分组与布局，不同视图的位置互不覆盖。
- **知识关系**：两个节点间的带方向关系，分概念依赖与补充/对比，可有说明；与视图父级分离。
- **知识笔记**：简介、核心理解、公式、示例、提醒等可选段落，采用 Markdown；v1 默认按有正文的节点独立存放，无正文的节点不创建笔记文件，共享节点的多处出现共用同一笔记。
- **引用快照**：选文、来源身份/视图、版本与定位线索；来源改变不改写既有原文。
- **阅读状态**：会话内路径、选中节点、详情及缩放位置；与知识内容分离，不进入分享。
- **分享快照**：导出范围、版本及自包含阅读内容；不是连接原图谱的实时同步副本。
- **地图目录**：工作区内一张地图的持久化边界，绑定稳定图谱身份，容纳结构、Markdown笔记、布局和分享产物。
- **AI 编辑操作**：目标地图与内容版本、受影响节点/关系、修改结果或错误；不把聊天记录本身存入地图目录。

## Success Criteria *(mandatory)*

### Measurable Outcomes

以下是待实现后的验收目标，并非已有测试结果。基准图谱含100个唯一节点、10个视图、最多30个节点/视图、5层导航、重复标题、共享节点及一篇5000字笔记。

- **SC-001**: 在上述6组侧栏尺寸完成打开、下钻、返回、详情、搜索与引用，100%主入口可达，没有永久遮挡内容。
- **SC-002**: 5名首次使用者中至少4人在仅有任务说明的情况下，2分钟内完成“找到知识点→选文加入草稿→引用回跳”，并指出当前层级。
- **SC-003**: 至少20个引用案例覆盖已有草稿、重复文字、内容变化、来源失效、切换会话和插入失败；草稿损坏、自动发送、串会话及无提示错位均为0次。
- **SC-004**: 基准图谱本地打开至可阅读不超过3秒；各20次搜索和跨层定位中至少19次在1秒内显示结果或目标，不计模型回答耗时。
- **SC-005**: 10次有效外部修改均在完成后2秒内可见；10次无效修改均指出问题且不破坏源文件或最近有效画面。
- **SC-006**: 第二期20个案例覆盖新建、内容/关系编辑、拖动、删除、撤销、重开、保存失败及并发修改；已保存内容一致率100%，无提示丢失编辑为0次。
- **SC-007**: 全图和当前视图两种HTML各在两个不同主流桌面浏览器断网验证，范围内节点、关系、笔记完整率100%，导航/搜索/详情/缩放可用；会话信息、凭据及本机绝对路径泄漏为0。
- **SC-008**: 相同内容跨视图保持类别配色、卡片及笔记分节一致；5名试用者中至少4人无需解释即可区分两类关系，找到返回和关闭入口。
- **SC-009**: 20个AI操作案例覆盖创建、查询、扩展、修改、连接、删除、版本冲突和失败，成功结果重开一致率100%，失败导致半完成知识修改为0次。
- **SC-010**: 在两个工作区创建同名地图、重命名、重开及导出，并模拟无权限/创建中断；所有成功地图独立存放，跨图串写、覆盖未知文件为0次，失败地图不被列为有效产物。
- **SC-011**: 在正常动态效果下各执行10次进入与退出子图，每次完整过渡目标0.5秒，实际可见时长容差±0.1秒；无重复画布重影或结束后回弹。在相同内容、侧栏尺寸及缩放下对照 v17，逐项核对排版、字体、间距、节点、连线、详情和菜单；端点颜色、实空心及2px输出描边与原文件一致，切换过程遵循180ms退出和320ms淡入。
- **SC-012**: 连续20层子图可下钻、逐级返回、保存和重开且路径完整；基准图谱自动布局节点重叠数为0，仅改笔记或新增节点时已有手动节点位置改变数为0。
