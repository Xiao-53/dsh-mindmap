## 0.3.0 最新范围（2026-11-15）

产品为DSH侧栏通用思维导图，可用于架构设计、系统流程、学习知识及其他结构化主题。既有知识字段表示通用内容，沿用v1 JSON/Markdown/独立布局及固定渲染，不新增图形库。笔记章节由内容决定并保留作者顺序，不强制学习栏目。

用户指定`/minimap`注册为DSH命令，加载插件分发的`mindmap` skill，指引只注入后续请求上下文，不自动唤醒模型或提交草稿。实际注册atlas_list/read/create/preview/apply；内容生成与界面模板职责不变。

本轮完成已有布局保护及AI工具所需的候选、提交、恢复链。内部故障注入获得单独授权；10项内部专项通过，DSH真机、界面、浏览器和视觉验收待用户。人工编辑/撤销、显式重排和可选分享扩展仍延期。恢复记录通过`/minimap recover <mapId> 原操作已终止`明确恢复；无超时接管。详细实现与限制见[0.3.0交付](../../docs/validation/0.3.0.md)。

## Summary

原生侧栏阅读、搜索、选文入草稿、回跳和外部刷新构成原首期。保留三期完整产品规划，同时按用户后续选择纳入收纳与0.2.0增量；已接入入口、剩余实现和待人工验收分别记录，不再将全部导出/节点引用/拖动统称为未启用。内容使用独立JSON/Markdown，插件统一渲染并维护布局。

研究证据见 [research.md](research.md)。宿主读取服务不提供写入操作；ctx.fs 已有单文件条件写入依据，可用于布局保存，但客户端到 Host 的授权通路尚需集成验证。多文件提交由插件按图串行处理，使用前镜像、持久化记录和条件恢复，不依赖宿主提供多文件事务。详见 [保存契约](contracts/persistence.md)。

## Technical Context

- **Language/Version**：TypeScript，按 DSH v0.2.2-rc.3 官方插件工具链约束；不预设与宿主无关的编译器版本。
- **Primary Dependencies**：宿主 React Slot 与原生服务；DOM 卡片和 SVG 连线复用 v17 呈现机制；不引入独立图形库或全局状态库。Markdown 优先核实宿主安全渲染能力，禁止原始 HTML 执行。
- **Storage**：map.json、notes/*.md、layout.json；目录及字段沿用既有存储契约。单文件使用 ctx.fs guarded mutation。多文件操作采用插件保存与恢复协议；`.transactions/`按需保存内部恢复资料，不进入知识内容或分享。
- **Testing**：历史工程已有本地检查记录，但最终0.2.0未重跑全套测试。可人工验收的场景交由用户；Agent不自行运行自动测试、浏览器或视觉检查。内部多文件提交/崩溃恢复尚未实现和验证，技术验证方式另行明确，未具备证据前不启用相关能力。本次仅修正文档。
- **Target Platform / Project Type**：DSH v0.2.2-rc.3桌面原生侧栏插件；当前可下载全图离线HTML，完整分享能力仍待补齐。
- **Performance Goals**：100节点、10视图、单视图30节点；打开≤3秒；20次搜索/定位至少19次≤1秒；有效文件更新≤2秒。
- **Constraints**：360/480/720 × 600/900；正常导航180ms退出+320ms进入；输入#8699aa实心，输出#b38c97空心2px。
- **Scale/Scope**：个人工作区，任意业务层级，20层验收；无云同步、多人协作、自动发送或整份HTML内容生成。

## 设计与依赖

1. 首期先验证官方原生页签、引用source与发送序列化，再接入结构校验和只读加载；布局持久化通过同一插件保存服务闭环。监听外部变化，重新读取完整候选快照并校验后替换，保留最后有效画面及阅读位置。
2. 布局按视图分组顺序和实测卡片尺寸确定性排列；新增对象在空闲区域放置，保留已有位置。关系允许循环，不以拓扑排序作为合法性前提。已有卡片变高导致遮挡时不得擅自移动手动位置，提示显式重新布局。
3. 引用保存身份、原文与定位线索，使用宿主插入位置/草稿版本检查；不使用setDraft，不调用发送接口。原视图失效时按稳定节点找可用出现位置并说明。
4. 第二期所有编辑先生成候选快照并校验，删除展示影响范围，提交成功后才更新已保存版本；失败或冲突保留用户编辑。采用前镜像和持久化操作记录，失败回退；无法回退则明确恢复状态并保留资料。
5. 第三期复用阅读模板，以显式字段白名单生成分享快照，内嵌所需资源；范围外子图禁用，去除宿主动作与机器路径。不能复制整个运行时状态进行导出。
6. 原生工具、节点引用、问题草稿及递归扩展的完整范围见接口草案；可读查询依赖校验器，修改由插件提交与恢复服务执行，不将“提案”标记为成功写入。

## 用户指定的选择收纳增量（2026-11-15）

沿用现有 React Slot 与 DOM/CSS，增加 MapLibrary 选择页及 library.json 索引，不引入新框架。AtlasPane 将目录与阅读页分开：普通打开先选择，携带 mapId 的引用导航直接阅读。文件夹通过 parentId 形成独立层级，归档只改索引；创建空图只写一份合法 map.json，归档是后续独立操作。两者均采用宿主条件原子写入，绑定工作区并验证真实路径。无多文件提交，不启用未完成的内容编辑能力。

## 0.2.0 原型移植补充

用户已要求停止后续自主测试与浏览器检查，最终候选仅构建打包，交由手动验收。

当前全图HTML由 src/client/export-html.ts 通过浏览器下载，离线入口为 src/client/offline.tsx；并未实现默认写入本图exports或currentView范围。问题草稿由 QuestionDraft.tsx 插入可编辑文字，完整稳定来源引用仍待补齐。显式重新布局、撤销、导出预检与保存规则继续保留未完成任务；可人工验收的已接入部分统一交T083，不能提前勾选完整需求。
