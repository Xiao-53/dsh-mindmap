## 前置检查

后续开发时，在仓库根目录使用 PowerShell；本次重新加载跳过这些自动检查，直接使用现有安装包：

```powershell
git status --short
specify integration status
pwsh -File .specify/scripts/powershell/check-prerequisites.ps1 -Json
```

准备 DSH v0.2.2-rc.3、已授权的两个独立工作区及现有安装包 `dsh-mindmap-0.2.1.tgz`。本次重新加载按用户要求不运行构建、测试或自动检查脚本；直接按开发文档安装至已确认的 profile 并打开原生侧栏，安装包缺失时先报告。后续开发的完整工程命令见开发文档。无需 Better Sidebar。不重置已有 profile；本轮没有自动安装到用户 DSH。

## 验收材料

按 [存储契约](../../docs/mindmap-storage-format.md)准备100节点、10视图、单视图最多30节点、5层导航、重复标题、共享节点、两类关系及5000字笔记。另备合法空图、无布局图、20层子图、非法 JSON、重复身份、悬空关系、父级循环、合法知识关系循环、错图布局、缺失笔记和越界路径。测试材料在实现阶段按需建立，不将原型课程作为内置产品内容。

## 首期

1. 打开有效图与无布局图。对360/480/720 × 600/900六组尺寸检查主入口、独立笔记滚动和面包屑；无布局由插件计算，DSH不提供坐标。空图显示空状态，非法图显示具体错误。
2. 下钻、返回并核对父级路径和阅读位置。正常动态效果各10次进出，180ms退出加320ms进入，总计0.5秒±0.1秒；减少动态效果时仍完成导航。按v17逐项核对字体、间距、卡片、关系与端点。
3. 跨层搜索标题、摘要、正文和重复标题；结果显示路径，全部命中可访问。键盘完成搜索、详情、菜单与关闭，焦点返回触发处；复制获得可读文本。
4. 准备含文字、引用和附件的草稿。至少20例覆盖选文入草稿、点击回跳、重复选文、正文改写、出现位置删除、节点删除、会话切换、输入锁定及插入失败。已有内容完整保留，自动发送、串会话和无提示错位均为零；仅用户手动发送后检查模型收到可读选文与来源。
5. 外部有效修改10次、无效修改10次。有效修改2秒内反映，无效修改保留最近有效画面并标记旧版本；恢复有效文件后可恢复阅读。删除当前对象有明确说明，不改写源文件。
6. 记录打开耗时≤3秒；20次搜索及跨层定位至少19次≤1秒。请5名首次使用者试用，至少4人2分钟内完成阅读引用闭环并识别层级、关系和关闭入口。

## 后续阶段及未排期能力

以下为尚未完成的完整能力，不表示拖动、节点引用、问题草稿文本或全图下载入口仍未接入；当前子集按上述人工清单交接，不据此勾选完整验收。

- 第二期：20例覆盖创建、编辑、拖动、撤销、删除、重开、保存失败与并发冲突。失败保留编辑；关闭提供保存、放弃、取消。只改正文不重排，拖动不改正文。多文件能力未通过失败恢复门禁时不得宣称保存成功。
- 第三期完整分享：补齐当前视图范围、预检/缺失项明确省略、未保存标记、默认exports保存和重名保护后，人工分别导出全图和当前视图，各在两个主流桌面浏览器断网打开。范围内内容完整、核心阅读可用，无宿主按钮、会话信息、绝对路径和网络依赖；导出不写回源文件或清除未保存状态。当前浏览器全图下载先按T083人工检查。
- 未排期完整能力：20例原生工具操作、两个工作区同名地图隔离、创建中断与权限失败、20层保存重开、新增节点不移动既有手动位置。SC-010须人工在两个工作区创建同名图、改名后按同一ID重开并导出，核对内容身份、各自默认exports归属及重复导出不覆盖，其他地图和工作区不变；与T057/T066共用案例。工具失败不能留下部分知识修改，内部崩溃恢复证据另行明确技术验证方式。依赖与错误格式见 [接口契约](contracts/interfaces.md)。
