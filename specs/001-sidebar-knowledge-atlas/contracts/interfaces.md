# 插件接口与行为契约

日期：2026-11-15。依据：[规范](../spec.md)、[数据模型](../data-model.md)、[宿主调研](../../../docs/sidebar-integration-research.md)。以下业务操作名称用于设计，不宣称它们已经是 DSH API。官方适配签名及兼容性证据以 [research.md](../research.md) 为准。

本文件定义完整目标契约。当前0.2.0已接入节点引用、问题草稿文本、拖动保存及全图HTML浏览器下载；问题草稿的稳定来源引用、导出范围/预检和默认exports保存等仍为剩余实现，不因入口存在而宣称完整契约已满足。可人工验收场景交用户执行，见 [当前候选人工验收](../../../docs/validation/current-candidate.md)。

## 原生侧栏与引用（首期）

注册原生页签类型与同 ID 的会话级 `sidebar.right.pane.tab`，使用宿主提供的会话上下文、资源地址与生命周期；停用时释放注册及订阅。打开输入包含已授权工作区内的地图资源身份，可选 viewId/nodeId/选文定位线索。不存在的身份返回具体错误，不按同名对象猜测。

引用适配使用官方插入锚点及自定义引用 source，绑定发起动作的会话。不得将草稿转普通字符串后 setDraft 覆盖，不调用 send 或 submit。流程为：

1. 在详情中捕获当前非空选文、稳定来源及前后文，捕获原会话插入锚点。
2. 准备引用时校验生命周期、会话绑定、草稿版本及可写性；宿主拒绝插入则返回失败并保留待引用内容。
3. 插入一个引用，保持已有文本、引用、附件与撤销语义；失败不得向当前其他会话兜底。
4. source 的序列化输出可读原文和地图／节点来源，不自动带全图、子图或邻居；只在用户发送时由宿主消费。
5. source 的回跳先查地图与节点身份，再找 originViewId 中的出现位置；已移除则选择同节点的有效位置并说明。节点仍在但没有画布出现位置时可打开详情并说明。选文仅在原文和上下文能唯一匹配时精确高亮，否则定位节点并提示变化。源文件缺失或无权限时展示原因与原文。

完整版本的节点引用包含标题、摘要和可读笔记；准备问题仅追加可编辑问题与引用。内容超宿主限制必须明确失败，无静默截断。发送后历史消息的可点击回跳不纳入当前承诺。

## 文件读取、刷新与布局（首期）

输入为工作区身份、地图地址及宿主授权。输出为完整有效快照，或包含相对路径、对象 ID、字段位置和原因的诊断。拒绝未知 schemaVersion、非法 ID、重复身份、悬空引用、父级循环、缺失笔记、错图布局及越界路径；知识关系循环合法。

文件变化事件只触发重新加载，不直接修改当前画面。合并短时间事件，读取整个候选依赖集，检查读取期间变化，校验成功后一次发布快照；中间写入状态不能作为正常数据发布。无效更新保留最近有效画面并标旧，允许重试；未保存编辑存在时进入冲突。宿主订阅失效需显示状态并允许手动刷新，不假装持续更新。

缺少 layout.json 是合法输入。插件测量节点并补齐布局，既有位置保持；常规标题／正文更新不触发全图重排。只有显式重新布局允许调整整个目标视图且可撤销。布局写入也要检查读入以来的实际变化，未验证安全写入前不声称持久化成功。

## 后续原生工具业务协议（不分配新增实施批次）

工具注册前必须具备服务端授权、结构校验、真实版本检查与失败恢复。工具名及参数以 [authoring.md](authoring.md) 的插件契约为准；下列为需覆盖的语义集合：

| 操作 | 输入 | 成功结果 |
| --- | --- | --- |
| 列举／读取地图 | 绑定工作区、可选 mapId、读取范围 | 有效地图身份、请求内容、读取版本指纹；未知目录不接管 |
| 创建地图 | title、合法结构与节点笔记 | 新稳定 mapId、独立目录及已提交指纹；同名不覆盖 |
| 查询对象 | mapId、对象类型与稳定 ID，或明确搜索条件 | 对象内容、身份、依赖和指纹；歧义返回候选 |
| 修改节点／笔记／关系 | mapId、expectedFingerprint、目标 ID、限定字段或正文变更 | 受影响身份、已提交指纹；无关文件与布局保持 |
| 扩展子图 | mapId、expectedFingerprint、nodeId、视图与内容变更 | 已有 childViewId 优先复用；父级及中心关联合法 |
| 移除出现位置／全图删除 | mapId、expectedFingerprint、目标、明确删除范围、已确认影响清单 | 实际删除／修改对象，无悬空引用；仍被引用对象保留 |

统一结果包含 status、mapId、affectedIds；成功包含实际已提交指纹，失败包含 code、message、对象／路径诊断和可重试信息。语义错误类别包括 invalid_data、not_found、permission_denied、path_outside_map、version_conflict、storage_failure、capability_unavailable。部分写入不得返回 success。

提交由插件按图串行执行，修改前保存前镜像和恢复记录，完成后再发布刷新。失败先回退；回退失败保留记录并返回recovery_required，不能冒充完整成功或完整回退。具体协议见 [persistence.md](persistence.md)，工具参数和内容职责见 [authoring.md](authoring.md)。实现通过故障恢复验收后启用写功能；不要求宿主提供跨文件事务原语。

## HTML 导出（第三期）

请求包含 mapId、范围 `all/currentView`、当前有效编辑快照与可选目标位置。先预检并展示视图／节点／关系／笔记数量、缺失资源和未保存状态；用户可取消或明确省略缺失项。默认写入本图 exports，重名不静默覆盖。

输出为单个自包含 HTML：内嵌选定知识、布局、必要资源和阅读器；断网可导航、搜索、详情、平移及缩放。currentView 包含当前视图节点完整笔记和关系，未纳入子图入口禁用并解释；全图包含全部子图和共享内容。成品标示范围与省略项。

导出采用明确允许字段投影，排除草稿、会话绑定、聊天记录、凭据和绝对路径；不序列化整个运行时状态。内容经过转义及非执行 Markdown 渲染，不能注入脚本或任意本地文件访问；外部来源链接可以保留，核心阅读不依赖网络。宿主引用与提问动作不进入成品。导出当前有效未保存快照时不写回源文件、不清除未保存状态。
