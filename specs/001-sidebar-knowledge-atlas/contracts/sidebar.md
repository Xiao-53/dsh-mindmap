# 侧栏结构与渲染设计

本设计将 [v17](../../../docs/knowledge_atlas_demo_v17.html) 的界面实现拆为插件组件；不另造视觉方案、不把原型作为运行依赖。范围以 [spec.md](../spec.md) 为准。

以下分期表述保留原设计语境。用户后续0.2.0增量已接入选择收纳、拖动、节点引用、问题草稿文本及全图下载；已接入与剩余部分以 [tasks.md](../tasks.md) 为准，当前入口由用户按 [人工清单](../../../docs/validation/current-candidate.md) 验收，不自动运行浏览器或视觉检查。

## 页面组成

| 区域／组件 | 内容与数据 | 行为 |
| --- | --- | --- |
| AtlasPane | 会话绑定、地图选择、加载状态 | 挂载原生 sidebar.right.pane.tab；地图由工作区目录列举，不依赖聊天正文 |
| MapHeader | 地图名称、当前视图标题、搜索、本节笔记、上一级 | 地图名称入口切换地图；根视图返回禁用；本节笔记读取 centerNodeId；导出在第三期启用 |
| Breadcrumbs | 从 rootViewId 到当前视图的 parentViewId 链 | 路径按实际层级生成，局部横向滚动；共享节点下钻采用目标视图父级路径 |
| MapViewport | 点阵背景、平移缩放、适配、两类关系图例 | 相机按地图/视图保存；缩放仅作用于画布，不缩放工具栏和详情 |
| MapScene | 分组底框、DOM卡片、SVG连线与端点 | occurrences决定出现位置，relations决定连线，layout决定几何；共用同一坐标系 |
| NodeCard | icon、title、summary、category及子图提示 | 有子图且非当前子图时下钻，否则读详情；键盘等价，后续拖动后不触发点击 |
| NoteInspector | 节点标题、简介、核心理解、公式、示例、提醒 | 缺失段落不占位；笔记独立滚动；复制、定位、关闭及选文加入输入框 |
| SelectionActions | 详情当前非空选文 | 右键和可发现按钮共用捕获逻辑；首期只加入草稿，完整版本再支持问题草稿 |
| SearchOverlay | 当前地图全部标题、摘要、笔记文本 | 每条结果带节点身份和路径；可滚动访问全部结果；不保留原型 slice(0,12) 截断 |
| StatusRegion | 空图、读取失败、保存中、旧版本、恢复失败 | 正常时不堆叠说明；错误显示对象与重试，保留最后有效画面 |

组件仅划分职责，不在本轮生成空组件。原型 draw/createConnections 对应 Scene 与连线几何；navigate 对应导航状态机；openInspector 对应详情渲染；demoDSH 替换为真实引用适配，不保留演示逻辑。

## 文件到界面的流程

地图目录 → 插件读取结构、笔记、布局 → 校验并建立有效快照 → 构建节点/视图索引 → 测量卡片、补齐缺少的位置 → 渲染当前视图。

map.json 是知识结构来源；Markdown 是详情来源；layout.json 是插件维护的位置。DSH工具修改完成后由插件发布 mapChanged 通知，侧栏重新读取已提交文件并更新快照。外部文件观察为补充刷新通道，不要求模型发刷新指令。更换快照不重建无关阅读状态，不将每次文件变化都当成重新打开地图。

## 侧栏适配和交互细节

- 360/480/720像素宽、600/900像素高均保持标题区、返回、搜索及关闭可达。以插件容器宽度决定工具折行和次要操作收纳，不沿用原型以整个浏览器宽度判断侧栏的方式。
- 详情沿用320像素目标宽度和容器内边距；窄栏约束为容器宽度减32像素，遮盖画布但不挤压全部文字。搜索及菜单定位在插件容器内，不使用覆盖整个宿主的 fixed 浮层。
- 节点和分组字体、配色、圆角、间距沿用v17；输入端点#8699aa实心，输出#b38c97空心2px。线连接实测卡片边界，拖动时同步更新，不能只改卡片而留下旧端点。
- 单次导航180ms退出、替换场景、320ms淡入；连续触发只处理最新待导航目标，不并行叠加场景。返回恢复对应视图相机。减少动态效果时省略空间运动；取消或卸载清理动画并恢复一致状态。
- 详情关闭、搜索关闭、菜单关闭恢复触发焦点。Escape依次关闭最上层浮层；快捷键仅在面板相关作用域生效。
- 新图按分组顺序和测量尺寸排布；新增卡片在未占用区域补位，保留已有坐标。正文更新不修改卡片几何；标题高度变化后重新测量连线，手动位置冲突提示用户重新布局，不自动推开手动卡片。

## 分期和复用

首期提供阅读、搜索、选文引用与刷新。第二期编辑和拖动调用同一保存服务；第三期导出复用无宿主依赖的阅读器，去除引用/编辑动作。节点引用、问题草稿和原生工具设计完整，但不在本次改变既有分期。原型中的JSON导出、固定三层、示例课程和假发送行为不进入产品。
