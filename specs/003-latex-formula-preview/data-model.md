# 数据模型：节点笔记公式

## 持久化

沿用 `notes/<nodeId>.md`。保存的是 Markdown 中的原始定界符与 LaTeX 文本，不写渲染 HTML、编号、状态或独立公式文件。导出仍从已提交的有效快照读取。JSON schema、布局、图片文件和 RPC 均无变更。

## 内存数据

| 实体 | 字段 | 约束 |
| --- | --- | --- |
| FormulaToken | `kind` 行内/块、`delimiter` 起止形式、`tex` 内部字符串、`source` 原始定界串、`raw` 分词消耗范围 | 完整匹配才生成，无子 token。分词器可能将尾随换行并入 raw，编辑和复制取稳定的 source。格式损坏但已闭合仍可显示源式。 |
| FormulaOccurrence | 节点及视图身份、正文片段位置、原式快照、编辑版本 | 只在当前编辑会话有效。两条同源公式按出现位置区别，绝不按字符串全局替换。 |
| FormulaPreview | `ready` 或 `invalid`、固定文案错误类型、派生排版 | 缓存以源式、显示模式、渲染配置为键。缓存有界，不能写入正文；错误回退始终保留原式。 |
| FormulaDraft | 目标位置、打开时的原式与版本、当前输入 | 独立于现有 autosave draft。应用前不计入正文、导出或写请求。与原版本不再一致时仅允许保留/复制原输入或取消，不能覆盖其他公式。 |
| BodyEdit | 修改前后 Markdown、锚点与焦点位置、动作类型 | 正文编辑区本地有界历史，记录输入组、粘贴、IME 提交、删除或应用。预览形态变化不产生条目。离开正文后使用既有导图级历史。 |

### 状态转换

1. 普通正文输入 → 可编辑文本 → 边界闭合且可排版 → 原位公式预览。合并进本次输入或粘贴动作。仍可能继续输入改变边界的单美元式，重新核对边界并还原为文本；语义源式保持原样。
2. 编辑已有公式 → 局部未应用草稿 → 每次输入更新局部预览。取消恢复显示原式；无效内容只在当前输入框。应用或删除前校验目标，从原文位置更新一次，接入现有按批次自动保存和导图历史。
3. 打开同一笔记时若存在会话保留的未应用草稿，先核对节点、视图、公式位置和原式。准确匹配则可继续；否则显示为可复制草稿。插件可控离开先询问继续或放弃。宿主同步关闭无法等待选择时只在当前会话内保留，不自动应用。
4. 接收外部版本或撤销时重新建立公式投影。外部变更处理与既有冲突策略一致；不得继续用旧位置提交。

### 光标与原式投影

正文历史保存逻辑位置（块路径、块内文本偏移、公式边界前后）而非长期持有浏览器 Range。显示层将公式视为一个整体，复制与引用定位以原式占据的字符范围替代渲染子树。原式跨边界复制时，纳入完整公式并去除 MathML 与视觉双层重复。
