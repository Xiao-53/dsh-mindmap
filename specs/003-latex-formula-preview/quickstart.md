# 验证指南：阅读、可视编辑、离线公式

本指南供实现完成后验收。项目的浏览器、实机、自动验证授权按 AGENTS.md 执行。以下项目当前均未执行。

## 准备与构建

1. 使用 Node.js >=24.9、目标 DSH v0.2.2-rc.3、已安装依赖及一张独立验收导图。固定记录 Windows/DSH/浏览器版本、设备与 320 px 默认详情宽度，另以 260 px 窄栏复验。
2. 在仓库根目录执行 `npm run pack:plugin` 得到本地安装包。按 [现有安装说明](../../docs/plugin-development.md)加载至测试宿主。将打包耗时和前后产物体积记入交接，构建成功与人工结果分别记录。
3. 使用验收图的一个节点正文加入下列样例。保留另一节点、图片、链接、一处真实本地资源及一条已有选文引用，便于比较。

| 类别 | 两个样例的内文（分别加规范定界符，推导和矩阵包含块样例） |
| --- | --- |
| 上下标 | `a_i^2`、`x_{n+1}` |
| 希腊字母 | `\alpha+\beta=\gamma`、`\Omega\neq\omega` |
| 分式 | `\frac{1}{2}`、`\frac{x+1}{x-1}` |
| 根号 | `\sqrt{x^2+y^2}`、`\sqrt[3]{8}` |
| 求和 | `\sum_{i=1}^n i`、`\sum_{n=0}^{\infty}2^{-n}` |
| 积分 | `\int_0^1 x\,dx`、`\oint_C f(z)\,dz` |
| 矩阵 | `\begin{pmatrix}1&0\\0&1\end{pmatrix}`、`\begin{bmatrix}a&b\\c&d\end{bmatrix}` |
| 对齐 | 块内 `\begin{aligned}a&=b+c\\&=d\end{aligned}`、`\begin{aligned}x+y&=3\\x-y&=1\end{aligned}` |

轮换四类定界符，取其中一块为独立起止行的多行写法。另加 8 组普通文本样例：两句美元金额、两种转义美元、行内代码及围栏代码各一、未闭合行内和块各一。添加两条闭合错误公式，例如未知命令和缺右括号。把一条公式放进章节标题、一条进表格、一条在图片旁，并保留长式样例。

## 验收顺序

1. **阅读与范围（SC-001）**：打开详情，确认 16/16 正常、8/8 普通文本保留。异常公式两处显示原式，余下内容可读。窄栏长公式可用键盘横向阅读。点击现有图片和链接核对功能。含看似资源链接的 TeX 不产生额外资源读取，真正 Markdown 图片仍可加载。
2. **可视编辑与保存（SC-002）**：在行内直接键入一条，另粘贴一段包含文字、代码、独立公式和未闭合公式的混合文本。检查仅有效公式转换，光标可继续输入。用中文输入法组字直到完成。修改既有公式、取消、应用、删除、撤销、重做。每次自动转换本身不增加撤销步；校验两个相同原式的公式只改所点的那一个。完成编辑后重开并核对已保存源码、未改公式和相邻资源。
3. **工作区与未应用草稿**：打开一个局部草稿后点完成、切节点和关闭详情，检查继续编辑/放弃分支。使用宿主关闭后重开核对会话内保留。编辑期间让另一侧更新正文，确认旧位置不能直接覆盖外部版本。应用无效式和取消均不写入；已应用内容保留现有冲突行为。
4. **时延（SC-003）**：同设备打开同笔记 5 次，详情出现至首屏公式就绪各 ≤1 s。局部编辑分别输入普通分式 5 次，停止输入至显示结果各 ≤300 ms。逐次记录，不把构建耗时计入。
5. **独立分享与复制（SC-004）**：导出后仅复制 HTML 到新目录，断网并用桌面浏览器打开。16 条有效公式可读，2 条错误式保留源式。复制完整公式、带公式选文与整篇笔记，定界表达式各出现一次。核对插件中的选文引用仍可回跳或保留原文，检查离线文件没有宿主动作或临时草稿。

验收记录应分别标明构建、实机行为、离线表现和未执行条件。需求及行为边界见 [规格](spec.md) 与 [公式契约](contracts/formula-preview.md)。
