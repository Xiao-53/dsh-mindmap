# 契约：公式识别、编辑与离线阅读

## 正文语法

| 用法 | 定界及位置 |
| --- | --- |
| 行内 | `$...$` 或 `\(...\)`，不得跨行，内容非空。单美元起符后与止符前不是空白，止符后不能紧跟数字。 |
| 独立公式 | `$$...$$` 或 `\[…\]`，同一行的前后均无其他正文，或开闭定界符各自独占一行。端点容许 0–3 个普通缩进空格。正文段落里的双美元不降级为单美元公式。 |

- 代码块、行内代码、HTML 字面内容、链接/图片目标与转义定界符由已有 Markdown 语义保护。代码优先于缩进数学识别。逃逸判断使用连续反斜杠的奇偶，显式括号定界符本身除外。
- 单美元遇到第一个未转义的候选止符即判定，不跨越被拒的候选去寻找更远的止符。保留规格中的价格示例及紧随其后的公式。普通价格没有明确闭合时保留文本；有歧义的表达式可使用 `\(...\)`。校验源码所属 Markdown 上下文后再判断，不用渲染成功与否猜测是不是价格。
- 原式完整保留，包括定界符和公式内空格、换行。未闭合与被 Markdown 保护的文本照常读取；已闭合但不支持、超限或不能排版的公式仅该处回退，源码仍可复制。
- 初始实现限单条源式 4096 UTF-16 码元、宏展开 200 次、渲染显式尺寸上限 20 em。结合 16 个验收样例核对。安全命令保持限制，宏不跨公式共享。

## 可视编辑

- 从「复制内容」旁的「编辑」进入，正文直接输入或粘贴。首版无插入专用按钮。粘贴按现行纯文本规则进入编辑区，其中符合语法的公式可预览，代码围栏或行内代码内不转换。公式可跨同一合格块内的多个文本片段，不跨代码、链接目标、图片或无关段落拼接。
- 合法公式原位排版，光标继续在公式后或选区的原逻辑边界。输入法组字期间不做投影。紧邻公式继续输入会重新核对单美元闭合条件。已经完整的多行独立公式一起变成一个显示块。
- 点击公式或键盘激活仅打开这一条的文本输入及实时预览。焦点进入公式输入；应用、取消后回到原位置附近。保留原定界风格，删除作为独立内容动作。无效变更保留输入与提示，不能覆盖正文中原式。
- 正文 Ctrl+Z/重做按内容动作算一步。自动转换不占额外一步。标题、摘要、公式输入框继续由各自输入控件处理撤销，正文外沿用导图 30 步历史。应用与删除调用现有自动保存队列，预览或取消不调用提交。
- 插件内切图/切节点/完成编辑/关详情/搜索导致卸载前，未应用的公式草稿可继续编辑或明确放弃。宿主强制关闭的当前会话保留行为见 [数据模型](../data-model.md)。

## 复制、安全与离线

- 复制整条笔记保留所有章节和表格里的公式。选择内容涉及完整公式时输出一份原始含定界表达式。选文加入输入框与回跳共用原式投影，旧引用无法唯一定位时维持原有可读回退。
- 局部公式错误使用文本 fallback 和可识别提示。禁止隐式请求、任意 HTML 属性/样式和文档操作。渲染 DOM 不作为存储源；编辑时公式节点内部不接受任意内容写入。
- 独立 HTML 可在断网及新目录下读取，携带全部必须本地资源。长块公式拥有自身可键盘到达的横向滚动。离线仅提供阅读和复制，沿用现有导出边界。
