# Feature Specification: 节点笔记 LaTeX 公式预览与编辑

**Feature Branch**: main（当前工作分支）
**Created**: 2026-11-18
**Status**: Draft
**Input**: 用户询问正文是否支持 LaTeX 预览，并要求先调研方案再完善规格。沿用节点笔记底部「编辑」入口、所见即所得正文、自动保存和离线分享。

## Clarifications

### Session 2026-11-18

- Q: 首版如何在可视正文中插入公式？ → A: 直接输入或粘贴带定界符的表达式，完整且有效时原地预览。首版省去插入按钮，已有公式仍可点击编辑。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 阅读时直接看公式 (Priority: P1)

读者打开含公式的节点笔记，行内公式跟随文字排版，较长的推导独立成块。遇到异常公式时，仍能读到原式和其他内容。

**Why this priority**: 分式、根号、矩阵按数学排版呈现，读者可以直接理解公式结构。

**Independent Test**: 打开一份含中英文段落、16 条样例公式、美元金额和代码的已有笔记，无需编辑即可验证。

**Acceptance Scenarios**:

1. **Given** 笔记内有行内和独立公式，**When** 打开节点详情，**Then** 两种公式按各自位置排版，周围文字、图片和链接照常呈现。
2. **Given** 同一段含美元金额、转义美元、代码和公式，**When** 打开详情，**Then** 只有真实公式排版。
3. **Given** 一条已闭合的公式包含无法解析的命令，**When** 打开详情，**Then** 该处显示可复制的原式与简短提示，同页其他公式照常显示。

### User Story 2 - 在正文中插入或修改单条公式 (Priority: P1)

编辑者从「复制内容」旁开启编辑。正文仍可直接输入，已有公式保持预览。点一条公式即可修改其表达式并查看即时排版，也可以在光标处直接输入或粘贴行内或独立公式。

**Why this priority**: 修改笔记时保留阅读上下文，避免误改公式的排版字符或切换整篇笔记的显示方式。

**Independent Test**: 进入编辑，在句子中直接输入行内分式，再粘贴独立公式。修改另一条公式并先取消一次，再应用一次有效修改。等待保存后重开节点，核对公式位置和周围段落。

**Acceptance Scenarios**:

1. **Given** 笔记处于编辑模式，**When** 修改公式前后的文字，**Then** 公式保持排版，重开后原式未改。
2. **Given** 打开一条公式的编辑，**When** 修改表达式，**Then** 该条公式的预览更新。取消保留原式，应用有效修改进入现有自动保存流程。
3. **Given** 新输入的公式无效，**When** 尝试应用，**Then** 编辑区保留输入并指出错误，正文中的原公式继续保留。
4. **Given** 正在正文输入或粘贴内容，**When** 输入法结束组字且形成完整有效的公式，或粘贴内容包含此类公式，**Then** 公式原地预览，光标可继续输入后文。未闭合、无效表达式和普通文本仍可直接编辑。
5. **Given** 已应用公式变更，**When** 使用正文撤销，或离开输入区后使用导图撤销，**Then** 对应层级恢复公式内容与位置，重做可恢复该变更。

### User Story 3 - 断网阅读分享文件 (Priority: P1)

分享者导出导图。接收者断网打开独立分享文件，仍能阅读公式，并复制可复用的源表达式。

**Why this priority**: 离线分享是现有交付方式，公式需要与正文和图片一同完整呈现。

**Independent Test**: 导出一张含有效公式、异常公式及图片的导图，将文件复制到另一目录，断网独立打开并复制公式。

**Acceptance Scenarios**:

1. **Given** 分享文件来自含公式的导图，**When** 断网打开，**Then** 公式呈现与插件内一致，其他笔记内容可以阅读。
2. **Given** 正文中有完整公式，**When** 复制完整公式或复制整条笔记，**Then** 复制结果包含一份可复用的源表达式及定界符。

### Edge Cases

- 普通美元价格（如「原价 $20，现价 $15」）、转义美元、行内代码和代码块保持文本。单美元行内定界符不跨行，开始符后与结束符前不得有空白，结束符后紧接数字时不构成闭合。
- 孤立或未闭合的定界符按文本显示。正文编辑中直接输入的无效表达式留在原位置供修正。阅读或分享时，闭合但无法解析的公式显示源表达式和短提示，不影响相邻内容。
- 狭窄侧栏中的长公式可在自身区域横向阅读；公式不会扩大侧栏，键盘可进入可滚动区域。
- 只读笔记及离线分享仍可阅读公式。公式内容里的远程资源请求、自定义界面样式与文档操作不得生效。
- 单条公式有未应用输入时，关闭详情或切换节点须允许返回继续编辑或明确放弃。已应用改动继续按现有保存规则处理。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**：阅读、编辑与离线分享均须识别 `$…$`、`\(...\)` 行内公式，以及独立成块的 `$$…$$`、`\[…\]`。块公式支持单行完整定界，也支持由独立起止行包围的多行表达式。
- **FR-002**：首版至少支持上下标、希腊字母、分式、根号、求和、积分、矩阵和对齐推导。屏幕阅读器须能获取公式含义或可读原式，并能识别错误提示。
- **FR-003**：代码、转义文本与常规价格示例保持文本。未闭合公式不吞掉正文，单条公式排版失败不阻断整篇阅读。长公式可以在侧栏内完整阅读。
- **FR-004**：保留底部「编辑」入口和正文直接输入。在编辑模式中，点击现有公式或用键盘激活，仅打开该条公式的源表达式输入及即时预览，可应用、取消或删除它。
- **FR-005**：编辑者在正文光标处直接输入或粘贴带定界符的表达式。符合 FR-001 且有效的公式在输入闭合后或粘贴完成后原地预览，输入法组字期间等到组字结束。行内公式保持在原句，独立公式遵循独立成块规则。转换后可继续输入后文。首版不提供单独的插入公式按钮。
- **FR-006**：应用有效变更和删除公式须沿用现有自动保存、撤销重做、工作区冲突与失败提示。取消、单条公式编辑框中的无效输入、单独预览及打开笔记均不触发公式写入。直接输入或粘贴的普通文本和未完成表达式仍按现有正文规则保存。编辑相邻正文须保留未修改公式的原表达式及定界符。
- **FR-007**：插件及导出文件无需联网即可预览。预览不得因公式内容发出网络请求、执行命令或改变公式区域之外的界面。
- **FR-008**：阅读或编辑视图中复制完整公式，或通过「复制内容」复制节点笔记时，公式源表达式及定界符各出现一次。
- **FR-009**：公式随节点正文保存与分享，无需迁移已有笔记。单条公式修改只影响对应节点正文，并保留其他节点、布局和资源。

### Key Entities *(include if feature involves data)*

- **笔记公式**：节点正文中的一处行内或独立公式，包含源表达式、定界符、正文位置及预览状态。
- **公式编辑草稿**：尚未应用的单条公式输入。应用后成为节点正文的一部分，按现有流程保存。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**：目标 DSH 侧栏打开含 16 条样例公式的笔记，FR-002 每类至少两条，全部正确排版。8 组普通文本样例（金额、转义、代码、孤立定界符各两组）均保持文本。
- **SC-002**：在样例笔记完成直接输入行内公式、粘贴独立公式、修改、取消、删除、撤销、重做七项操作。七项均得到预期结果，重开后已保存的改动正确，未编辑的公式原式及相对位置均保留。
- **SC-003**：在同一目标桌面环境打开 16 条公式样例 5 次，从详情可见到公式排版完成，每次不超过 1 秒。预览区输入普通分式 5 次，停止输入后均在 300 毫秒内给出结果。
- **SC-004**：复制独立分享文件到另一目录并断网查看，16 条有效公式全部正确显示，2 条异常公式各自保留可复制原式。复制完整公式和整篇笔记两个场景均无重复表达式。

## Assumptions

- 目标为现有 DSH 桌面侧栏及独立离线分享文件。首版通过正文直接输入或粘贴添加公式，通过单条 LaTeX 源表达式输入修改已有公式。公式虚拟键盘、全功能文档编辑器及任意 LaTeX 宏包不在范围内。
- 沿用 [节点编辑与自动保存](../002-edit-layout-history/spec.md) 的流程。无需迁移现有地图或笔记。
- 验收设备、侧栏宽度与样例在规划阶段固定。以上数值为验收目标，当前尚无实测结果。
