# 节点详情阅读与编辑样式统一数据模型

地图和节点的持久化身份遵循 [存储契约](../../docs/mindmap-storage-format.md)。本设计中的页面状态、源码范围和编辑撤销依据随会话或快照变化。旧 Markdown 无需迁移。

## 节点详情与正文块

| 实体 | 字段与关系 | 规则 |
| --- | --- | --- |
| 节点详情 | `mapId`、`nodeId`、当前视图、标题、摘要、Markdown、权限、读写状态。 | 同一节点在多个视图共用正文。默认只读。已进入编辑时，以当前 `EditSession` 显示本地工作内容和保存状态。离线只读取已导出内容。 |
| 解析后的正文块 | 原始 Markdown 的 `[start,end)`、token 类型、渲染节点、可映射的源文边界。 | 范围以原始字符串的 UTF-16 编码单元计数，摘要按原文 UTF-8 计算。CRLF、转义和行内标记需从源文核对。使用真实 token 层级，顶层分隔空白与块内容分别跟踪。 |
| 读写切换位置 | 可见块源位置、该块相对滚动容器的顶部距离，必要时记录滚动偏移。 | 同节点、同宽度、同内容切换时保留该段落可见。切换节点按既有详情导航处理。 |
| 图块 | 同一节点内的 `plotId`、原围栏字节、范围、解析数据、渲染状态。 | 复用 `dsh-plot` 的 `version: 1`。有效且身份唯一的图块支持手动动作。历史坏块和重复 ID 保留原文回退。 |

## 整图操作与撤销

- **移动候选**包含正在操作的 `nodeId`、`plotId`、当前正文修订和有效落点。落点位于同一正文顶层块之间，也可位于开头或结尾。移动按当前范围剪切其原始围栏，再插入落点，保留非目标片段，必要时在接缝补分隔。
- **删除候选**绑定相同来源和修订，仅移除所选围栏。失效来源、相同位置、取消或越界放置不生成历史记录。动作完成后焦点保留在可继续编辑的位置。
- **历史**复用现有正文编辑历史及地图 `EditSession`。每次有效整图动作对应一次可撤销修改，撤销或重做恢复对应正文与位置。会话保存合并时依据原基线核对此次实际变更，保留正在等待保存的显式动作来源。
- **恢复依据**由 Host 在当前工作区、宿主编辑会话、地图和节点作用域内持有，记录已验证删除的图块 ID、围栏摘要及所属提交。只在成功事务或可验证回执后生效；内部确认的后续提交推进版本链，外部版本变化、会话关闭或历史失效使该恢复依据过期。它只授权校验通过的原围栏恢复。待定结果通过既有回执查询确认。
- **写入**沿用 `commitEdit`、`expectedFingerprint`、操作 ID、事务和错误状态。有冲突时保留本地副本，按现有界面提示处理。已知仅改变布局时无需重建图块恢复依据；其有效性仍由当前编辑版本链约束。

## 正文位置引用

| 对象 | 字段 | 生命周期 |
| --- | --- | --- |
| 正文位置引用 | 复用 `ReferenceSnapshot`，新增 `kind: note-position` 和 `anchor`。显示地图、节点与短上下文，继承原会话、工作区、资源地址和视图绑定。 | 由正文右键菜单生成，宿主在原草稿保存引用。模型只获得来源标识、可读片段和定位所需字段。 |
| 段落定位 | 版本号、地图和节点 ID、已保存正文摘要、块的原始起点、长度和摘要、块内点击偏移、前后块摘要。 | 相同正文以原范围核对定位。正文发生变化时以完整块匹配及原邻近上下文重新核验。找不到或出现多个候选时失效。 |
| 正文开头定位 | 版本号、地图和节点 ID、已保存正文摘要和空正文类型。 | 对应正文开头 0；仅在无可见正文且可验证的空源状态下成立。 |
| 追加内容 | `nodeId`、上述 `anchor`、内容种类、单项 Markdown。 | 使用最新 `atlas_read` 返回的地图指纹。条件提交仅写目标节点正文，首次创建笔记时更新该节点的 `notePath`。 |

点击偏移记录在段内，段后位置从同一有效块的结尾计算。原始正文摘要与地图版本指纹分别验证点击来源和本次提交的基础版本。接口和错误处理见 [DSH 定位引用契约](contracts/dsh-insertion-reference.md)。
