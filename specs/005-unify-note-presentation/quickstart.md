# 节点详情统一的快速验收

本指南供实现完成后在实际 DSH 和断网 HTML 中手动执行。分别记录打包结果、宿主版本、侧栏宽度和每项人工结果。

## 准备

1. 使用 Node.js ≥24.9 和 DSH `v0.2.2-rc.3`。准备独立验收导图及可写 profile，启用原生 `/mindmap`。另准备只读工作区或权限受限的会话。
2. 在仓库根目录使用已安装的依赖。首次安装依赖时运行 `npm ci`。构建本地候选包后按 [插件安装说明](../../docs/plugin-development.md#在已有-dsh-中加载) 用相同 DSH 版本加载实际生成的 tgz。

   ```powershell
   npm run pack:plugin
   ```

3. 建立一个长笔记，包含节点标题、摘要、连续同级标题、从二级起始的章节、可换行的长三级标题、`## 简介`、列表、图片、代码中的井号、转义字符、行内公式、独立公式、一张函数图和一张统计图。图块按 [现有格式](../004-function-plot/contracts/plot-markdown.md) 编写。另准备正文为空的节点、同名不同 ID 的两张图、完全相同的段落，以及单独用于旧坏块回退的笔记副本。
4. 在 DSH 提问框保留一段文字、一个既有引用和一个附件。记录相关 Markdown 原文或保留磁盘副本，便于核对写入范围和撤销。

## SC-001 至 SC-003　读写切换与正文排版

1. 先把详情宽度设为约 320 px，再用约 260 px 重试。每个宽度都滚动到长笔记中部，往返「编辑」和「完成」，核对相同段落仍可见，标题、摘要、分隔、边距、字号和换行一致。
2. 在两种状态分别核对一、二、三级标题及连续同级标题。颜色与普通正文可辨，字重、字号或留白能够辨认层级。节点标题保持最突出，长标题换行，代码与正文中的井号保留原用途。
3. 核对列表、图片、行内与独立公式、两张图的完整显示。读态选文、复制和点击合法链接，编辑态修改标题、摘要、正文及公式，完成后重新打开确认结果。检查空节点和同一笔记的只读会话，确认可阅读复制、无法写入。

## SC-004　图块移动、删除及保存后撤销

1. 将统计图从原位置拖到正文开头，再移到末尾，观察落点提示和完整图面。取消一次拖动，将另一拖动放在正文区域外，检查两次正文均保持原样。使用同名样例确认仅目标图移动。
2. 等待自动保存完成，退出并重新打开详情，核对围栏原文、ID、图序和周围正文。通过现有正文或会话历史撤销及重做，分别等保存完成确认位置实际恢复和再次移动。
3. 使用「删除图表」删除函数图，核对统计图及前后正文。等待保存完成后撤销，使原函数图在原位置恢复，再重做并重开详情确认。对统计图重复删除与恢复。检查普通粘贴、剪切和跨块选区不能改写图块定义。
4. 检查含旧坏块或重复 ID 的笔记可继续阅读，在相邻文字可写时编辑并核对坏块原文。另用验收副本在存在本地修改时从外部更改目标笔记，验证冲突报告与本地副本保护。详情见 [读写契约](contracts/note-detail.md)。

## SC-005　草稿引用与条件插入

在段间空白行、正文开头及末尾分别右键选择「添加此位置到正文」，检查提问框出现对应位置引用。手动发送一条添加图表的请求，核对图表落在目标空白处，两侧正文保留。普通段落取点时继续核对段后插入。

1. 选中 DSH 草稿中的一段文本。在编辑态正文用鼠标右键点中另一段文字，选择「添加图表/公式」。检查原草稿文字、引用及附件仍在，新引用可辨认来源和点击位置，笔记内容和宿主发送状态保持原样。点击草稿引用核对回跳。
2. 以互不影响的段落分别发送三个请求，经现有 `/mindmap` 流程要求添加行内公式、独立公式和图表。行内公式应出现在点击的两个字符之间，其他两项应在各自段落后。用含加粗、转义、中文和表情的目标段补验源码位置，核对目标外的原文与图块 ID。
3. 在空节点正文取起始引用，发送单项添加请求。核对新增内容从起始处出现，首次写入建立正确笔记引用。可在独立副本预先放一个未被地图引用的同名候选笔记文件，验证文件被保留并返回冲突。
4. 加入引用后修改目标段并保存，或者使该段及上下文出现重复，再发送。应保留现有笔记并提示重新选点。若仅在远处编辑且原段与上下文仍可唯一核对，复验原位置仍可用。另在原会话外重试一次已有待加入引用，核对原会话绑定。
5. 在有未保存修改的段落中执行右键操作。若已保存源无法核对点击点，应提示保存后重新选点。对仍能核对到已保存文段的情况，核查操作只更新原草稿。规则见 [定位契约](contracts/dsh-insertion-reference.md)。

## 离线回归

导出已保存的验收导图为独立 HTML，复制到另一目录后断网打开。拖动有连线的节点到分组外，核对节点、端点和连线跟随，分组背景位置及尺寸保持。切换子图再返回应保留本次位置，刷新应恢复导出位置。取消下一次拖动应回到此前位置。在至少两个分组的视图使用顶部排版按钮切换纵向与田字型，在七组及以上的视图复验多列。切换后只重排当前视图，刷新恢复导出时的排列。打开该节点详情，核对标题、正文顺序、公式、图片、图表、局部原文回退和复制，确认详情只显示阅读操作。复验离线搜索及节点切换，记录实际结果。
