# Feature Specification: 节点详情阅读与编辑样式统一

**Feature Branch**: `main`

**Created**: 2026-11-18

**Status**: Draft

**Input**: 以现有节点编辑页为基准，让只读预览和直接编辑共用正文渲染与自定义样式，并用较克制的字号和易读的颜色区分正文标题层级。编辑时可拖动或直接删除整张图，也可把正文中的插入位置加入 DSH 草稿，请 DSH 添加图表或公式。

## Clarifications

### Session 2026-11-18

- Q: 进入编辑模式后，笔记里的函数图和统计图也要和只读预览一样完整显示吗? → A: 两种状态均完整显示。编辑模式可手动删除整张图，也可拖动整张图调整它在正文中的位置。图表数据仍由 DSH 修改。在正文右键选「添加图表/公式」可将插入位置带入 DSH 草稿，用户补充要求并手动发送。公式仍可自行编辑。
- Q: 在一段文字中右键选择「添加图表/公式」时，行内公式应该插在点击的文字位置，还是和图表一样放在该段后面? → A: 行内公式插在点中的文字位置，图表和独立公式放在该段之后。

## 实机验收后的更新

后续定位插入应支持非空正文的空白行。用户可把空白位置加入草稿，手动发送后在该处插入图表或公式。文本取点沿用 FR-008 的规则，图表和独立公式放在段后，行内公式放在点击处。具体设计见 [图表与公式的正文选点](insertion-followup.md)。

离线 HTML 提供画布节点自由拖动，节点详情保持只读。离线本次打开的节点位置可随子图导航保留，刷新后从导出位置重新开始。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 用统一样式阅读和编辑节点详情 (Priority: P1)

用户打开节点详情时，看到以当前编辑页为视觉基准的只读页面。点击「编辑」后，在同一位置修改标题、摘要和正文。完成后回到阅读状态。

**Why this priority**: 阅读和编辑之间保留相同的版式和阅读位置，用户可以继续关注正在查看的段落。

**Independent Test**: 打开一条含标题、摘要、多个章节和长正文的笔记。在正文中段依次点击「编辑」和「完成」，核对版式、阅读位置和输入状态。

**Acceptance Scenarios**:

1. **Given** 节点详情处于只读状态，**When** 用户打开并浏览已有笔记，**Then** 标题、摘要、分隔位置、正文边距和段落布局沿用当前编辑页的视觉结构，文字可查看、选中和复制。
2. **Given** 用户已经滚动到某一段，**When** 在内容未发生变化时点击「编辑」再点击「完成」，**Then** 同宽度下相同内容的字号、行距、换行和段落位置一致，原来可见的段落仍在视野内。
3. **Given** 普通笔记允许编辑，**When** 用户通过「编辑」改动文字并点击「完成」，**Then** 输入在原位置发生，回到只读状态后能看到改动，并沿用已有保存和失败提示。
4. **Given** 节点或会话的权限为只读，**When** 打开详情或尝试输入，**Then** 可持续阅读和复制，内容保持原样。
5. **Given** 正文中有函数图和统计图，**When** 进入编辑，**Then** 两张图均保持完整显示。对其中一张执行「删除图表」后，仅该图从正文中移除，移除沿用正文的保存和撤销流程。
6. **Given** 用户正在编辑正文，且 DSH 提问框已有草稿，**When** 在目标位置右键并选择「添加图表/公式」，**Then** 一条能辨认来源节点与插入位置的引用进入原提问框，原草稿保留。用户补充描述并手动发送后，DSH 将行内公式插到点中的文字位置，将图表或独立公式加到该段之后。
7. **Given** 编辑中的节点笔记含一张图和多段正文，**When** 拖动该图到另一段前后，**Then** 拖动时显示落点，松开后仅该图移到目标位置。撤销恢复原位置，保存后重新打开仍可看到已保存的顺序。

---

### User Story 2 - 辨认正文标题层级而不抢占阅读重点 (Priority: P1)

用户看到笔记里的一级、二级、三级标题，能够辨认章节层级。标题用与正文有区别的颜色和字重，字号和留白保持紧凑，节点主标题仍是页面最突出的标题。

**Why this priority**: 较长笔记需要清楚的阅读顺序，正文小节也应该自然融入笔记。

**Independent Test**: 选择含一级、二级、三级标题、正文、列表和公式的笔记，分别打开只读与编辑状态逐项对照。

**Acceptance Scenarios**:

1. **Given** 笔记包含 `# 一级标题`、`## 二级标题` 和 `### 三级标题`，**When** 分别在两种状态查看，**Then** 三者均显示为各自的标题层级，显示顺序与原文一致。
2. **Given** 三种标题与正文同屏，**When** 比较它们的显示效果，**Then** 标题颜色与正文有可见区别，层级还可由字号、字重或间距辨认。一级标题只比正文略大，二级和三级与正文接近。
3. **Given** 笔记同时含普通文字、列表、行内公式和独立公式，**When** 在阅读和编辑之间切换，**Then** 各项按原顺序显示，公式保持可视排版，已有正文和公式编辑入口可继续使用。

---

### Edge Cases

- 无摘要或无正文的节点仍能按原方式查看和编辑已有字段，空笔记在只读状态保持简洁。
- 笔记可能从二级或三级标题开始，也可能连续出现同级标题。展示采用原文层级和顺序。
- 窄侧栏中的长标题可以换行，标题颜色在实际背景上仍然易读，内容留在详情区域内。
- 围栏代码块内的井号示例和普通正文中的井号按原用途显示。已有图片保留原有阅读与操作方式。
- 若笔记没有正文，仍可从正文区域引用起始位置。发送后如果目标位置无法唯一定位，保留可读来源并提示用户重新选点。
- 图表可以放到正文开头、末尾或两个内容块之间。拖动取消或放到正文区域外时保留原位置。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**：以当前编辑页为基准，替换旧预览的单独分节渲染。只读预览与直接编辑共用一套正文渲染规则和自定义样式，节点标题、摘要、正文的布局、边距、行距和相对位置在两种状态一致。
- **FR-002**：详情默认以只读方式打开，支持选文和复制。有权限的用户通过「编辑」进入直接编辑，通过「完成」回到只读，并沿用已有保存流程。
- **FR-003**：内容未变化时，在相同详情宽度切换只读与编辑，保持当前阅读位置，至少让相同的正文段落仍在可见区域。
- **FR-004**：正文一级、二级、三级标题在两种状态均可辨认，保留原始层级和顺序。正文中的非标题井号和代码示例照原用途显示。
- **FR-005**：正文标题使用与正文有明显区别的易读文字颜色，结合字号、字重和间距区分三级标题。一级标题略大于正文且小于节点主标题，二级和三级使用与正文接近的字号。长标题随详情宽度换行。
- **FR-006**：列表、图片、行内公式、独立公式、函数图和统计图在两种状态均完整显示。公式和图片沿用已有手动编辑方式。
- **FR-007**：编辑模式提供对单张函数图或统计图的明确删除操作。删除整张图沿用普通正文的保存和撤销，周围文字及其他图表保持原样。图表的数据和表达式仍由 DSH 按请求修改。
- **FR-008**：编辑正文时，右键提供「添加图表/公式」，在原 DSH 会话的提问框中加入一条标识导图、节点和正文插入位置的可读引用，保留已有文字、引用和附件。参考位置同时包含点击处和对应段落。用户补充描述并手动发送后，行内公式加到点中的文字位置，图表与独立公式加到该段之后。仅加入引用时保留原笔记内容。定位失效或无法唯一定位时先提示用户重新选点。
- **FR-009**：编辑模式可拖动整张函数图或统计图，在同一节点笔记的正文内容块之间调整顺序。拖动时标明预定落点。移动保留图表原有身份和定义，周围正文保持原样。移动沿用正文的保存和撤销流程。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**：选用一条有摘要和长正文的笔记，在正常宽度和窄栏各往返切换一次。两次均保留当前段落，标题、摘要和正文的边距、换行和章节样式在同一宽度下对应一致。
- **SC-002**：使用含一、二、三级标题的样例，在只读和编辑状态分别核对，六处标题均呈现正确层级。三级均有与正文可辨认的颜色差异，单看字重、字号和留白也能区分层级。
- **SC-003**：核对含列表、图片、行内公式、独立公式和图块的样例，五类内容均保持可阅读。只读时文字无法输入且可复制，手动编辑文字及公式并完成后，重新打开仍可看到已保存内容。
- **SC-004**：在含一张函数图和一张统计图的笔记中，切换到编辑时两张均完整显示。分别验证删除、拖动换位、撤销及保存后重新打开，目标图之外的内容保持原样。
- **SC-005**：用已有文字、引用和附件的草稿验证右键定位。仅执行加入引用时，草稿原有内容和笔记保持原样。分别发送一条行内公式、一条独立公式和一张图表，三项均落在规定位置。位置失效时保留笔记。

## Assumptions

- 本功能适用于 DSH 桌面侧栏的节点详情。以用户提供的截图中显示「完成」按钮的编辑页面为视觉参考。
- 具体字号和色值由后续设计确定。以同一侧栏宽度、缩放和背景对照样例，检验标题可辨认程度及两种状态的版式。
- 这里的「标题」指节点详情正文的 Markdown 标题。两种状态沿用同一套 KaTeX 公式排版规则，正文标题和段落通过共同的自定义样式呈现。
- 「插入位置」指当前节点笔记正文中的位置。
- 本次编辑模式开放直接删除和拖动整张图，更新了[图块功能规范](../004-function-plot/spec.md)中的手动操作边界。
