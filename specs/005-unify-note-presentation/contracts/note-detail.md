# 节点详情的读写和图块操作契约

## 同一份正文

- 打开节点时默认只读，保留选文、复制和原有安全链接行为。可写节点提供「编辑」和「完成」。离线或只读节点持续提供阅读。遇到保存失败和冲突，沿用既有反馈和本地副本保护。
- 标题、摘要、分隔线、正文宽度、边距和相同内容的行高一致。编辑焦点提示、图片移除和图表操作使用无需挤占正文宽度的呈现。切换读写保留相同滚动区域和正文可见段落。无摘要和空白正文沿用编辑页的空状态结构，输入提示仅在编辑态有用时显示。
- 按原 Markdown token 顺序呈现，保留 `## 简介` 等正文标题的位置及其真实层级。正文标题使用色彩、字重和间距，一级标题略大于正文且低于节点标题，二级和三级贴近正文大小。窄栏长标题自然换行。
- 在两种模式呈现列表、已有图片、普通代码、公式和图表。公式继续用 KaTeX，编辑态保留现有打开、编辑和删除途径。正文显示或转换所需的 DOM 以受控 token 和资源生成，Markdown 原始 HTML 保持原有安全语义。

## 完整图表及整图编辑

1. `dsh-plot` 的函数、柱状和折线图在两种模式显示相同图面、图例、单位和异常回退。图块作为正文的原子块，图例公式和图表控件与正文编辑、点击位置和 Markdown 序列化隔离。
2. 编辑态为有效整图提供明确的「删除图表」和拖动入口。拖动时在正文的合法顶层块间显示落点，支持正文开头与末尾。松开后只迁移选中围栏。取消、越界或目标已变化时保留当前正文。
3. 删除仅作用于所选图。显式拖放或删除走原正文历史、保存和重做，包含保存后的撤销。图块相同标题以 ID 区分，原定义、相邻内容与其他图保持。普通输入、剪贴和跨图选择不将图块定义暴露为可手动编辑内容。数据和函数表达式使用 DSH 既有写入途径。
4. 原文坏块仍可查看诊断和可复制的源文。只读模式保留已有图块的引用入口和回跳，原选文或图块无法精确定位时保留可读快照并说明位置变化。

## 离线回归

独立 HTML 复用相同阅读投影和 CSS，复验断网图面、公式、图片、标题、列表、选文和复制。离线详情展示已保存内容并提供阅读能力。画布节点可自由拖动，页面内保留本次位置。导出规则见 [现有图块离线契约](../../004-function-plot/contracts/dsh-plot-reference.md#离线)。
