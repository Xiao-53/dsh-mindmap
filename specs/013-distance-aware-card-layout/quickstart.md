# Quickstart & Validation Guide: 基于相连节点距离与结构规则的卡片初始排列优化

**Feature**: `013-distance-aware-card-layout` | **Date**: 2026-11-24 | **Spec**: [spec.md](spec.md)

## 1. 本地编译、静态检查与单元测试（工程验证）

> 按项目约定（`AGENTS.md`），日常开发执行静态类型检查、构建与预览打包；`npm.cmd run test` 仅在用户明确授权运行自动化测试时执行。

在仓库根目录执行以下命令：

```powershell
# 静态类型检查与构建产物验证
npm.cmd run typecheck
npm.cmd run build

# 自动化测试（仅在用户明确授权时执行）
npm.cmd run test
```

### 自动化验收对照点
1. **跨分组连线距离协同（`SC-001`）**：
   - 验证组内无边但存在跨组连线的多分组导图，下游卡片自动对齐上游相连卡片横向列位/重心，跨组平均横向偏移与总连线长度较旧盲排下降 $\ge 45\%$。
2. **分叉汇合弹性行、重心微调与零重叠（`SC-002`）**：
   - 验证 `1→2→1`、`1→3`、`2→1` 及不满 3 列行自动对齐相连重心（相邻偏差 $\le 48\text{px}$ 时精确对齐直线），且视图内任意两卡重叠率为 `0%`。
3. **增量邻居就近补位与旧布局保护（`SC-003`）**：
   - 验证既有已存坐标视图新增带连线节点直接落在相连邻居附近空位，原有已存坐标保持率 `100%`。
4. **确定性与性能（`SC-004`）**：
   - 验证含环路、孤立点及 20 节点 / 30 边的满载视图重复计算 10 次结果完全一致且瞬时完成。
5. **带子图节点单击选中高亮与双击下钻（`SC-005`）**：
   - 验证单击带子图节点停留在当前视图、选中卡片并激活 `.edges-focus` 提层高亮（不弹出详情）；双击带子图节点正常进入子图；拖拽松手不误触发下钻。

## 2. DSH Desktop 真机与离线 HTML 人工验收步骤

> 实现并构建打包后，在 DSH Desktop（浅色/深色主题）与导出的独立离线 HTML 阅读页中按以下 5 项手工确认：

1. **跨分组长斜线消除（`US1`）**：
   - 新建或对包含 3～4 个分层分组且主干连线跨组连接的导图点击“重置排列”；
   - 确认上下游直接相连的卡片基本上下垂直对齐或落在相邻列，跨组连线多为干净垂直短线或柔和短斜线，无横跨全图的冗余长斜线。
2. **分叉/汇合与不满行对称平衡（`US2`）**：
   - 查看包含 `1→2→1` 菱形、`1→3` 分叉或某组仅有 2 个节点的视图（对比重置排列效果）；
   - 确认单节点或双节点行不再死板紧贴最左列，而是居中对齐到所连接分支的重心位置，卡片整洁不重叠。
3. **局部新增节点就近落位（`US3`）**：
   - 在已手动排好的导图中通过 `/mindmap` 新增 1 个连接到右侧某张卡片的新节点；
   - 确认原有所有已拖好的卡片纹丝不动，新卡片自动出现在该目标卡片旁边的相邻顺向空位，无需再大老远从左上角拖回。
4. **带子图节点单击选中 vs 双击进入（`US4` / Q1）**：
   - 在任意含子图节点的视图（如总览页）**单击**一个带子图入口的卡片：确认视图不跳转，该卡片进入选中态且与之相连的线条和胶囊立刻浮升到卡片上方高亮看清去向，右侧不会闪出详情面板；
   - **双击**该卡片：确认平滑过渡 0.5 秒进入子图；
   - 返回父视图后**按住拖动**该卡片再松手：确认位置保存正常且不误跳转进子图；
   - **单击**无子图的普通卡片：确认立即选中并展开右侧详情面板；打开某叶子详情后去单击带子图卡片，确认旧详情自动收起并切换高亮到该子图卡片。
5. **既有 `layout.json` 保护与离线 HTML 一致性**：
   - 直接打开旧导图确认原有排版 100% 不变；点击右上角导出独立 HTML 并在浏览器中打开，验证初始排列（若未保存过或导出后交互）与带子图节点单/双击行为与侧栏完全一致。
