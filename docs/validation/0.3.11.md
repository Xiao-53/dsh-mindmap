# 0.3.11 创建失败占位处理

日期：2026-11-15。目标DSH v0.2.2-rc.3，安装包`dsh-mindmap-0.3.11.tgz`。本轮仅静态核对与构建打包，未运行自动测试、类型检查、故障注入、浏览器或视觉验收；以下行为待人工验证，不把构建成功视为保存/恢复保证已验证。

## 修改

- atlas_create先校验节点/视图/关系、笔记归属和完整候选的正文资源，再创建reservation；未通过校验的新请求不建立地图目录。旧请求记录的冲突检查与成功结果重放仍优先执行，不放宽身份保护。
- 完成占位后，如果提交失败且已回退，或在正式提交前失败，插件尝试释放本次reservation。先确认目录仅含本操作的reservation/failed记录及可选空notes目录，校验operationId派生的mapId和请求哈希，再使用与正常提交相同的active.json条件认领，认领后复核。
- 写入`.transactions/<operationId>/failed.json`保留kind/operationId/request/code，随后按版本删除reservation。先持久化请求指纹再释放占位，保留同ID不同请求拒绝及同请求重试；成功提交的result.json不删除。清理使用独立signal，普通取消不取消已开始的回退/清理。原操作遇到recovery_required时保留资料，不自动清理。
- 清理失败保留原错误码并附cleanup_incomplete诊断；未知文件、非空notes、符号链接、截断列举、未知/损坏记录、活动事务、purge及成功结果记录均不按占位清理，不递归删除目录。进程在清理认领期间中断仍保留活动标记，须单独处理，不按超时接管。
- 管理页与atlas_list将能严格识别的无地图占位放入独立incompleteCreates，返回mapId/operationId/state，不暴露内部请求哈希。用户指定的二级入口位于回收站页“回收站”文字右侧，名为“未完成创建”，只在回收站显示；点击切换列表，支持搜索operationId/mapId、按项清理和失败后继续清理。普通管理页不增加常驻失败列表。目录观察包含这些身份，后续提交成功可重新列为正常图。
- 手动入口通过会话绑定RPC cleanupCreate调用`src/server/cleanup-create.ts`；DSH新增`atlas_cleanup_create({mapId,operationId})`工具，须宿主授权后调用同一服务。只清理严格识别的无地图占位，受工作区、只读权限、同图队列及active条件认领保护。完整地图、未知文件、非空notes及活动/恢复记录均拒绝清理。
- 显式清理先写`.transactions/discarded-create.json`保留mapId/operationId/request，再按版本删除reservation/failed记录。清理完成后列表不再显示，重试清理幂等；中途失败显示cleanup_pending供继续清理。原创建请求被持久化作废，创建入口及实际提交前均复核标记；旧请求与清理交错时只释放晚到占位，不重新生成失败记录或地图。
- 历史只有reservation的目录不自动删除或修改；用户可经上述入口显式清理。包含额外内容、未知格式或完整结果却缺失map.json的目录继续报告原诊断。
- skill新增清理工具的条件：仅用户明确要求时查询并清理，不在建图后顺便清理其他记录，不扫描/删除磁盘文件。完全相同请求重试复用ID，修改参数使用新ID；显式清理后原请求作废，仅用户重新要求建图后使用新ID。

## 目录与接口限制

固定目标版本官方`@deepseek-ai/dsh-fs/src/index.ts`公开的是带版本条件的deleteFile，没有目录删除接口。本版不绕过宿主文件服务调用本地递归删除。自动释放后保留最小失败请求记录；显式清理后仅保留作废标记与空目录，以阻止旧请求复活，不承诺目录从磁盘彻底消失。

不修改DSH profile，不访问或清理用户已移走的历史备份，不提交、推送或发布。0.3.9人工通过记录保留，0.3.10的skill专项仍待用户反馈。

| 回收站二级入口 | “回收站”右侧的“未完成创建”可进入/退出、搜索、按项清理；清理完成记录消失，普通回收站还原/永久删除及侧键页面导航保持原有行为 | 未执行 |

| 权限与完整地图 | 只读拒绝清理，指定完整地图或错误operationId拒绝，保留所有用户内容 | 未执行 |
| 修改已有地图 | 原有读取、局部修改、删除预览/授权及布局保存正常 | 未执行 |
| 未知或损坏目录 | 含未知文件、损坏记录、非空notes或result却无map.json时，保留资料并报告诊断 | 未执行 |

提交故障、取消、清理失败、跨Host认领竞争与中断边界没有本轮故障注入证据；技术验证方式按项目约定另行授权。不得通过破坏真实地图或手工删改活动标记进行验收。
