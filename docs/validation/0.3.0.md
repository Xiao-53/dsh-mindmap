# 0.3.0 通用思维导图工具交付

日期：2026-11-15。目标DSH v0.2.2-rc.3；可安装产物为仓库根目录dsh-mindmap-0.3.0.tgz。本轮不修改DSH profile、不提交、推送或发布。

## 实现

- `/minimap`是实际注册的DSH命令，加载随插件打包的mindmap skill。只调用agent.inject排入后续上下文，不调用followUp/steer、提交草稿或发起模型请求。用户随后手动发送创建或修改需求；取消活动任务可能丢弃宿主待注入上下文，此时重新执行命令。
- 定位为通用思维导图，适用于架构设计、系统流程、学习知识等。仍使用v1 JSON结构、Markdown详情、独立layout.json及统一侧栏/离线阅读器。Markdown按作者顺序保留章节，学习专用标题不再强制重排。
- 注册atlas_list/read/create/preview/apply，使用来源会话工作区和Sandbox策略。schema拒绝任意路径、坐标和模板参数；创建自动分配地图身份及笔记路径，同名不同operationId创建独立图。
- 读取总是返回完整结构（保留依赖），笔记每页最多10个节点，nextCursor绑定工作区、mapId、版本和筛选。筛选只影响笔记页；模型须继续读取nextCursor，不将首屏当全量笔记。
- 修改只生成对象级候选；先全组校验结构、笔记资源及布局，再条件写入。仅改正文不改写未变map.json，内容/标题修改不重排已有布局。删除移除出现位置或全图对象的范围不同；视图/子图仍被引用时必须显式处理依赖，不能自动级联丢弃内容。
- 删除previewToken绑定完整变更及版本，宿主approval确认实际影响，已获宿主批准的相同token复用授权。模型参数不能充当用户授权；插件重载后预览/授权内存失效，需重新预览。
- 内容工具与侧栏RPC共用地图队列；文件观察已有active.json依赖，提交期间读取等待同Host队列或拒绝活动地图，保留最后有效画面；完成后按文件重新加载。
- 拖动工作副本按会话/工作区/mapId保留，切图、返回目录及页签卸载后可恢复；重试成功清除，明确放弃后重新读取。进程退出前提供浏览器beforeunload提醒；保留的是内存副本，不承诺宿主强制退出或崩溃后仍保留拖动草稿。

## 保存与恢复

`.transactions/active.json`使用createIfAbsent认领，并持久化实际文件前后镜像、旧版本和请求摘要；正式更新/删除及回退都带版本条件。提交前复核实际读集，逐项写入后复读完整候选，再持久化committed；完成结果保存在`.transactions/<operationId>/result.json`。同ID同请求返回原结果及版本，同ID不同请求拒绝。新建使用内部reservation.json识别本操作的空目录重试，未知目录不接管。

写失败逆序条件回退；读写/回退持续失败返回recovery_required并保留资料。外部内容既非before也非after时不覆盖。原始文件观察者可能看到中间磁盘状态，插件正常读取受活动标记保护；不声称跨文件操作系统原子替换。

进程重启不凭时间接管未知所有者。确认原写入或原Host已经结束后，用户明确输入：

```text
/minimap recover <mapId> 原操作已终止
```

该命令在当前工作区的同一队列内恢复：prepared回退，committed校验并补齐结果记录。恢复完成后手动刷新。外部冲突时保留活动记录并报告具体文件；须由用户核对恢复镜像与外部内容后处理，不能自动丢弃或覆盖外部编辑。工具本身不会代用户发出此确认。

完成的结果记录用于幂等重放，本轮不自动清理它们；人工内容撤销及其备份生命周期留到后续编辑范围。恢复机制在内存文件端口上注入I/O失败、用新协调器模拟进程重启；没有声称实际杀死DSH进程或真实磁盘满验收通过。

## 人工验收（待执行，T103）

| 场景 | 操作与预期 |
| --- | --- |
| 指令发现 | 输入/minimap可发现并执行，显示已加载；现有草稿不自动发送，不开始模型请求。随后手动发送架构或知识主题需求 |
| 新建架构 | 请求“创建服务架构图，包含网关、应用、存储和接口约束”；实际调用atlas_create后在目录点刷新可见，读取和重开内容一致 |
| 新建学习图 | 以不同operationId创建同名主题图；身份不同，原图不覆盖 |
| 只读与权限 | 只读会话创建/修改失败，无正式内容改动；拒绝写权限如实报告失败或待恢复 |
| 修改正文 | 手动拖动并保存位置后，要求只修改某节点公式或接口约束；正文变更，结构及手动位置保持 |
| 扩展子图 | 读取后向已有子图增加节点/关系；复用childViewId，旧对象ID及位置不变 |
| 分页 | 超过10个带笔记节点，沿nextCursor读取；修改内容后旧cursor失效，不能声称读取了省略笔记 |
| 局部移除 | preview移除共享节点的单视图出现位置，确认后apply；其他视图、节点正文仍在 |
| 全图删除 | preview显示出现位置/关系/笔记影响；拒绝宿主授权后保持原图，批准后实际删除；有子图先处理依赖 |
| 版本冲突 | read后外部修改目标，再apply旧版本；返回version_conflict，不覆盖新内容 |
| 重复请求 | 同operationId同请求重放结果，不新建第二张图；同ID不同内容拒绝 |
| 未保存布局 | 保存失败或待完成时返回目录、切图、关闭再打开页签；本会话恢复位置，可重试或明确放弃；切换会话不串位置 |
| 中断恢复 | 在独立样本中由用户选择执行；原Host完全结束后重新打开，活动图不正常列出；使用恢复命令，复读完整旧/新状态；冲突保留资料 |
| 通用笔记和离线 | 架构自定义章节保留顺序，全图HTML仍可离线阅读，原有视觉与引用行为正常 |
