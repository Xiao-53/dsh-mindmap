# 0.3.7 紧凑布局保存状态

按用户截图移除布局保存相关的顶部横条、大型重试/放弃按钮，改为阅读标题栏右上角28px图标按钮。

- 已保存：绿色圆圈勾。
- 保存中：蓝色环形进度，保存请求完成后更新；减少动态效果时静态显示。
- 未保存：琥珀色磁盘；包含恢复的会话内工作副本，不将“恢复位置”本身当失败。
- 失败：红色警告，真实错误不消失，只收进按需打开的状态弹层。

悬停可查看状态文字，按钮提供aria-label；点击查看详情并保存/重试，存在工作副本或错误时可放弃重载。保存中禁用动作，外部点击或Escape关闭弹层。仍保留原有条件写入、失败后内存位置和切图保留逻辑。独立的地图读取/文件观察错误保留原反馈，正常保存状态不占画布空间。离线HTML不显示工作区保存按钮。

已构建打包dsh-mindmap-0.3.7.tgz。本轮仅静态核对与构建，未运行自动测试、类型检查、浏览器或视觉验收，未提交或推送。

T128待人工复验：四种状态及图标/颜色可区分；拖动保存、失败重试、切回恢复位置时状态正确；状态弹层可查看真实错误、保存与放弃可用、保存中不重复提交；外部点击/Escape可关闭，窄侧栏无溢出，保存提醒不再挤占画布；原阅读和离线导出正常。
