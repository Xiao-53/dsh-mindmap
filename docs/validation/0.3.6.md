# 0.3.6 四边端点排序与轻量位移

用户确认0.3.5已改善左右侧，剩余问题集中于上下侧；随后明确选择撤销开发中的曲线交叉优化，复用统一排序规则，而非尝试消除复杂图中的所有交叉。最终0.3.6不包含曲线采样、交叉计数或相邻交换搜索。

四边均按对端相对位置投影排序：左右侧的切向是Y，上下侧是X；再按离边距离归一到同一侧外参考平面，处理投影方向相同但远近不同的连接。同侧输入、输出一起排序，不分角色；最多6轮依据实际端口进行校正，保留逆序较少的结果，重复状态停止，稳定ID处理同位。不会重新布局卡片、改变关系方向或删除连线，不保证任意复杂图无交叉；没有基于实际曲线的搜索。

节点目标位置变化采用140ms立方缓出的requestAnimationFrame过渡，卡片、分组、SVG端点、曲线、箭头和标签使用同一中间布局。只计算目标端点顺序，动画帧复用该顺序计算坐标。直接拖动时立即跟手，普通刷新或取消拖动回位可平滑过渡；初次挂载不从原点飞入；视图切换保留原0.5秒机制。减少动态效果时直接更新。动画不写入layout.json，卸载取消帧；删除对象在首帧就从显示集合移除。

已构建打包dsh-mindmap-0.3.6.tgz；未运行自动测试、类型检查、浏览器或视觉验收，也未测量复杂图实际帧率。未提交或推送。
