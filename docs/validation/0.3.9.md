# 0.3.9 原生mindmap skill与内容规则

日期：2026-11-15。目标DSH v0.2.2-rc.3；安装包为仓库根目录`dsh-mindmap-0.3.9.tgz`。用户已明确反馈“人工验收通过了”，本版已实现范围按该反馈记录人工验收通过，T139完成；0.3.8既有通过记录保留。

## 实现范围

- `register.ts`只注册mindmap skill，删除旧`/minimap`命令的全部代码，包括recover、迁移提示和别名；Host注册不再依赖commands服务。移除旧注入使用的commands/llm直接依赖。
- 使用宿主原生`/mindmap`：选择或输入后引用保留在输入框，用户填写需求后手动发送。由宿主skill consumer加载正文，不再把指引预先排入下一次请求。正常自动发现策略保留，模型也可按需加载。
- 新skill明确地图定位、按任务分页读笔记、节点/分组/子图职责、架构/流程/知识组织、关系依据和方向、共享对象复用、局部字段修改、整篇正文替换注意事项及删除预览/授权。没有任务不创建空图，不能猜测侧栏选中对象。
- 新增节点连同出现位置、关系展示集合及子图关联按真实schema操作；不开放布局、分区尺寸和对齐工具。保存成功仍由既有插件行为刷新并打开目标图。
- 管理页空状态文案改为`/mindmap skill`。运行时唯一正文与描述为`src/server/prompts/authoring.ts`，没有另建SKILL.md副本。

## 官方接入依据与边界

DSH固定目标版本[原生skill输入与展示说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/packages/client/ui-skill/README.md)规定：`/name`选择落为普通可编辑文字，输入框引用高亮由原生lexicon识别；[skill consumer说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/packages/skill/tool-skill/README.md)规定：随用户请求发送的skill token由pre-step边界加载。同名Host命令会优先占用入口，因此插件不注册`mindmap`命令。

宿主需启用`dsh-client-ui-skill`和`dsh-tool-skill`。目录缓存或服务未启用可能影响发现/高亮；本版原生入口及输入框引用随用户整体反馈记录人工通过，没有新增独立常驻“已启用”标签。输入框引用只表示本次草稿选择，保存成功依据工具结果。内嵌skill没有文件path，原生点击不提供SKILL.md文件预览。

按用户要求，旧恢复命令一并删除。自动失败回退与事务资料保留；遇到中断残留active.json或recovery_required仍拒绝继续写入，不自动认领或清除记录。本版没有新的用户恢复入口，不能再执行历史文档中的`/minimap recover`，相关情况须单独处理。
