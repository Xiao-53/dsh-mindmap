# 0.4.0-preview.5 节点笔记公式

本地候选 [dsh-mindmap-0.4.0-preview.5.tgz](../../dsh-mindmap-0.4.0-preview.5.tgz) 已通过构建打包。包体 1,040,477 字节，较 preview.4 增加约 726 KB，包含插件和独立阅读器中的公式渲染代码与字体。

阅读、可视正文及离线阅读器共用公式规则。直接输入或粘贴有效公式时原地预览，点已有公式可修改、预览或删除。正文撤销记录内容动作，应用后的修改走现有自动保存。公式继续以原式存入 Markdown，异常式保留可读源码。公式草稿不会随导出分享。
