# 0.3.5 端点、通用模板与交付反馈

本轮交付包为仓库根目录dsh-mindmap-0.3.5.tgz，目标DSH v0.2.2-rc.3不变。

端点以对端中心初排，再按对端实际端口投影最多迭代6轮，使用稳定关系ID处理同位，并保留局部逆序较少的排序；处理卡片不同高度、多端口导致的上下错位。只重排边界端点，不改变地图内容、关系方向和节点布局，不保证任意布局完全无交叉。

原“↗/·”换为带底色、描边的蓝色子图箭头/灰绿色详情文档图标；测量节点也包含同样标识与标题留白。正常拖动不再出现未保存横条，失败状态仍保留。选文浮动按钮缩小内边距、使用深色文字；“查找知识”改为“查找节点”。模板根面包屑为导图总览、详情标题为节点详情、依赖图例为依赖关系；旧Markdown的学习提醒标题仅在显示时映射为注意事项，不改源文件。新提示词不强制学习栏目。

阅读通知3秒后开始240ms淡出，随后移除；再次插入同类引用会重新计时，关闭按钮及卸载清理保留。真实文件保存错误不依赖此临时通知。

自动打开通过本地目标版本官方SessionBinding.eventSource的实时append工具结果与sidebarRight.openTab接入：关联atlas_create/apply的callId，检查success及稳定mapId、operationId，限定当前仍在屏幕上的同一会话绑定，去重同一操作。初始化/替换/补载历史结果不触发；预览及失败不触发；不修改草稿或发出模型请求。官方依据为安装包dsh-api-session-controller/src/client/sessions/service.ts、contract/events.ts及dsh-client-ui-sidebar-right/src/client/service.ts。DSH真实事件投递仍待人工验收。

## 提示词编辑位置

- 运行时正文：src/server/prompts/authoring.ts（mindmapAuthoring）。
- 内嵌mindmap skill注册与/minimap注入：src/server/prompts/register.ts。二者同在src/server/prompts/，没有另存一份DSH SKILL.md。
- 参考内容规范与示例：docs/mindmap-authoring-prompts.md；此文档不由插件自动读取。
- 工具参数约束：src/server/tools/schemas.ts。`.agents/skills/`是Codex/Spec Kit开发技能目录，不是DSH运行时mindmap正文。

关系label保持可选，提示词明确只有方向/含义不够清楚时才写；现有图的已写label不被批量删除。修改运行时正文后需重建安装包并更新DSH插件。
