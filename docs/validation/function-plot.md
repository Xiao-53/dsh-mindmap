# 0.4.0-preview.6 节点笔记图块

本地安装包为 [dsh-mindmap-0.4.0-preview.6.tgz](../../dsh-mindmap-0.4.0-preview.6.tgz)，目标宿主为 DSH `v0.2.2-rc.3`。安装按 [本地插件流程](../plugin-development.md) 使用本次 tgz。

- 节点详情用现有 KaTeX 排版、JSXGraph SVG 显示函数图、柱状图和折线图。支持函数范围、数据单位、缺值提示与数据复制。损坏图块局部回退为原文。
- 图块通过在线右键或 Shift+F10 加入原 DSH 会话草稿，可点击草稿引用回跳。发送后的消息保留来源和内容快照。AI 修改由手动发送触发，仍用现有版本和删除审批路径。手动改正文时保留原图块。
- 导出使用已保存快照，单个 HTML 内嵌 KaTeX 和 JSXGraph。离线阅读器仅提供浏览、查找和复制。
