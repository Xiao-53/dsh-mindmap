# 0.4.0-preview.2 原位编辑与自动保存

本地候选 [dsh-mindmap-0.4.0-preview.2.tgz](../../dsh-mindmap-0.4.0-preview.2.tgz) 启用手动编辑自动保存。

- “全部导图”旁的小图标按当前可用模式循环切换，同一行保留重置图标。模式按纵向、田字型、多列排序。
- 标题、摘要直接输入。点击正文或聚焦后按 Enter，在原位修改 Markdown。失焦回到排版后的笔记。选中文本仍可引用。用小图标添加图片，悬停或键盘聚焦图片角上的按钮可移除引用。多处完全相同的 Markdown 引用通过正文定位删除。
- 文字停顿约 800 ms 后自动保存，组字期间等待。图片、拖动结束和排版操作立即保存。工具栏的状态图标提供重试与放弃。回退后只有完整读集内容一致才更新文件版本基线，响应不明时先查询回执。
- 写入布局会生成 v2 格式。新版添加的文本图片封装也需要新版读取器。

已构建打包，保存专项 17 项通过。DSH 实机中的输入、快捷键、布局和视觉仍待人工验收。[专项记录](edit-layout-history-internal.md)
