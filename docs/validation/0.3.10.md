# 0.3.10 skill新建契约与示例

日期：2026-11-15。目标DSH v0.2.2-rc.3；本地安装包`dsh-mindmap-0.3.10.tgz`。0.3.9既有人工通过记录保留，本次skill调整待人工验收。

## 调整

用户反馈DSH在新建地图前列出既有图、搜索源码并读取无关地图作为格式样例。此前skill将已有图定位与新建规则写在同一段，且缺少中心节点语义与完整创建示例。本次只修改内嵌skill，入口和五个工具契约保持现有实现。

- 新建直接按材料调用atlas_create，无需先查同名图；列图仅用于实际查找/查重/复用任务或已有图身份定位，已有mapId直接读目标图。
- 说明读取内容与当前任务的关系。格式依据skill及工具schema；不为学习格式搜索源码、读无关地图或保存试验图，用户指定参考/复用仍可读取。
- 补齐nodes与occurrences、relations与relationIds的定义/展示区别，端点出现位置、分组归属、必填空数组和notes节点ID到Markdown的映射。
- centerNodeId表达子图所属节点，普通根视图省略；它与所属节点childViewId双向对应，不要求所属节点同时出现在自己的子图画布，参与连线时仍需occurrence。
- 内嵌一个两节点、一分组、一关系、一根视图和节点正文的完整创建参数示例，说明仅用于理解格式；真实任务替换内容和operationId，不照抄主题或节点数量。

唯一运行时正文为`src/server/prompts/authoring.ts`；按现有schema和validate-map逻辑静态核对示例，没有调用工具创建任何地图。未运行自动测试、类型检查、浏览器或视觉验收；仅构建打包，模型实际遵循效果由用户检查。未修改DSH profile、提交、推送或发布。
