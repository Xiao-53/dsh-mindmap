# 0.3.4 鼠标侧键页面导航修正

用户反馈：回收站无法用鼠标侧键返回主管理页及前进；知识笔记不应占用侧键历史，只有页面变化才进入历史。

回收站范围由AtlasPane统一管理，主管理页、回收站和不同导图接入页面历史。导图内部仅切换视图时新增阅读历史；打开、切换、关闭笔记，以及同一视图内的搜索/引用定位，只更新当前页面状态，不新增历史，也不清除已有前进分支。跨页面返回可恢复相机和页面原有笔记状态，但不会逐次回放笔记操作。旧版留下的同视图笔记历史会跳过。

返回后进入新的页面或导图视图会清除前进分支；地图目标按工作区和当前目录检查，已移入回收站或永久删除的导图不通过历史重开。侧键仍限制在面板内，图内过渡期间忽略重复侧键。离线HTML共用阅读导航修正。

已执行npm run pack:plugin，构建打包dsh-mindmap-0.3.4.tgz（5个文件）；仅静态核对和构建，未运行自动测试、类型检查、浏览器或视觉验收，未提交或推送。

人工复验（T117，全部待执行）：

- 主管理页点击右上角回收站：侧键后退直接回主管理页，前进回回收站；连续点击图标形成的页面切换也可往返。
- 管理页打开导图、进入子图、依次打开/切换/关闭多篇笔记：每次侧键后退直接回前一个导图视图，耗尽后回管理页；前进可恢复页面，不逐次回放笔记打开/关闭。
- 返回上一视图后只操作笔记或同视图搜索/引用定位，前进仍可进入原下一视图；改走新的页面/子图后，旧前进分支清除。
- 返回管理页后前进恢复最近导图；其间进入回收站形成新路径后，前进不重开旧导图。旧导图被删除、工作区改变或历史耗尽时不错误重开，也不触发宿主后退。
- 跨视图过渡保持原0.5秒要求，连续侧键不重影；面板外侧键不被插件拦截。新下载的离线HTML中，笔记操作同样不占历史，历史耗尽不离开HTML。
