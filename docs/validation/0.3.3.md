# 0.3.3 管理页视觉反馈修正

用户本轮反馈：回收站入口移到右上角并降低强调；回收站勾选框不应黑底；删除后的成功信息占据列表；文件夹三角箭头需要优化。

已将回收站文字页签替换为标题栏右侧17px描边图标，无常驻背景、徽标或高亮下划线，悬停显示提示，点击在回收站和全部导图间切换。列表顶部仅标注当前范围与数量，搜索区及按需选择模式保留。

文件夹展开符由字体字符换为固定12px SVG描边箭头，折叠朝右、展开朝下，统一居中和旋转原点。删除、批量删除、永久删除和清空完成后不再出现常驻成功消息；失败与未完成状态仍如实显示。

已构建打包dsh-mindmap-0.3.3.tgz；仅静态核对和构建，未运行自动测试、类型检查、浏览器或视觉验收，未提交或推送。
