# 0.3.2 搜索区恢复与目录加载修正

用户反馈：管理页搜索区被误删，切换/加载目录较慢。已恢复单层边框搜索区，配色与现有列表一致，原生输入不再叠加独立边框。可按标题或所属文件夹路径筛选导图，按文件夹名匹配展开路径；回收站同样可搜索。更改搜索词会清理旧选择，全选和所选操作仅覆盖当前匹配列表；全部还原/清空回收站仍明确针对整个回收站。

## 加载路径修正

静态排查确认原目录list调用listMaps→readSnapshot，按地图串行读取结构、全部笔记、资源和布局，再复读读集。返回目录同时有回调刷新和可见性刷新，观察每条ready帧还会再次触发加载；每次请求都将列表替换成加载提示。

本轮增加管理目录专用listMapHeaders：每图仅读map.json、校验结构及活动/永久删除标记，最多4项并发，不读笔记、资源或布局。目录请求不排在整批永久删除的工作区写队列后，独立条件读取有效索引；打开目标图仍执行原完整快照校验。AI工具atlas_list仍沿用原完整有效性查询，不因管理页优化改变其含义。

客户端只保留一个在途目录请求，同期聚焦/返回/ready复核共用请求，真实变化发生在读取期间时合并为后续复核。每代目录观察的ready帧只安排一次复核。返回目录直接显示组件内已有列表，后台更新不清空列表；初次打开仍显示加载状态。不缓存跨会话/工作区的列表，也不省略目标地图打开时的内容与路径校验。

## 交付及验证边界

安装包为仓库根目录dsh-mindmap-0.3.2.tgz。仅执行静态阅读与构建打包，未运行自动测试、类型检查、浏览器或视觉验收，未测量真机耗时。没有将代码路径优化写为性能指标已通过。未提交、推送或修改DSH profile。

## 人工复验（T111，待执行）

- 搜索标题、文件夹及无结果，清空后恢复原目录；匹配项展开其父级路径。搜索中的全选及所选删除/还原不触及过滤范围外项目。
- 从阅读页返回目录，先看到已有列表；窗口聚焦和文件变化后台更新时，列表不闪回“正在读取目录”。
- 工作区较多地图/大笔记/图片时比较首开及返回目录耗时；实际时间尚未测量。打开目标地图仍能报告笔记缺失、资源越界等错误。
- 创建、改名、目录移动、回收站删除/还原后最终列表正确；内容写入期间或永久删除中的图不作为正常目录打开。首次加载或错误时仍可明确看到状态。
