# dsh-mindmap v0.4.0 写作交接

交给 Googleargon。请基于这份材料写两份独立的中文 Markdown 草稿。更新日志从 `v0.3.12` 比到 `v0.4.0`，宣传稿面向正在使用 DeepSeek Harness 的用户。两份草稿均以文末的公开资料为事实依据。

## 交付内容

| 文件 | 读者与用途 | 写作重点 |
| --- | --- | --- |
| `CHANGELOG-v0.4.0.md` | 已安装插件、准备升级的用户 | 先概括最大变化，再按节点编辑、图表和引用、画布与离线导出列出新增和修复。最后给出兼容版本、下载链接和人工验收状态。 |
| `announcement-v0.4.0.md` | 想整理知识、梳理流程或设计系统架构的 DSH 用户 | 给一个清楚的标题，选三项能直接感受到的变化，用一个实际操作流程串起它们。结尾提供安装包和 Release 链接。 |

## 发布事实

- 产品名为 `dsh-mindmap`，是 DeepSeek Harness（DSH）的原生右侧栏思维导图插件。
- `v0.4.0` 于 **2026-11-18** 在 GitHub 正式发布。对比基线为 `v0.3.12`。正式安装包为 `dsh-mindmap-0.4.0.tgz`。
- 目标宿主为 **DSH `v0.2.2-rc.3`**。安装到当前使用的 DSH profile 后，可从原生右侧栏打开「思维导图」。
- 最新候选由用户确认人工测试通过，正式包通过 TypeScript 检查和构建打包。线上下载包与本地构建的 SHA-256 一致。可写「已通过用户人工验收」，性能数字及专项故障覆盖以各自证据记录为准。
- 仓库采用 MIT 许可证。插件使用各地图独立的 `map.json`、Markdown 笔记和 `layout.json`。这可以作为产品特点，更新日志优先列版本新增。

## 相比 v0.3.12 的主要变化

| 主题 | 用户可见变化 | 需要写准的行为 |
| --- | --- | --- |
| 节点笔记编辑 | 读写状态共用排版。在详情底部点击「编辑」，可原位编辑标题、摘要和正文，支持插入 PNG、JPEG 或 WebP 图片。 | 写入通过自动保存。可撤销和重做，当前编辑会话的操作历史最多 30 步。 |
| LaTeX 和图表 | 正文显示、编辑行内与独立 LaTeX 公式，支持函数图、柱状图和折线图。编辑时可整体移动或删除图表。 | 需要修改图表数据或函数表达式时，可以把已有图表引用加入 DSH 草稿，再手动发出修改请求。 |
| 正文位置引用 | 在编辑正文时，可以把文字处、段间空白、正文开头或末尾加入 DSH 草稿。已有草稿文字、引用和附件会保留。 | 空白处选择「添加此位置到正文」，手动发送后在该处插入。文字处取点时，行内公式在字符间，图表和独立公式在整段之后。 |
| 画布和分组 | 加入纵向、田字型、多列排列，以及重置、撤销和重做。自由拖动节点时，连线跟随，分组背景保持原尺寸。 | 显式切换排版会重排当前视图。多列及田字型的可用性取决于分组数量。 |
| 离线 HTML | 单个 HTML 保留公式、图表、图片、搜索和子图导航，也能拖动节点、切换当前视图的排版。 | 节点详情只读。拖动和排版调整留在当前打开的页面，刷新后恢复导出时的位置及排列。已有 HTML 需用新版本重新导出。 |
| `/mindmap` 内容组织 | 生成时优先让总览展示主线，复杂结构分到子图，解释和资料放进节点详情。 | 提示词默认每视图最多 20 个显示节点，这是生成规则，可随明确请求调整。 |

原生侧栏、`/mindmap` 建图、节点和选文引用、回收站与离线 HTML 是已有能力。宣传稿可以用它们交代产品定位，更新日志应把新增交互和改善说具体。

## 可演示的操作流程

1. 在 DSH 中手动发送 `/mindmap 帮我把咖啡店运营整理为思维导图，将采购、门店和财务拆成子图`。打开侧栏里的导图。
2. 进入「财务」节点，点击「编辑」，补一段说明。在段间空白右键「添加此位置到正文」。
3. 在原 DSH 草稿补上「在这个位置插入一张折线图，类目为第一周至第四周，数值为 12、15、14、18，单位为千元」，然后手动发送。请把数据标明为演示样例。
4. 导出 HTML，断网打开，演示切换排版、拖动节点和只读查看详情。

## 写作口径与素材

- 宣传稿讲用户能完成的事，可以围绕「从对话创建导图，到在节点里整理资料，再导出可互动的离线文件」展开。
- 使用界面里的原名，例如「思维导图」「编辑」「完成」「添加此位置到正文」。描述 DSH 协作时保留「手动发送」这一环。
- 现有截图来自 `v0.3.12`，可用作侧栏界面示意。需要展示新版编辑器、图表或离线排版时，使用实际 `v0.4.0` 截图。 [已有界面截图](https://github.com/Xiao-53/dsh-mindmap/blob/v0.4.0/docs/images/interface-preview.png)
- 发版内容以 `v0.4.0` 及已发布源码为准。外部 Harness 规划、尚无测量结果的性能指标和未记录验收的专项能力不进入成稿。
